02 🔗 트위스티드 페어 (Twisted Pair, TP)
1기본 개념과 꼬는 이유
앞글자 암기
2 · 절 · 신 · 접
2개 이상 구리 도선 / 절연체 피복 / 신호 전달 / 접지(Ground)
💡 핵심 정리
  • 2개 이상의 구리 도선이 꼬인 형태이며 각 도선은 절연체로 싸여 있음
  • 도선 하나는 신호를 전달, 다른 하나는 접지(Ground)로 사용
  • 도선을 꼬은 이유: 잡음이 완전히 제거되지는 않지만 단위 길이당 꼬인 횟수가 증가하면 상당한 감소 효과
  • 전화선으로 사용되었으며, 최근에는 LAN의 100BASE-T, 기가비트 이더넷에서 많이 사용
  • 분류: UTP(Unshielded TP) / STP(Shielded TP)
2차폐 여부에 따른 분류 (UTP / FTP / STP / S-STP)
암기 포인트
U → F → S → S-S
차폐 강도 순. UTP = 차폐 없음 / FTP = 4쌍 한꺼번에 / STP = 쌍별 차폐 / S-STP = 쌍별 + 전체
UTP (Unshielded TP)
금속 박막 없이 플라스틱 피복만. 가장 저렴·유연. 요즘 가장 많이 사용. 최대 거리 100m, 155MHz 대역폭(CAT.5E 기준).
FTP (Foiled TP)
접지선과 4쌍을 포일(금속 박막)로 한 번 감싼 다음 외부 피복. UTP보다 우수하지만 제작 어려움. 공장·PC방.
STP (Shielded TP)
UTP의 각 쌍을 금속 박막으로 둘러쌈. UTP보다 비싸고 성능이 월등하지 않으며 설치 불편 → 거의 사용 안 함.
S-STP (Screened Shielded TP)
10기가비트 이더넷의 보급으로 사용. CAT.7 케이블이 이에 해당. 각 쌍 + 전체에 차폐.

4UTP 커넥터 (RJ-45)와 연결 방식
앞글자 암기
송 1·2 / 수 3·6
CAT.5 기준 RJ-45 8핀 중 송신 1·2번, 수신 3·6번
💡 RJ-45 (Register Jack)
  • UTP 커넥터로 RJ-45가 가장 많이 사용 · 8핀
  • 송신용으로 1, 2번을 쓰고 수신용으로 3, 6번을 쓴다 (CAT.5 기준)
  • 다이렉트 케이블: 송수신이 변하지 않음. PC↔허브, PC↔스위치
  • 크로스 케이블: 송수신이 바뀜. PC↔PC, 허브↔허브 연결
⚙️ UTP 케이블 특성
  • 가격이 저렴하고 사용하기 쉽다
  • 유연하여 설치하기 쉽다
  • 커넥터는 RJ-45를 사용한다
  • 최대 전송 거리 100m, 155MHz 대역폭 제공 (CAT.5E 기준)
03 📺 동축 케이블 (Coaxial Cable)
1구조와 특성
앞글자 암기
차 · 주 · 전 · 매 · BNC
차폐성 우수 / 주파수 특성 우수(수백 Mbps) / 전력 손실 적음 / 매설 가능 / BNC 커넥터
💡 핵심 정리
  • 외부와의 차폐성이 좋아서 외부 간섭(노이즈) 현상이 적음
  • 구조: 내부 도체 — 절연체 — 외부 도체(차폐) — 플라스틱 피복
  • 주파수 특성이 TP에 비해 우수 → 수백 Mbps 빠른 데이터 전송 가능
  • 전력 손실이 적고, 바다 밑이나 땅 속에 묻어도 성능에 큰 지장이 없음
  • 장비 연결은 BNC 커넥터를 사용

04 💡 광케이블 (Optical Fiber)
1광케이블 기본 원리
광케이블 한 줄 정의
유 · 간 · 속 · 폭 · 오
가는 유리섬유 / 전기적 간섭 X / 전송속도 ↑ / 대역폭 넓음 / 오류 적음
💡 빛의 굴절과 스넬의 법칙(Snell's law)
  • 높은 밀도에서 낮은 밀도로 이동하는 빛은 경계에서 굴절
  • (a) 입사각 < 임계각 → 굴절 / (b) 입사각 = 임계각 → 굴절각 90° / (c) 입사각 > 임계각 → 전반사
n₁ · sin θ₁ = n₂ · sin θ₂
스넬의 법칙 — n₁ : 매질 1의 굴절률, θ₁ : 입사각
θc = sin⁻¹(n₂ / n₁)
임계각 — 굴절각이 90°일 때의 입사각
2광섬유 구조 (3층)
앞글자 암기
코 · 클 · 코
코어(높은 굴절률) → 클래딩(낮은 굴절률, 125μm) → 코팅(합성수지 보호)
코어 (Core)
높은 굴절률의 투명한 덮개로 빛이 통과하는 통로 역할.
클래딩 (Cladding)
코어보다 낮은 굴절률의 투명한 덮개. 코어 외부를 싸며 빛을 반사. 표준 지름 125μm (ITU-T).
코팅 (Coating)
코어와 클래딩을 보호하기 위해 합성수지로 만든 피복으로 외부를 감쌈.
광섬유 크기 정의
코어 지름과 클래딩 지름의 비율로 정의 (단위 μm). 클래딩 지름은 125μm로 ITU-T 표준화.
3광섬유의 전파 방식 (다중모드 / 단일모드)
수신 특성 순서
단일 > 증가형 > 계단형
단일모드가 가장 우수, 도시와 도시 장거리(30Km↑) 공중망
💡 전파 방식 분류
  • 다중 모드: 송신부에서 나온 광선이 코어에서 서로 다른 경로를 타고 수신부로 전달
  • 계단형(SI) 다중모드: 코어의 밀도가 일정 → 모드 분산 발생
  • 증가형(GI) 다중모드: 코어 밀도가 클래딩 쪽으로 갈수록 연속적으로 감소 → 모드 분산 영향 ↓ → 계단형보다 좋은 수신 특성
  • 단일 모드(SM): 하나의 광섬유에 단일 광선을 전송 → 다중모드보다 우수한 수신 특성. 도시와 도시 간 장거리 공중망
구분계단형(SI) 다중모드증가형(GI) 다중모드단일모드(SM)
코어 재료석영석영석영
클래딩 재료석영석영석영
코어 지름 (μm)5050, 62.5, 1009 ~ 10
클래딩 지름 (μm)125125125
전송 대역폭수십 MHz/Km수백 MHz ~ 수 GHz/Km10 GHz/Km 이상
용도LAN, 데이터링크용고속 장거리 LAN, 데이터링크용대용량(100Mbps↑), 장거리(30Km↑) 공중망용
4광통신 시스템 (송·수신부)
앞글자 암기
송: LED · ILD / 수: PD · APD
송신부(전→광): LED(단거리) · ILD(장거리) / 수신부(광→전): PD · APD
송신부 소자
LED(단거리) · ILD(분사 레이저 다이오드)(장거리) → 전기 신호를 광 신호로 변환.
수신부 소자
PD(Photo Diode), APD(Avalanche Photo Diode) → 광 신호를 전기 신호로 변환.
5광섬유의 장단점
장점 앞글자
대 · 감 · 간 · 도 · 무
대역폭 넓음 / 감쇠 낮음(50Km 무중계) / 간섭 강함 / 도청 강함 / 무게 가벼움
👍 장점
  • 대역폭이 넓다: 가시광선의 넓은 대역폭을 이용해 높은 데이터 전송률
  • 신호 감쇠가 낮다: 중계기 없이 50Km까지 신호 전달 (TP/동축은 5Km마다 중계기 필요)
  • 전자기파 간섭에 강함: 일반 전자기파는 광섬유에 영향을 주지 않음
  • 도청에 강함: 광섬유 연결이 매우 어려워 도청을 위한 선 연결이 어려움
  • 무게가 가볍다
👎 단점
  • 설치와 유지 보수가 어렵다 (특정 도구·기술 요구, 부러지기 쉬움)
  • 레이저 광원이 전기 신호 발생기보다 가격이 매우 높다
6광섬유의 전송 손실 6종
고유 3 + 부가 3
레 · 흡 · 구 / 마 · 휨 · 접
고유 손실: 레일리·흡수·구조 불완전 / 제조 후 부가: 마이크로벤딩·휨·접속
레일리 산란 손실
광이 미소한 입자에 부딪힐 때 광이 여러 방향으로 진행하는 현상.
흡수 손실
광 출력이 광섬유 내에서 일부 열로 유실되는 현상.
구조 불완전에 의한 손실
불균일한 면에 의해 광 에너지의 일부가 코어 밖으로 나와 광 손실 증가.
마이크로벤딩 손실
광섬유의 불균일한 압력에 의해 광섬유의 축이 휘기 때문에 발생.
휨 손실
광섬유 설치 시 광섬유가 구부러져서 발생하는 손실.
접속 손실
광섬유를 접속할 때 정확하게 코어에 맞추지 않을 경우에 발생하는 손실.
7광섬유의 분산 (Dispersion)
크기 순서 ★
모드 > 재료 > 구조
모드 분산은 다중모드에만 존재, 단일모드 광섬유에는 없음
💡 분산 = 광 펄스가 광섬유를 통과하는 동안 시간적인 퍼짐이 발생하는 현상
  • 모드 분산: 다중 모드형에서 각 모드의 전파 경로가 달라 출력단에서 도착 시간 차이로 발생. 계단형 다중모드에서 영향 큼 → 증가형이 개선. 단일모드에는 없음
  • 재료 분산: 유리의 굴절률이 빛의 파장에 따라 다름. 레이저에서 방출되는 빛은 완전한 단일 파장이 아니어서 발생
  • 구조 분산(도파로 분산): 경계 면에서 빛의 일부가 클래딩 부분으로 누설되며 발생. 펄스 파형이 시간적으로 퍼짐
05 📡 무선 매체 (Wireless)
1주파수에 따른 전파 특성
주파수 영역 3종
3KHz ~ 1GHz / 1GHz ~ 300GHz / 300GHz ~ 400THz
라디오파 / 마이크로파 / 적외선파 (가시광선 = 400THz~)
주파수가 높을수록
감쇠가 심해 직진성이 강해진다 → 대량 정보를 전송할 수 있어 고정·초고속 통신에 적합. 안테나도 소형으로 제작 가능.
주파수가 낮을수록
감쇠가 적고 회절성이 강해진다. 전송 정보량은 적지만 해상이나 항공 등 장거리 통신에 적합.
전파의 거리별 출력
전파는 진행 거리의 제곱에 반비례해 출력이 감쇠하는 특성을 갖는다.
라디오파 / 마이크로파 / 적외선
라디오파(3KHz~1GHz) / 마이크로파(1GHz~300GHz) / 적외선파(300GHz~) 주파수 영역.
2무선 통신의 전파 방법 3종
앞글자 암기
지 · 전 · 가
지표면 전파 / 전리층 전파 / 가시선 전파
지표면 전파
라디오파가 지구를 감싸는 대기의 가장 낮은 부분을 통하여 이동하는 방식 (장파·중파).
전리층 전파
높은 주파수의 라디오파가 전리층에 발사되어 전리층에서 반사되어 되돌아오는 방식 (단파).
가시선 전파

💡 지상 마이크로파 특징
  • 유선 매체를 설치하는 데 드는 비용이 비싸거나 설치가 불가능할 때 주로 사용
  • 가시선 전파를 이용하므로 안테나는 고지대에 위치해야 한다
  • 지향성 안테나인 접시형(파라볼라) 안테나나 혼 안테나가 사용
  • 장거리 구간에서는 높은 데이터 전송률을 제공
  • 동축 케이블에 비해 훨씬 적은 수의 증폭기나 리피터가 필요
  • 대기를 통해 통신이 이루어지므로 구조물이나 기상 조건에 영향을 받음

5위성 마이크로파 (Satellite microwave)
상·하향 주파수 외우기
상 > 하
상향 링크에 더 높은 주파수 (지상은 강한 송신 가능 / 위성은 전력 한계로 낮은 주파수)
💡 위성 통신의 기본
  • 위성을 매개체로 전자기파를 이용하여 데이터를 송수신
  • 위성 통신은 전리층을 통과하여 전파되어야 하기 때문에 1GHz 이상의 주파수를 이용
  • 상향 링크에 더 높은 주파수를 할당 → 지상에서 더 강한 신호 송신이 용이
  • 위성에서는 시스템 크기·전력 문제로 강한 송신기를 갖추기 어려워 감쇠가 상대적으로 적은 낮은 주파수 사용

💡 고도에 따른 위성 통신 종류
  • 저궤도 위성(LEO): 100 ~ 1,500 Km
  • 중궤도 위성(MEO): 5,000 ~ 20,000 Km
  • 정지 궤도 위성(GEO, Geostationary Earth Orbit): 적도 36,000Km 상공. 지구 자전과 같은 주기로 돌아 지상에서 정지된 것처럼 보임 → 송수신국이 항상 같은 위치에 있어 통신용으로 활용 용이
⚖️ 위성 마이크로파 장단점
  • 장점: 매우 넓은 영역에 신호 도달 → 다중점 연결에 유리. C 대역 링크 대역폭 500MHz로 음성 채널 다중화 다수 가능. 대기 통과 거리 짧아 오류율 낮음 (1×10⁻⁸ vs 지상 1×10⁻⁶)
  • 단점: 전송 지연 길다 (GEO 왕복 ≈ 0.24초 = 2 × 36,000 / 300,000). 주파수가 높을수록 비·눈 등 기후 영향 ↑. 보안성 떨어지고 위성 고장 시 수리 어려움
6적외선파 (Infrared)
적외선 핵심
300GHz ~ 400THz / IrDA / 4Mbps
단거리 / 벽 통과 못함 / 리모컨 / IrDA 표준 / 75Kbps → 4Mbps 개선
💡 적외선파 특징
  • 300GHz ~ 400THz, 단거리 통신에 사용. 벽을 통과하지 못하는 특성을 이용
  • Remocon (remote controller, 리모컨)에 사용
  • IrDA (Infrared Data Association): 적외선 통신의 표준을 제정
    • 키보드, 마우스, 프린터 등의 주변기기와 PC가 무선으로 통신하기 위한 표준
    • 원래 규정된 데이터 전송률은 8m 이내에서 75Kbps였으나 최근 4Mbps까지 개선

▪ 단답형

Q13.광섬유의 코어 외부를 감싸며 코어보다 낮은 굴절률을 가진 층의 이름은? (영문 또는 한글)
클래딩(Cladding) — 표준 지름 125μm로 ITU-T에서 표준화. 코어보다 낮은 굴절률로 빛을 코어 안에 가둬 반사시킨다.
Q14.지상 마이크로파에서 안테나 높이 h = 80m, K = 4/3일 때 최대 전송 거리 d는 약 몇 km인가? (소수점 첫째 자리까지)
d = 7.14 × √(4/3 × 80) = 7.14 × √106.67 = 7.14 × 10.328 ≈ 73.7 km
Q15.적외선 통신의 표준을 제정한 단체의 영문 약어는?
IrDA (Infrared Data Association) — 키보드·마우스·프린터 등 PC 주변기기 무선 통신 표준. 75Kbps → 최근 4Mbps까지 개선.
Q16.광섬유의 분산 중 다중모드 광섬유에만 존재하고 단일모드에는 없는 것은?
모드 분산(Mode Dispersion) — 다중 모드형에서 각 모드의 전파 경로가 달라 출력단에서 도착 시간 차이가 발생. 계단형에서 영향 큼, 증가형이 개선.
Q17.스넬의 법칙 식을 적으시오 (n₁, n₂, θ₁, θ₂ 사용).
n₁ · sin θ₁ = n₂ · sin θ₂ — 임계각 θc = sin⁻¹(n₂ / n₁), 굴절각이 90°가 되는 입사각.

▪ 서술형 연습

Q18.광섬유의 장점을 5가지 이상 서술하시오.
① 대역폭이 넓다 — 가시광선의 넓은 대역폭을 이용해 높은 데이터 전송률.
② 신호 감쇠가 낮다 — 중계기 없이 50Km까지 전달 가능 (TP·동축은 5Km마다 중계기).
③ 전자기파 간섭에 강함 — 일반 전자기파가 광섬유에 영향을 주지 않음.
④ 도청에 강함 — 광섬유 연결이 어려워 도청용 선 연결이 매우 어려움.
⑤ 무게가 가볍다.
Q19.광섬유의 전파 방식 3가지(계단형 다중 모드, 증가형 다중 모드, 단일 모드)를 코어 지름과 수신 특성을 중심으로 비교하시오.
▸ 계단형(SI) 다중 모드: 코어 지름 50μm, 코어 밀도가 일정하여 모드 분산 발생, 전송 대역폭 수십 MHz/Km. LAN·데이터링크용.
▸ 증가형(GI) 다중 모드: 코어 지름 50·62.5·100μm, 코어 밀도가 클래딩 쪽으로 갈수록 연속적으로 감소하여 모드 분산 영향 ↓, 수십~수 GHz/Km. 고속 장거리 LAN.
▸ 단일 모드(SM): 코어 지름 9~10μm로 단일 광선만 전송, 10GHz/Km 이상. 다중모드보다 우수한 수신 특성. 도시와 도시 간 장거리(30Km↑) 공중망.
수신 특성: 단일 > 증가형 > 계단형.
Q20.위성 마이크로파에서 상향 링크 주파수가 하향 링크 주파수보다 더 높게 할당되는 이유를 서술하시오.
상향 링크에 더 높은 주파수를 할당하는 이유는 지상에서 더 강한 신호 송신이 용이하기 때문이다. 위성에서는 시스템 크기와 전력 문제 등으로 강한 송신기를 갖추기 어려워 감쇠가 상대적으로 적은 낮은 주파수를 이용한다. 예) C 대역: 상향 6GHz / 하향 4GHz, Ku 대역: 14GHz / 12GHz.
