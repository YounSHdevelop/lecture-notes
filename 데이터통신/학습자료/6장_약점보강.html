01 🔬 광섬유 3층 구조 + 굴절률 관계
⚠ 자주 틀리는 포인트
"코어 vs 클래딩, 누가 굴절률이 더 높지?" → 코어 > 클래딩 (안쪽이 더 밀도 높음)
"빛의 통로는 어디?" → 코어 (Core = 중심 = 통로)
"클래딩 지름은?" → 125μm (모든 종류 공통, ITU-T 표준)
코어
(빛의 통로)
🟡 코어 (Core)
높은 굴절률 · 9~125μm
빛이 통과하는 통로
🔵 클래딩 (Cladding)
낮은 굴절률 · 125μm
빛을 반사 (전반사 일으킴)
🟢 코팅 (Coating)
합성수지 피복
외부 충격 보호
📐 코어 지름 별 종류
단일모드 = 9~10μm (가장 좁음, 단일 광선)
계단형 다중 = 50μm
증가형 다중 = 50/62.5/100μm

외울 것: 클래딩 125μm는 셋 다 동일 / 변하는 건 코어 지름!
02 💫 전반사 조건 — 스넬의 법칙
⚠ 자주 틀리는 포인트
"전반사가 일어나려면 입사각이 임계각보다 어때야 해?" → 커야 함 (>)
왜? 입사각이 충분히 크면 빛이 통과 못 하고 모두 반사되니까.
🔥 REPEAT MISTAKE — 전반사의 "방향"이 헷갈림
Q. 전반사는 어떤 방향에서 일어나는가?

✅ 높은 굴절률 → 낮은 굴절률 (예: 코어 → 클래딩)
❌ 낮은 굴절률 → 높은 굴절률 (불가능!)

"고→저로 갈 때만 전반사"

왜 이게 중요한가? 광섬유가 작동하는 핵심 원리예요. 빛이 코어(고밀도)에서 클래딩(저밀도) 경계를 만났을 때, 입사각이 임계각보다 크면 빛이 모두 반사되어 코어 안에 갇혀 멀리 전달돼요.
입사각 < 임계각
굴절 (다른 매질로 빠져나감)
입사각 = 임계각
굴절각 = 90° (경계면 따라 진행)
입사각 > 임계각 ★
전반사 (광섬유의 원리!)
💡 광섬유에서 전반사가 가능한 이유
① 코어가 클래딩보다 굴절률이 높음 (필수 조건)
② 빛이 코어 안에서 클래딩 경계에 임계각보다 큰 각으로 부딪침
③ 결과: 빛이 모두 코어 쪽으로 반사되어 갇힘 → 멀리 전달

만약 코어 굴절률이 클래딩보다 낮으면 → 빛이 클래딩으로 빠져나가 전송 불가!
03 📊 광섬유 분산 3종 — 발생 매트릭스
⚠ 자주 틀리는 포인트 (★★★ 진짜 자주 틀림)
Q. 단일모드에 없는 분산은? → 모드 분산 (단일 광선이라 경로 차이 X)
Q. 모든 광섬유에 있는 분산은? → 재료 분산 + 구조 분산 (= 색 분산)
Q. 분산 크기 순서? → 모드 > 재료 > 구조
🔥 REPEAT MISTAKE — 재료 분산 vs 구조 분산 헷갈림
"파장에 따라 굴절률이 달라서 발생" → 재료 분산 (구조 X)
"빛이 클래딩으로 누설" → 구조 분산 (재료 X)

★ 결정적 키워드 매칭 ★
분산핵심 키워드원인
모드경로 차이다중모드 광선이 여러 길로 감
재료파장 / 굴절률유리(재료)의 굴절률이 파장마다 다름
구조클래딩으로 누설경계면(구조)에서 빛이 새어 나감

"재료 = 파장 / 구조 = 누설"
"재료"를 보면 → "유리 재료가 파장마다 다르게 굴절"을 떠올리고,
"구조"를 보면 → "광섬유 구조(경계면)에서 새는 것"을 떠올리세요!
분산 종류 계단형 (SI) 증가형 (GI) 단일모드 (SM) 원인
🔴 모드 분산 ✓ 큼 ✓ 작음 ✗ 다중모드 광선의 경로 차이로 도착 시간 다름
🟠 재료 분산 ✓ ✓ ✓ 빛의 파장별 굴절률 차이
🟡 구조 분산 ✓ ✓ ✓ 빛 일부가 클래딩으로 누설
📂 분산 분류 트리
분산 (Dispersion)
├─ 모드 분산 (단일모드엔 없음)
└─ 색 분산 (Chromatic)
├─ 재료 분산 (파장별 굴절률 차이)
└─ 구조 분산 (=도파로 분산, 클래딩 누설)
🎯 암기법
"모재구" 순서로 작아짐 → 모드 > 재료 > 구조
"단일은 모드가 없다" → 단일모드에 없는 분산 = 모드 분산
"색 = 재 + 구" → 색 분산 = 재료 + 구조
04 📉 광섬유 손실 6종 — 제조 vs 설치
⚠ 자주 틀리는 포인트
"흡수 손실은 제조 단계? 설치 단계?" → 제조 단계 (고유 손실)
"마이크로벤딩은?" → 설치 단계 (불균일한 압력)
✅ 제조 단계 (고유 손실)

광섬유 자체의 결함

  • 레일리 산란 손실 — 미소 입자에 부딪힘
  • 흡수 손실 — 광 출력이 열로 유실
  • 구조 불완전 손실 — 불균일한 면에 누설
⚠ 설치 단계 (부가 손실)

사람이 설치하다 발생

  • 마이크로벤딩 손실 — 불균일한 압력으로 축이 휨
  • 휨 손실 — 광섬유 구부러짐
  • 접속 손실 — 코어 정렬 불량
🎯 암기법
제조 = 레·흡·구조 (광섬유 자체)
설치 = 마·휨·접 (사람이 만지는 것)
🔥 REPEAT MISTAKE — 손실 6종 원인 키워드 매칭이 약함
각 손실의 "결정적 원인 키워드" 한 단어로 외우기 ★
손실키워드설명단계
레일리 산란입자광이 미소 입자에 부딪힘제조
흡수열광 출력이 광섬유 내에서 열로 유실제조
구조 불완전면불균일한 면에 의해 광 에너지 누설제조
마이크로벤딩압력불균일한 압력으로 축이 휨설치
휨구부러짐광섬유 자체가 구부러짐설치
접속정렬접속 시 코어 정렬 불량설치

"레=입자, 흡=열, 구조=면, 마=압력, 휨=구부러짐, 접=정렬"
🔥 REPEAT MISTAKE — 마이크로벤딩 vs 휨 손실 (미묘한 차이)
둘 다 설치 단계 손실(마·휨·접)이지만 원인이 다름!
🔬 마이크로벤딩 손실
  • 키워드: 불균일한 압력
  • 광섬유의 축이 미세하게 휨
  • "micro(미세) + bending(휨)"
  • 눈에 잘 안 보이는 미세한 휨
💪 휨 손실
  • 키워드: 구부러짐
  • 광섬유가 눈에 보이게 구부러짐
  • 설치할 때 손으로 휘는 큰 휨
  • 코너에 강제로 꺾을 때

구분 팁:
▸ 문제에 "불균일한 압력"이 나오면 → 마이크로벤딩
▸ 문제에 "구부러져서" 또는 "설치 시 휘어서"가 나오면 → 휨 손실
05 💡 광통신 송수신 소자 매칭
⚠ 자주 틀리는 포인트
"단거리 송신은?" → LED
"장거리 송신은?" → ILD (분사 레이저 다이오드)
"수신 소자는?" → PD / APD (둘 다 Photo Diode)
📤 송신부 (전 → 광)
LED (Light Emitting Diode)
→ 단거리, 가격 저렴

ILD (Injection Laser Diode)
→ 장거리, 가격 매우 비쌈 (광섬유 단점 중 하나!)
📥 수신부 (광 → 전)
PD (Photo Diode)
APD (Avalanche Photo Diode)

→ 빛을 전기 신호로 변환
🔋 전기 → LED/ILD → 💡 광섬유 → PD/APD → 🔋 전기
🎯 암기법
송신 = 빛 만들기 (LED·ILD)
수신 = 빛 감지하기 (Photo Diode 시리즈)
LED = 단거리 / 레이저 = 장거리

"RG-58은?" → LAN (50Ω, 10BASE2 Thin Ethernet)
"75Ω는?" → CATV/TV용 (RG-6, RG-11, RG-59)
RG 번호 임피던스 용도 분류

RG-58 ★ 50Ω 10BASE2 LAN (Thin) LAN용

🎯 암기법 (이것만 외우면 끝)
50Ω = LAN → RG-8, RG-58
75Ω = TV → RG-6, RG-11, RG-59

"오공(50)은 랜, 칠오(75)는 TV"로 외우면 어떤 RG가 나와도 답할 수 있어요!
07 📻 주파수 대역별 활용 (VLF~EHF)
⚠ 자주 틀리는 포인트
"이동 전화는?" → UHF (300MHz~3GHz)
"위성 통신은?" → SHF (3~30GHz)
"우주 통신은?" → EHF (30~300GHz)
"FM 라디오는?" → VHF (30~300MHz)
VLF3~30KHz
LF30~300KHz
MF300K~3M
HF3M~30M
VHF30M~300M
UHF300M~3G
SHF3G~30G
EHF30G~300G
📻 라디오·TV 관련 (헷갈리기 쉬움)
▸ AM 라디오 = MF (중파)
▸ 단파 방송, HAM = HF
▸ FM 라디오, VHF TV = VHF (초단파)
▸ UHF TV = UHF
📱 통신 관련
▸ 이동 전화 = UHF (300MHz~3GHz)
▸ 레이더 = UHF / SHF
▸ 위성 통신 = SHF (3~30GHz)
▸ 미사일, 우주 통신 = EHF (30~300GHz)
🎯 결정적 암기법
AM↔MF, FM↔VHF (글자가 정반대!)
휴대폰 U = UHF ("U"의 폰)
위성 S = SHF (Satellite의 S)
우주 E = EHF (Extreme = 가장 먼 우주)
🔥 REPEAT MISTAKE — VHF vs UHF (이동전화 위치 헷갈림)
"TV"가 들어가서 VHF로 착각하기 쉬움. 이동전화는 무조건 UHF!
대역주파수활용
VHF 30~300 MHz VHF TV, FM 라디오 (옛날 TV만)
UHF ★ 300 MHz ~ 3 GHz 이동 전화, TV 방송, 레이더

"이동전화는 무조건 UHF!"
"휴대폰 U = UHF"
08 🛰 위성 마이크로파 — 핵심 3가지
⚠ 자주 틀리는 포인트
"위성 마이크로파 주파수는?" → 1GHz 이상
"정지궤도 고도는?" → 36,000 Km
"Uplink vs Downlink, 누가 주파수 높음?" → Uplink > Downlink
1️⃣ 주파수: 1 GHz 이상
마이크로파 전체 대역(1~300GHz) 중 사용
위성 통신용은 주로 SHF (3~30GHz)
2️⃣ 정지궤도: 36,000 Km
지구 자전과 같은 주기로 공전
지상에서 보면 항상 같은 위치에 있는 것처럼 보임
3️⃣ Uplink > Downlink (주파수)
상향 링크(Uplink)가 하향 링크보다 높은 주파수
→ "올라가는 게 더 힘드니까 높은 주파수"로 기억
4️⃣ 가시거리 공식 (참고)
d = 7.14√(Kh), K = 4/3
(이건 공식 자체보다 √(Kh) 형태만 알아두면 OK)
🎯 위성 통신 3가지 키워드
1 GHz 이상 · 36,000 Km · Uplink > Downlink
🔥 REPEAT MISTAKE — 위성 마이크로파 주파수 "1 GHz 이상"
"300 MHz 이상"이나 "30 GHz 이상"으로 헷갈리지 말 것!

왜 1 GHz인가?
마이크로파 전체 대역이 1 GHz ~ 300 GHz이기 때문에, 위성 마이크로파도 1 GHz부터 시작합니다.

주파수 경계값 단권화 ★
  • 라디오파: 3 KHz ~ 1 GHz
  • 마이크로파: 1 GHz ~ 300 GHz (위성 마이크로파 = 1GHz 이상)
  • 적외선파: 300 GHz ~ 400 THz

"1G / 300G / 400T 이 3개 숫자"만 외우면 다 풀려요!
+ 🌐 BONUS: 무선 전파 방법 3종
🌍 지표면 전파

→ 저주파 대역에서 활용
⚡ 전리층 전파

→ HF(단파) 방송에 활용
📡 가시선 전파

→ 마이크로파, 지상 마이크로파에 활용 (고지대 안테나 + 지향성)

🔥 무조건 외워야 하는 숫자 10개
  1. UTP 최대 전송 거리 = 100m
  2. 광섬유 무중계 전송 = 50 Km (TP/동축은 5Km)
  3. 클래딩 지름 = 125 μm (모든 종류 공통)
  4. 단일모드 코어 = 9~10 μm
  5. 계단형 코어 = 50 μm
  6. 라디오파 = 3KHz ~ 1GHz
  7. 마이크로파 = 1GHz ~ 300GHz
  8. 적외선파 = 300GHz ~ 400THz
  9. 정지궤도 = 36,000 Km
  10. 위성 마이크로파 = 1 GHz 이상
🔥 무조건 외워야 하는 매칭 10개
  1. 유선 매체 3종 = TP / 동축 / 광케이블
  2. 무선 매체 3종 = 라디오파 / 마이크로파 / 적외선파
  3. 전파 방법 3종 = 지표면 / 전리층 / 가시선
  4. 차폐 강도 = UTP < FTP < STP < S-STP
  5. S-STP = CAT.7 (10기가비트)
  6. 분산 크기 = 모드 > 재료 > 구조 (모드는 단일모드 X)
  7. 수신 특성 = 단일 > 증가형 > 계단형
  8. 송신 소자 = LED(단)/ILD(장), 수신 = PD/APD
  9. RG-8, RG-58 = 50Ω LAN, 나머지(6,11,59) = 75Ω TV
  10. 이동전화=UHF, 위성=SHF, 우주=EHF
🔥 절대 안 헷갈리게 — 함정 패턴 모음
🚨 함정 1: 단일모드에 없는 분산
❌ 색 분산 → ✅ 모드 분산 (색 분산은 모든 광섬유에 있음)
🚨 함정 2: 전반사 방향
❌ 저→고 → ✅ 고→저 (코어→클래딩)
🚨 함정 3: 흡수 손실 vs 레일리 산란
"열" 키워드 → ✅ 흡수 / "입자" 키워드 → ✅ 레일리 산란
🚨 함정 4: 재료 vs 구조 분산
"파장/굴절률" → ✅ 재료 / "클래딩 누설" → ✅ 구조
🚨 함정 5: 위성 마이크로파 주파수
❌ 300MHz / 30GHz → ✅ 1 GHz 이상
🚨 함정 6: 이동 전화 = VHF?
❌ VHF → ✅ UHF (300MHz~3GHz)
🚨 함정 7: 마이크로벤딩 vs 휨
"불균일한 압력" → ✅ 마이크로벤딩 / "구부러짐" → ✅ 휨
🚨 함정 8: RG-8 = CATV?
❌ CATV → ✅ LAN (50Ω, 10BASE5 Thick Ethernet)
