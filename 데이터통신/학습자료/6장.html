💡 핵심 정리
  • 2개 이상의 구리 도선이 꼬인 형태이며 각 도선은 절연체로 싸여 있다
  • 도선 하나는 신호를 전달하며, 다른 하나는 접지(Ground)로 사용
  • 전화선으로 사용되었으며, 최근에는 LAN의 100BASE-T, 기가비트 이더넷에서 많이 사용
  • 종류: UTP(Unshielded), STP(Shielded)
3도선을 꼬는 이유
왜 꼬는가?
잡음 감쇄 (단위 길이당 꼬임 ↑ → 감소 ↑)
평행선이면 잡음이 한쪽에만 누적되지만, 꼬으면 양쪽이 균등하게 받아 상쇄됨
💡 잡음의 효과 예 (PDF 그림 6-3)
  • 평행선: 한쪽 잡음 합 16, 다른 쪽 12 → 차이 4 (잡음 남음)
  • 꼬임: 양쪽 14씩 → 차이 0 (잡음 상쇄)
  • 도선을 꼬았다고 해서 잡음이 제거되는 것은 아니지만 꼬인 횟수가 증가하면 상당한 감소 효과
4UTP / FTP / STP 구분
차폐 정도 ★
UTP < FTP < STP < S-STP
금속 박막이 없으면 UTP, 한 번 감싸면 FTP, 각 쌍을 둘러싸면 STP
UTP (Unshielded)
네 쌍 이상의 꼬인 선을 금속 박막 없이 플라스틱 피복으로 감싼 구조. 가격 저렴, 유연. CAT.5E를 많이 사용.
FTP (Foiled)
접지선과 4쌍의 선을 포일(금속 박막)로 한 번 감싼 다음 외부 피복. UTP보다 우수하지만 제작 어려움. 공장·PC방에서 사용.
STP (Shielded)
UTP의 각 쌍을 얇은 금속 박막으로 둘러싼 구조. 초기 LAN에 사용되었으나 UTP로 대체. 가격↑ 성능 큰 차이 X, 설치 불편 → 거의 사용 X.
S-STP (Screened STP)
CAT.7 케이블. 10기가비트 이더넷 보급으로 사용. 편조 쉴드 + 금속 박막.

03 💡 광케이블 (Optical Fiber)
1광케이블 개요
광케이블 한 줄 ★
가는 유리섬유로 빛 전달
전기적 간섭 X, 전송 속도 ↑, 대역폭 ↑, 오류 ↓
💡 핵심 정리
  • 가는 유리섬유를 이용해 정보를 보냄 → 전기적 간섭을 받지 않음
  • 전송 속도가 높고, 대역폭이 넓고 오류가 적음
2스넬의 법칙 + 임계각
스넬의 법칙
높은 밀도 → 낮은 밀도 = 굴절
입사각이 임계각보다 크면 전반사 → 광섬유가 빛을 가두는 원리
n₁ × sinθ₁ = n₂ × sinθ₂
n₁: 입사 매질 굴절률, n₂: 굴절 매질 굴절률
💡 입사각에 따른 3가지 경우
  • 입사각 < 임계각 → 굴절 (빛이 다른 매질로 통과)
  • 입사각 = 임계각 → 굴절각이 90°
  • 입사각 > 임계각 → 전반사 (빛이 경계면에서 모두 반사)
θ_C = Sin⁻¹ (n₂ / n₁)
임계각 = 굴절각이 90°일 때의 입사각
3광섬유 3층 구조 ★
광섬유 구조 ★
코어 → 클래딩 → 코팅
안쪽이 굴절률 높음 (전반사 위해) — 코어 = 빛의 통로
코어 (Core)
높은 굴절률의 투명한 덮개로 빛이 통과하는 통로 역할.
클래딩 (Cladding)
코어보다 낮은 굴절률의 투명한 덮개로 코어 외부를 싸고 있으며 빛을 반사. 지름 125μm로 ITU-T 표준화.
코팅 (Coating)
코어와 클래딩을 보호하기 위해 합성수지로 만든 피복을 이용해 외부를 감쌈.
왜 굴절률 차이?
코어(고굴절률) → 클래딩(저굴절률) 경계에서 임계각보다 큰 각으로 빛이 부딪치면 전반사되어 빛이 코어 안에 갇혀 전달됨.
4광섬유 전파 방식 (3가지) ★
수신 특성 순서 ★
단일모드 > 증가형 다중 > 계단형 다중
계단형은 모드 분산 심함 → 증가형이 개선 → 단일모드는 모드 분산 없음
계단형 다중 모드 (SI)
코어의 밀도가 일정. 광선이 여러 경로로 전파 → 모드 분산 발생. 가장 수신 특성 떨어짐.
증가형 다중 모드 (GI)
코어의 밀도가 클래딩 쪽으로 갈수록 연속적으로 감소 → 모드 분산 영향 감소. 계단형보다 우수.
단일 모드 (SM)
하나의 광섬유에 단일 광선만 전송. 다중 모드보다 우수한 수신 특성. 도시와 도시 간 장거리.
크기 정의
광섬유 크기 = 코어 지름과 클래딩 지름의 비율 (단위 μm). 클래딩 = 125μm (ITU-T 표준).
종류계단형 다중 (SI)증가형 다중 (GI)단일 모드 (SM)
코어 지름 (μm)5050, 62.5, 1009~10
클래딩 지름 (μm)125125125
전송 대역폭수십 MHz/Km수백 MHz~수 GHz/Km10 GHz/Km 이상
용도LAN, 데이터링크고속 장거리 LAN, 데이터링크대용량(100Mbps↑), 장거리(30Km↑) 공중망
5광통신 시스템 (송신·수신 소자)
소자 매칭 ★
송신 = LED·ILD / 수신 = PD·APD
단거리 = LED / 장거리 = 레이저 (ILD)
💡 핵심 정리
  • 송신부: LED와 분사 레이저 다이오드(ILD) 사용 → 단거리는 LED, 장거리는 레이저
  • 수신부: PD(Photo Diode) 또는 APD(Avalanche Photo Diode)
  • 전기 신호 → 전-광 변환 → 광섬유 → 광-전 변환 → 전기 신호
6광섬유 장단점
구분내용
장점 ▸ 대역폭이 넓다 — 가시광선의 넓은 대역폭으로 높은 전송률
▸ 신호 감쇠가 낮다 — 중계기 없이 50Km까지 전달 (TP·동축은 5Km마다 중계기 필요)
▸ 전자기파 간섭에 강하다 — 일반 전자기파는 광섬유에 영향 X
▸ 도청에 강하다 — 구리선은 쉬워도 광섬유는 연결이 매우 어려움
▸ 무게가 가볍다
단점 ▸ 설치와 유지 보수가 어렵다 — 특정 도구와 기술 필요. 금속 도체보다 부러지기 쉽다
▸ 레이저 광원은 전기 신호 발생기보다 가격이 매우 높다
7광섬유의 전송 손실 6종
💡 광섬유 고유 손실 (제조 단계)
  • 레일리 산란 손실: 광이 미소한 입자에 부딪힐 때 여러 방향으로 진행
  • 흡수 손실: 광 출력이 광섬유 내에서 일부 열로 유실
  • 구조 불완전 손실: 불균일한 면에 의해 광 에너지가 코어 밖으로 누설
💡 제조 후 부가되는 손실 (설치 단계)
  • 마이크로벤딩 손실: 광섬유의 불균일한 압력에 의해 광섬유의 축이 휘기 때문
  • 휨 손실: 광섬유 설치 시 광섬유가 구부러져서 발생
  • 접속 손실: 광섬유를 접속할 때 정확하게 코어에 맞추지 않을 경우 발생
8광섬유 분산 ★
분산 크기 순서 ★
모드 분산 > 재료 분산 > 구조 분산
분산 = 광 펄스가 광섬유 통과 시 시간적 퍼짐 / 모드 분산은 단일 모드에는 없음
모드 분산
다중 모드형에서 각 모드의 전파 경로가 달라 출력단 도착 시간 차이로 발생. 계단형에 영향 큼, 증가형이 개선. 단일 모드에는 없음.
재료 분산
유리의 굴절률이 전파하는 빛의 파장에 따라 다르기 때문에 파형이 벌어짐. 레이저 빛도 완전한 단일 파장이 아니라 발생.
구조 분산 (도파로 분산)
경계면에서 빛의 일부가 클래딩 부분으로 누설. 누설되는 양은 빛의 파장에 따라 다름 → 펄스 파형이 시간적으로 퍼짐.
분산 분류
분산 = 모드 분산 + 색 분산(재료 분산 + 구조 분산).
04 📶 무선 매체 (Wireless)
1무선 매체 + 주파수 영역
무선 매체 = ?
공기·진공의 전자기파 (비유도 매체)
라디오파 3KHz~1GHz / 마이크로파 1GHz~300GHz / 적외선 300GHz~400THz
💡 핵심 정리
  • 무선 매체: 공기 중의 전자기파를 이용하여 정보를 전달하는 매체 (비유도 매체)
  • 무선 통신(Wireless communication): 무선 매체를 이용한 통신
  • 라디오파: 3KHz ~ 1GHz
  • 마이크로파: 1GHz ~ 300GHz
  • 적외선파: 300GHz ~ 400THz
2주파수에 따른 전파 특성 ★
주파수 특성 ★
높을수록 직진성·초고속 / 낮을수록 회절성·장거리
출력은 진행 거리의 제곱에 반비례
주파수 높을수록
감쇠 심하지만 직진성 강함 → 대량 정보 전송 가능 → 고정 통신·초고속 통신. 안테나 소형 제작 가능.
주파수 낮을수록

▪ 서술형 연습

Q25.UTP·FTP·STP의 차이를 설명하시오.
▸ UTP (Unshielded): 네 쌍 이상의 꼬인 선을 금속 박막 없이 플라스틱 피복으로 감싼 구조. 가격 저렴, 유연하여 설치 쉬움. CAT.5E를 많이 사용.
▸ FTP (Foiled): 접지선과 4쌍의 선을 포일(금속 박막)로 한 번 감싼 다음 외부 피복. UTP보다 우수하지만 제작 어려움. 주로 공장·PC방에서 사용.
▸ STP (Shielded): UTP의 각 쌍을 얇은 금속 박막으로 둘러싼 구조. 초기 LAN에 사용되었으나 가격↑·성능 큰 차이 X·설치 불편으로 UTP로 대체됨.
Q26.광섬유의 3층 구조와 빛이 전달되는 원리를 설명하시오.
▸ 코어(Core): 높은 굴절률의 투명한 덮개로 빛이 통과하는 통로 역할.
▸ 클래딩(Cladding): 코어보다 낮은 굴절률의 투명한 덮개로 코어 외부를 싸고 있으며 빛을 반사. ITU-T 표준 지름 125μm.
▸ 코팅(Coating): 코어와 클래딩을 보호하기 위해 합성수지로 만든 피복.
▸ 원리: 스넬의 법칙에 따라 빛이 코어(고굴절률)에서 클래딩(저굴절률)로 진행할 때, 입사각이 임계각보다 크면 전반사가 일어나 빛이 코어 내부에 갇힌 채 진행한다.
Q27.광섬유의 전파 방식 3가지(계단형·증가형·단일모드)를 비교 설명하시오.
▸ 계단형 다중 모드 (SI): 코어의 밀도가 일정. 여러 광선이 서로 다른 경로로 전파되어 모드 분산이 크게 발생. 수신 특성 가장 떨어짐.
▸ 증가형 다중 모드 (GI): 코어의 밀도가 클래딩 쪽으로 갈수록 연속적으로 감소 → 모드 분산 영향 감소. 계단형보다 우수.
▸ 단일 모드 (SM): 코어 지름 9~10μm로 매우 작아 단일 광선만 전송. 모드 분산이 없어 가장 우수한 수신 특성. 도시와 도시 간 장거리 공중망에 사용.
▸ 수신 특성 순서: 단일 모드 > 증가형 다중 모드 > 계단형 다중 모드.
Q28.광섬유의 장점 5가지를 설명하시오.
① 대역폭이 넓다: 가시광선의 넓은 대역폭을 이용하여 높은 데이터 전송률을 얻는다.
② 신호 감쇠가 낮다: 중계기 없이 50Km까지 신호 전달 가능 (TP·동축은 5Km마다 중계기 필요).
③ 전자기파 간섭에 강하다: 일반 전자기파는 광섬유에 영향을 주지 않는다.
④ 도청에 강하다: 광섬유에 선을 연결하기 매우 어려워 도청에 전문적인 도구와 기술이 필요하다.
⑤ 무게가 가볍다.
(단점: 설치·유지 보수 어려움, 부러지기 쉬움, 레이저 광원 가격이 매우 높음)
Q29.주파수에 따른 전파의 특성을 설명하시오.
▸ 주파수가 높을수록: 감쇠가 심하지만 직진성이 강하므로 대량 정보 전송이 가능해 고정 통신·초고속 통신에 적합. 안테나를 소형으로 제작 가능.
▸ 주파수가 낮을수록: 회절성이 강하고 감쇠는 적으나 전송 가능 정보량이 적어 해상·항공 통신 등 장거리 통신에 적합.
▸ 전파는 진행 거리의 제곱에 반비례해 출력이 감쇠하는 특성도 있다.
Q30.위성 마이크로파의 장단점을 설명하시오.
▸ 장점: ① 매우 높은 곳에서 신호를 전파하여 매우 넓은 영역에 도달 → 다중점 연결 유리. ② C 대역 링크의 대역폭은 500MHz로 매우 넓어 많은 음성 채널 다중화 가능. ③ 거리는 멀지만 대기 통과 거리는 짧아 오류율이 낮다(지상 마이크로파 1×10⁻⁵ → 위성 1×10⁻⁸).
▸ 단점: ① 거리가 멀어 전송 지연이 길다 — 정지궤도(36,000Km)는 상하향 합쳐 약 0.24초 소요. ② 사용 주파수가 높을수록 기후(비·눈)에 의한 감쇠 심해짐. ③ 보안성 떨어지며, 위성 고장 시 수리 어려움.

입사각 > 임계각 → 전반사. n₁sinθ₁ = n₂sinθ₂.
광섬유 구조 ★
코어(고굴절) / 클래딩(저굴절) / 코팅
클래딩 지름 = 125μm (ITU-T 표준), 단일 코어 9~10μm.
전파 방식 수신 특성 ★
단일 > 증가형 > 계단형
단일 모드는 모드 분산 X. 도시 간 장거리에 사용.
광통신 소자 ★
송신 LED/레이저, 수신 PD/APD
단거리=LED, 장거리=레이저(ILD).
분산 크기 ★
모드 > 재료 > 구조
모드 분산은 단일 모드에 없음. 색 분산 = 재료 + 구조.
주파수 영역
라디오 1GHz↓ / 마이크로 1~300GHz / 적외선 ~400THz
라디오파 3KHz부터 시작.
주파수 특성 ★
높을수록 직진성 / 낮을수록 회절성
높은=초고속·안테나 소형 / 낮은=장거리 통신.
전파 방법 3종 ★
지표면 / 전리층 / 가시선
대기 가장 낮은 곳 / 전리층 반사 / 안테나 직선.
라디오 주파수 핵심
MF=AM / VHF=FM·TV / UHF=이동전화
전방향성. 감쇠 적음. 주파수 재사용 가능.
지상 마이크로파
가시선 + 지향성 안테나
접시형·혼 안테나. d = 7.14√(Kh), K=4/3.
위성 마이크로파 ★
1GHz↑ / 상향 > 하향 주파수
정지궤도 36,000Km, 왕복 0.24초.
위성 고도 분류
저궤도 / 중궤도 / 정지궤도
100~1500 / 5000~20000 / 36,000 Km.
적외선파 ★
