01 🔀 다중화와 역다중화
1다중화(Multiplexing)의 개념
한 줄 요약
단일 링크 → 여러 신호 동시
전송 효율을 향상시키는 기술. 링크 1개에 채널 n개.
💡 핵심 정리
  • 다중화 = 단일 링크를 통하여 여러 개의 신호를 동시에 전송하는 기술 (전송 효율 향상)
  • 링크의 전송 용량이 연결된 장치들의 전송량보다 큰 경우 사용
  • 하나의 링크에 여러 개의 채널이 있을 수 있음
    • 링크(Link): 물리적인 경로(Physical path)
    • 채널(Channel): 링크의 한 부분으로 논리적 경로(Logical path)
  • 왼쪽의 n개 장치 → 다중화기(Multiplexer)로 묶어 하나의 링크로 전송 → 다중복구기(Demultiplexer)로 분리
2다중화의 종류 (4가지)
앞글자 암기 ★
FDM · WDM · TDM · CDM
아날로그 / 아날로그(광) / 디지털 / 혼합(아날로그+디지털)
FDM (주파수 분할)
아날로그 신호를 다중화. Frequency Division Multiplexing.
WDM (파장 분할)
아날로그 신호를 다중화. 광통신에 사용. Wavelength Division Multiplexing.
TDM (시분할)
디지털 신호를 다중화. Time Division Multiplexing.
CDM (코드 분할)
FDM과 TDM을 혼합한 방식. 확산 대역(Spread Spectrum)을 이용하여 다중화.
3역다중화 (Inverse Multiplexing)
한 줄 요약
고속 1개 → 저속 여러 개
다중화의 반대 과정. 음성(64Kbps) + 디지털(128Kbps) 등 다른 속도 동시 전송용.
💡 역다중화 핵심
  • 1개의 고속 회선에서 데이터를 받아서 여러 개의 저속 회선으로 나누어 전송
  • 다중화의 반대 과정
  • 서로 다른 데이터 전송 속도를 요구하는 음성(64Kbps)과 디지털 데이터(128Kbps)를 전송하려는 경우, 저속 채널을 여러 개 사용하는 개념
  • 만일 통신 회선 하나가 고장 난다 해도 회선 경로를 변경해서 계속 전송할 수 있다 (장애 복구성)
02 📻 주파수 분할 다중화 (FDM) + 파장 분할 다중화 (WDM)
1FDM (Frequency Division Multiplexing)
FDM 핵심
변조 + 보호 대역
각기 다른 반송파로 변조(Modulation) 후 다중화. 채널 간 간섭 방지용 보호 대역(Guard Band) 필수.
💡 핵심 정리
  • 각기 다른 반송파로 변조(Modulation) → 아날로그 다중화 기술
  • 보호 대역(Guard Band) 필요
    • 반송 주파수들은 변조 신호들을 수용할 수 있도록 서로 떨어져 있음
    • 인접한 채널 간의 간섭을 방지하기 위한 대역
  • 링크의 전송 용량이 연결된 장치들의 전송량보다 큰 경우
  • FDM은 매우 쉽게 구현 가능 — 각기 다른 주파수의 반송파로 변조하면 곧바로 다중화
2FDM 보호 대역 계산 예제
최소 대역폭 = N × 채널폭 + (N−1) × 보호 대역
N개 채널을 다중화할 때 최소 대역폭
📐 예제 7-1
  • 50KHz 대역폭의 5개 채널 + 5KHz 보호 대역 → 5개 채널 간섭 피하려면 최소 4개의 보호 대역 필요
  • 최소 대역폭 = 5 × 50KHz + 4 × 5KHz = 270KHz
3FDM의 사용 예 + 아날로그 계층 구조
앞글자 암기
G · S · M · J
Group → Super group → Master group → Jumbo group (전화회사 채널 분류 단위)
AM 라디오
530KHz ~ 1700KHz 대역. 각 방송국 10KHz 대역폭.
FM 라디오
88MHz ~ 108MHz 대역. 각 방송국 200KHz 대역폭.
아날로그 계층
12채널/4KHz → 그룹(48KHz·12채널) → 슈퍼그룹(240KHz·60채널) → 마스터그룹(2.52MHz·600채널) → 점보그룹(16.984MHz·3,600채널).
왜 FDM이 쉬운가?
각기 다른 주파수의 반송파를 사용하여 변조하면 곧바로 다중화가 된다.
4OFDM (Orthogonal FDM, 직교 주파수 분할 다중화)
OFDM 사용 표준 ★
802.11a · WiMAX · LTE · 5G
IEEE 802.11a · WiMAX(고정 4G) · LTE(모바일 4G) · 5G에서 사용
💡 OFDM 핵심
  • 다수의 주파수에 직각으로 교차하는 신호를 이용하여 다중화하는 방식
  • 직각으로 교차하는 신호는 서로 겹치더라도 수신 측에서 분리할 수 있음
  • 무선 LAN 프로토콜인 IEEE 802.11a, WiMAX(고정 4G), LTE(모바일 4G), 5G에서 사용
5WDM (Wavelength Division Multiplexing, 파장 분할 다중화)
WDM 핵심
광섬유 · 프리즘
광섬유 고속 전송을 위한 아날로그 다중화. 빛 결합·분리는 프리즘이 담당.
💡 핵심 정리
  • 광섬유의 고속 전송을 이용하기 위한 아날로그 다중화 기술
  • 다중화기에서 여러 빛들을 하나의 빛으로 결합하고, 다중복구기를 통하여 역의 동작(분리)을 수행
  • 빛들을 결합하고 분리하는 것은 프리즘에 의해 수행됨
03 ⏱️ 시분할 다중화 (TDM)
1TDM 기본 개념
FDM vs TDM
FDM = 주파수 / TDM = 시간
FDM은 주파수를 공유, TDM은 시간을 공유 (디지털 다중화)
💡 TDM (Time Division Multiplexing)
  • 높은 대역폭을 갖는 링크 하나를 여러 회선이 공유하는 디지털 다중화 방식
  • 주파수 분할 다중화에서는 주파수를 공유하지만, 시분할 다중화에서는 시간을 공유한다
  • 분류: 동기 TDM (STDM) / 비동기 TDM
2동기 시분할 다중화 (Synchronous TDM, STDM)
동기 TDM 키워드
고정 슬롯 · 빈 슬롯 낭비
각 장치에 고정 타임 슬롯 할당 → 데이터 안 보내면 슬롯 낭비
동기 TDM 정의
각 장치에 대해 고정적인 타임 슬롯(Time slot)을 할당하는 방식.
프레임 구성
한 프레임은 각 장치에 할당된 타임 슬롯들 + 프레임 구분 비트로 구성.
단점 (슬롯 낭비)
장치가 데이터를 보내지 않으면 해당 시간 슬롯은 낭비됨.
인터리빙 (Interleaving)
동기 TDM은 고속으로 동작하는 스위치에 비유. 비트 삽입식(Bit interleaving)과 문자 삽입식(Character interleaving)으로 분류.
3프레임 구성 비트 + 비트 채우기
동기화 패턴
10101
0과 1을 교대로 매 프레임에 하나씩 추가하여 프레임을 구분
💡 프레임 구성 비트(Framing bit)
  • 프레임을 구분하기 위한 동기화 정보
  • 0과 1을 교대로 매 프레임에 하나씩 추가 → 동기화 패턴 10101...
💡 비트 채우기 (Bit stuffing)
  • 각 장치의 전송속도가 다른 경우, 고속 장치에 더 많은 시간 슬롯을 할당
  • 각 장치의 데이터 전송 속도가 정수배가 되지 않는 경우, 정수배로 만들기 위해 여분의 비트를 채워 넣는 것
  • 예) 다른 장치 대비 2.5배 전송률을 요구하는 장치에 3개 슬롯 할당하면 부족한 0.5개에는 여분의 비트를 채워 전송
전송 효율 = 순수 데이터 / (순수 데이터 + 오버헤드) × 100
예) 4 장치 × 1문자 × 8비트 + 1 프레임 비트 = 33비트, 250프레임/초 → 8,250 bps 중 8,000 bps 데이터 → 97.0%
4비동기 시분할 다중화 (Asynchronous TDM)
비동기 TDM 별칭 ★
통계적 = 지능적 = 비동기
Statistical TDM = Intelligent TDM = Asynchronous TDM (모두 같은 것)
💡 비동기 TDM 핵심
  • 실제 보낼 데이터가 있는 장치에게만 시간 슬롯을 배정 (시간 슬롯을 동적으로 할당)
  • 프레임은 장치의 수 n보다 적은 시간 슬롯 m을 가질 수도 있음 (n ≥ m)
  • 비동기 TDM = 통계적 TDM(Statistical TDM) = 지능적 TDM(Intelligent TDM)
💡 주소 지정과 오버헤드
  • 비동기 TDM은 입력과 출력이 고정되어 있지 않으므로 수신 주소를 타임 슬롯에 삽입
  • 입력이 n개인 경우, N = log₂n 개 비트를 주소로 사용
  • 주소는 다중화기에 의해 부착되고 다중복구기에 의해 제거
  • 동기 TDM에 비하여 오버헤드가 증가됨
💡 가변 길이 시간 슬롯 (Variable length Time Slot)
  • 빠른 속도로 데이터를 전송하는 장치에는 더 긴 시간 슬롯을 배정
  • 모든 시간 슬롯 앞에 데이터의 길이를 알려주는 제어비트가 필요
5디지털 계층 구조 (DS, T, E)
DS-0 기본 단위
64Kbps · 표본화 8000회 · 8비트
125μs(=1/8000)마다 8비트 측정값 → 64Kbps
💡 디지털 신호(DS) 0~4 구성

  • 64Kbps × 96 + 168Kbps = 6.312Mbps
  • 64Kbps × 672 + 1728Kbps = 44.736Mbps
  • 64Kbps × 4032 + 16128Kbps = 274.176Mbps

04 📡 코드 분할 다중화 (CDM)
1CDM 기본 개념
CDM 한 줄 요약
FDM + TDM 혼합 / 직교 코드
서로 다른 코드(언어)를 부여 → 군사 통신·위성 통신(보안 + 잡음 대처)
💡 CDM 핵심
  • 모든 사람이 같은 장소에서 서로 다른 언어를 사용하여 이야기하는 것에 비유
  • 각 사용자에게 서로 다른 코드(언어)를 부여하여 신호와 코드를 곱해서 전송, 수신 시 송신과 동일한 코드를 곱해 원래 신호를 복구
  • FDM과 TDM의 혼합 다중화 방식
  • 각 사용자에게 할당되는 코드는 상호 직교 관계(Orthogonal)에 있어 서로 영향을 미치지 않음
  • 활용: 군사 통신, 위성 통신 (보안 + 잡음 대처)
cᵢ(t) × cⱼ(t) = 0 (i ≠ j) / cᵢ(t) × cⱼ(t) = 1 (i = j)
코드의 직교 관계: 다른 코드 곱 = 0, 같은 코드 곱 = 1
2스펙트럼 확산 (Spread Spectrum)
스펙트럼 확산 = ?
신호 → 넓은 대역으로 확산
전송하려는 신호를 그 주파수 대역보다 훨씬 넓은 대역으로 확산 → 잡음에 강해짐
💡 핵심 정리
  • 코드 분할 다중화는 대역 확산(Spread spectrum)을 이용
  • 전송하려는 신호를 그 주파수 대역보다 훨씬 넓은 주파수 대역으로 확산시켜 전송
  • 넓은 주파수 대역에서 다수 사용자가 서로 다른 코드를 사용 → 동일 주파수로 동시에 접속 가능
  • 대역 확산 기술을 사용하면 잡음에 강해진다
3스펙트럼 확산 2종 (FHSS / DSSS)
현재 주류 ★
FHSS → DSSS
초기에는 FHSS, 현재는 반도체 소자 고속화로 DSSS가 주로 사용
FHSS (주파수 도약)
Frequency Hopping Spread Spectrum. 시간을 홉 주기(Hopping period)로 나누고, 홉 주기에 따라 다른 반송 주파수로 변조해 전송. 도약 패턴은 슈도랜덤 코드 발생기의 난수 알고리즘으로 결정.
DSSS (직접 순열 대역 확산)
Direct Sequence Spread Spectrum. 칩(Chip)이라는 n비트 코드를 데이터의 각 비트에 곱해 비트율을 n배 증가 → 대역폭도 n배 확산. 무선 LAN에서 사용하는 바커 순열(Barker Sequence) n=11이 대표 예.
FHSS vs DSSS 결론
초기에는 FHSS가 많이 사용되었으나, 현재는 DSSS가 주로 사용됨 (반도체 소자 고속화).
DSSS 코드 검증
수신된 확산 신호에 송신 시와 동일한 확산 코드를 곱해야 원래 데이터 복구 가능. 다른 코드를 곱하면 복구 X.
4다중화 기술 적용 예 (요약 표)

05 🌐 SONET / SDH
1SONET / SDH 정의
국가 표준 vs 국제 표준 ★
SONET = ANSI / SDH = ITU-T
SONET(미국 ANSI 국가 표준) → SDH(ITU-T 국제 표준)로 발전
💡 핵심 정리
  • 광통신을 위한 디지털 신호의 동기 다중화 계층과 속도 체계, 인터페이스를 정의한 표준
  • SONET (Synchronous Optical Network): ANSI 미국 표준의 동기식 광전송 시스템을 위한 접속 규격
  • SDH (Synchronous Digital Hierarchy): ITU-T 국제 표준. 광 기반으로 미국이 개발한 국제 표준

2SONET 물리적 구성 (3가지 장비)
앞글자 암기
STS · ADM · 재생기
STS 다중화기(전→광 + 다중화) / 추가삭제 다중화기(ADM) / 재생기(Repeater)
💡 3가지 장비
  • STS 다중화기: 전기 신호를 광 신호로 변환하는 기능 + 들어온 신호를 다중화하는 역할
  • 재생기 (Repeater): 수신된 광 신호를 재생하는 리피터 역할
  • 추가/삭제 다중화기 (ADM): 다른 발신지에서 들어온 신호를 한 경로에 추가하거나 요구받은 신호를 경로에서 삭제
  • SONET 연결의 3가지 계층: 구간(Section), 회선(Line), 경로(Path)
3SONET 계층 구조
앞글자 암기 ★
광 · 구 · 회 · 경
광학 계층 → 구간 계층 → 회선 계층 → 경로 계층 (4계층)
광학 계층 (1)
신호는 NRZ 부호화를 이용. 빛이 있으면 1, 빛이 없으면 0.
구간 계층 (2)
프레임 구성, 스크램블링, 오류 제어를 처리.
회선 계층 (3)
STS 다중화기와 추가/삭제 다중화기(ADM)가 회선 계층 기능을 제공.
경로 계층 (4)
종단 발신지에서 종단 목적지까지 신호 전달을 담당. STS 다중화기가 경로 계층 기능을 제공.
🔗 SONET 장비와 계층의 관계
  • STS 다중화기 = 4계층 장치 (경로까지 모두)
  • 추가/삭제 다중화기(ADM) = 3계층 장치 (회선까지)
  • 재생기 = 2계층 장치 (구간까지)
4SONET 프레임 구조
STS-1 프레임 ★
9행 × 90바이트 = 810바이트
STS-1 신호는 초당 8,000개 프레임 전송 → 음성 디지털화 비율과 동일
💡 STS-1 / STS-3 프레임
  • STS-1 프레임: 810바이트 (= 9행 × 90바이트)
  • STS-3 프레임: 2,430바이트 (= 9행 × 270바이트)
  • STS-1 신호는 초당 8,000개 프레임을 전송 → 음성이 디지털화되는 비율과 같음
STS-1: 8000 × 9 × 90 × 8 = 51.84 Mbps
초당 프레임 × 행 × 열 × 비트
STS-3: 8000 × 9 × (90 × 3) × 8 = 155.52 Mbps
STS-3 = STS-1 3개를 다중화 = STM-1과 동일
💡 STS-1 프레임 오버헤드 (3종)
  • 구간 오버헤드(Section Overhead)
  • 회선 오버헤드(Line Overhead)
  • 경로 오버헤드(Path Overhead)
  • 프레임 전송 순서: 왼쪽 → 오른쪽, 맨 위쪽 → 맨 아래쪽, MSB → LSB 순으로
  • 사용자 데이터 전송률(STS-1): 774 × 8 × 8000 = 49.536 Mbps
💡 STM-1 프레임 (SDH)
  • SDH의 STM-1 프레임의 전체 구조는 SONET의 STS-3과 유사 (세부적인 면에서 차이 있음)
  • 구성: 재생기 구간 오버헤드, AU 포인터, 다중화 구간 오버헤드, 경로 오버헤드, 사용자 데이터(페이로드), 관리 유닛(AU)

▪ 단답형

Q15.50KHz 대역폭의 채널 5개를 5KHz 보호 대역으로 FDM 다중화할 때, 전송에 필요한 최소 대역폭은?
270 KHz — 5개 채널 간섭 피하려면 최소 4개의 보호 대역 필요. 5 × 50KHz + 4 × 5KHz = 270KHz.
Q16.비동기 TDM에서 입력이 16개일 때 주소 지정에 필요한 비트 수는?
4비트 — 입력이 n개인 경우 N = log₂n 비트가 필요. log₂16 = 4.
Q17.4개 장치가 1문자(8비트)씩 인터리빙하고 초당 250 프레임을 전송할 때 한 프레임의 비트 수는? (프레임 비트 1개 포함)
33비트 — 4 × 8 + 1 = 33 비트. 초당 250 프레임 전송 시 250 × 33 = 8,250 bps. 전송 효율 = 8,000 / 8,250 ≈ 97.0%.
Q18.T-1 프레임 1개의 비트 수는?
193 비트 — 24 타임 슬롯 × 8 비트 + 1 프레임 동기 비트 = 193 비트. 125μs 단위 → 1.544 Mbps.
Q19.SONET STS-1의 전송 속도는? (Mbps)
51.84 Mbps — STS-1 프레임 = 9행 × 90바이트 = 810바이트, 초당 8,000 프레임 → 8000 × 9 × 90 × 8 = 51.84 Mbps.

▪ 서술형 연습

Q20.다중화의 4가지 종류를 신호의 종류와 함께 설명하시오.
① FDM (주파수 분할): 아날로그 신호 다중화. 각기 다른 반송파로 변조하여 다중화하며, 보호 대역(Guard Band)이 필요하다.
② WDM (파장 분할): 아날로그 신호 다중화. 광통신에 사용되며, 프리즘으로 빛을 결합·분리한다.
③ TDM (시분할): 디지털 신호 다중화. 시간을 공유하는 방식이며 동기/비동기로 분류된다.
④ CDM (코드 분할): FDM과 TDM을 혼합한 방식. 확산 대역(Spread Spectrum)을 이용하며 직교 코드로 다중화한다.
Q21.동기 TDM과 비동기 TDM을 비교 설명하시오.
▸ 동기 TDM (STDM): 각 장치에 고정적인 타임 슬롯을 할당. 한 프레임은 각 장치에 할당된 슬롯 + 프레임 구분 비트로 구성. 장치가 데이터를 보내지 않으면 슬롯이 낭비되는 단점.
▸ 비동기 TDM: 실제 보낼 데이터가 있는 장치에만 시간 슬롯을 동적으로 배정 (n ≥ m). 입력과 출력이 고정되어 있지 않으므로 수신 주소를 타임 슬롯에 삽입해야 하므로 동기 TDM보다 오버헤드가 증가. 통계적 TDM = 지능적 TDM이라고도 함.
Q22.스펙트럼 확산 방식 2가지(FHSS, DSSS)를 비교 설명하시오.
▸ FHSS (주파수 도약): 시간을 홉 주기로 나누고, 홉 주기에 따라 이전과 다른 반송 주파수를 사용해 데이터를 변조해서 전송. 도약 패턴은 슈도랜덤 코드 발생기의 난수 알고리즘에 의해 결정.
▸ DSSS (직접 순열 대역 확산): 칩(Chip)이라는 n비트 코드를 데이터의 각 비트에 곱해 비트율을 n배 증가시켜 변조하므로 신호 대역폭도 n배 확산. 무선 LAN의 바커 순열(n=11) 등이 대표 예.
▸ 결론: 초기에는 FHSS가 많이 사용되었으나, 현재는 반도체 소자의 고속화에 따라 DSSS가 주로 사용됨.
Q23.SONET의 4계층 구조를 설명하시오.
① 광학 계층: 신호는 NRZ 부호화를 이용. 빛이 있으면 1, 빛이 없으면 0.
② 구간 계층: 프레임 구성, 스크램블링, 오류 제어를 처리.
③ 회선 계층: STS 다중화기와 추가/삭제 다중화기(ADM)가 회선 계층 기능을 제공.
④ 경로 계층: 종단 발신지에서 종단 목적지까지 신호 전달을 담당. STS 다중화기가 경로 계층 기능을 제공.
장비별 처리 계층: STS 다중화기 = 4계층 / ADM = 3계층 / 재생기 = 2계층.
