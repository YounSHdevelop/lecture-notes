1데이터통신 정의
Q. 데이터(Data)란?
현실 세계에서 단순한 관찰 또는 측정을 통해 수집한 사실이나 값을 문자, 숫자, 기호 등으로 표현한 것
Q. 정보(Information)란?
데이터를 가공·처리하여 가치와 의미를 부여한 것
Q. 통신이란?
두 사람(장치) 이상의 정보 공유를 위해 정해진 규칙(프로토콜)에 따라 한 지점에서 다른 지점으로 정보를 전달하는 과정
Q. 데이터통신 정의 ⭐
컴퓨터 같이 통신 기능이 있는 둘 이상의 통신 장치 사이에서 전송 매체를 통하여 정해진 규칙에 따라 데이터로 표현된 정보를 교환하는 과정

공식: 데이터 통신 = 데이터 처리 + 데이터 전송
Q. 데이터 통신 네트워크란?
지리적으로 분산된 여러 정보원에 정보를 전송하고 이를 공유하기 위해서 설계된 상호 연결 시스템
= 컴퓨터 네트워크 = 네트워크
2데이터통신 시스템 구성요소 5가지 ⭐⭐⭐
앞글자 암기법
송 · 수 · 전 · 메 · 프
송신자 · 수신자 · 전송매체 · 메시지 · 프로토콜
  1. 송신자 (Sender) — 데이터를 보내는 장치 (컴퓨터, 전화기)
  2. 수신자 (Receiver) — 데이터를 받는 장치
  3. 전송매체 (Medium) — 데이터가 이동하는 물리적 통로 (꼬임쌍선·동축·광섬유·무선)
  4. 메시지 (Message) — 전달하려는 데이터 (텍스트·숫자·이미지·오디오·비디오)
  5. 프로토콜 (Protocol) — 데이터 통신을 지배하는 규칙의 집합
3프로토콜 정의 + 3가지 구성요소 ⭐⭐⭐
프로토콜 (Protocol) 정의
Protocol: 의정서, 조서를 의미하는 외교상의 용어
통신 프로토콜: 통신을 위한 약속들의 집합
앞글자 암기법
구 · 의 · 타
구문(Syntax) · 의미(Semantics) · 타이밍(Timing)
  1. 구문 (Syntax) — "무엇을?"
    문법, 데이터의 구조나 형식
    데이터가 어떤 순서로 표현되는지를 의미, 순서에 따라 의미가 다름
  2. 의미 (Semantics) — "어떻게?"
    데이터의 의미, 뜻
    특정 패턴은 어떻게 해석되며, 그 해석에 따라 어떤 동작을 취할 것인가에 해당
  3. 타이밍 (Timing) — "언제?"
    언제 데이터를 전송할 것인가와 어느 정도의 속도로 전송할 것인가의 두 가지 특성을 가리킴
    예) 송신기는 100Mbps로 전송, 수신기는 10Mbps로 처리하는 경우?
4OSI 7계층 나열 ⭐⭐⭐
OSI 참조 모델이란?
1984년 ISO(국제표준화기구)가 제정한 네트워크 통신의 7계층 표준 모델. 서로 다른 시스템 간 상호 연결을 위한 참조 모델(Reference Model). TCP/IP 구조와 비교.
🔹 계층화 구조
  • 하나의 일을 수행하기 위해 관련 기능들을 모아서 그룹화한 계층화의 개념으로 구성
  • 각 계층은 인접한 하위 계층의 서비스를 이용하고, 바로 위 계층에 서비스를 제공
  • 다른 계층에 영향을 주지 않고 어떤 한 계층의 구조를 변경하거나 대체할 수 있음
  • 중간 노드들은 3계층까지 동작
  • 대등-대-대등 프로세스(Peer-to-Peer process) — 각 계층 프로토콜은 동일 계층 사이에 존재
  • 인터페이스(Interface): 동일한 장치 내에서 다른 계층과 상호 작용하는 것

5OSI 7계층 계층별 세부 설명 ⭐⭐⭐
🔹 1계층 · 물리 계층 (Physical Layer)
한줄 요약: 물리적인 전송로를 제공, 비트를 전송매체를 통해 전달
  • 4가지 특성:
    • 기계적 특성: DTE와 DCE 사이의 물리적인 연결에 관한 사항
    • 전기적 특성: 신호 형식·전송 방식·부호화 방식·변조 방식·신호의 전압 레벨·신호의 타이밍 등을 규정
    • 기능적 특성: 인터페이스의 각 핀이 수행하는 기능을 규정
    • 절차적 특성: 데이터를 교환할 때 일련의 절차를 규정
  • 주요 기능: 인터페이스·비트의 표현·데이터 속도·비트의 동기화·회선 구성·접속 형태·데이터 전송 방식
  • 처리 단위: 비트(Bit)
  • 주요 프로토콜: ITU-T V.21, V.22, V.29, X.21, X.21bis / EIA RS232C, RS-442, RS-449
🔹 2계층 · 데이터링크 계층 (Data Link Layer)
한줄 요약: 인접 노드(링크) 간 프레임 전달 (node-to-node frame delivery)
  • 인접하는 두 노드(컴퓨터, 라우터 등)를 직접 연결하는 링크 상에서 프레임 전달을 담당
  • Hop-by-hop 또는 Node-by-node 전송
  • 주요 기능:
    • 프레임 구성: 네트워크 계층으로부터 받은 비트 스트림을 일정한 길이로 분할
    • 주소 지정: 송신자와 수신자의 물리 주소를 프레임 헤더에 추가
    • 흐름 제어: 송수신 시스템의 처리 속도가 다를 때 수신 측의 데이터 처리 능력을 넘어서지 않도록 조절 (Stop-and-wait & Sliding window 방식)
    • 오류 제어: 에러가 발생한 프레임을 검출, 복구. 흐름 제어와 결합되어 구현
    • 접근 제어: 특정 순간에 어떤 장치가 매체를 사용할 것인지를 결정
    • 동기화: 각 프레임의 시작과 끝을 정확하게 수신 측에 알림
  • 처리 단위: 프레임(Frame) — 헤더 + 데이터 + 트레일러
  • 주요 프로토콜: HDLC, BSC, PPP, LLC
🔹 3계층 · 네트워크 계층 (Network Layer)
한줄 요약: 패킷을 발신지로부터 여러 네트워크(링크)를 경유하여 목적지까지 전달 (host-to-host packet delivery)
  • 종단 간 전달(End-to-end delivery): 호스트↔호스트
  • 송신 측의 네트워크 계층은 전송 계층에서 전달받은 데이터를 패킷(데이터+헤더)으로 구성하여 데이터링크 계층으로 내려 보낸다
  • 주요 기능:
    • 패킷 전달: 발신지에서 목적지까지 패킷을 전달
    • 논리 주소 지정: 발신지와 목적지의 논리 주소를 헤더에 추가. 논리 주소는 전송 도중 바뀌지 않음
    • 라우팅(경로 배정): 데이터가 전송될 수 있는 가장 적절한 전송 경로를 선택
    • 다중화: 하나의 데이터 회선을 사용하여 동시에 많은 데이터 전송을 수행
    • 폭주 제어: 네트워크로 일시적인 과도한 패킷의 유입으로 인한 폭주를 제어 (병목현상)
  • 2계층이 hop-by-hop이라면, 3계층은 End-to-end
  • 처리 단위: 패킷(Packet) / 데이터그램(Datagram)
  • 주요 프로토콜: ITU-T X.25, TCP/IP의 IP
🔹 4계층 · 전송 계층 (Transport Layer)
한줄 요약: 프로세스-대-프로세스(Process-to-process) 전달 제공
  • 전체 메시지를 출발지 응용 프로그램(Source process)에서 목적지 응용 프로그램(Destination process)까지 전달
  • End-to-end(종단간) delivery
  • 전송 계층의 헤더에는 포트 주소(Port address) 또는 소켓 주소가 들어 있다
  • 포트 주소로 인해 송신 측의 데이터가 수신 측의 해당 프로세스로 정확하게 전달
  • 주요 기능: 종단 간 오류 제어, 흐름 제어, 전송 제어
  • 처리 단위: 세그먼트(Segment)
🔹 5계층 · 세션 계층 (Session Layer)
한줄 요약: 특정 프로세스들 사이에서 세션(Session)이라는 가상 연결을 확립·유지·동기화
  • 프로세스는 사용자의 실제 응용 프로그램
  • 주요 기능:
    • 세션 관리: 프로세스 간의 세션을 연결하고 관리
    • 대화 제어: 반이중(Half-duplex, 무전기) 또는 전이중(Full-duplex, 전화) 대화 등을 결정
    • 동기화: 데이터 단위를 전송 계층으로 전송하기 위한 순서를 결정, 데이터의 중간 점검 및 동기점 제공
  • 동기점을 두는 이유: 긴 파일 전송 중 통신 상태가 불량하여 연결이 끊어질 때, 동기점이 있으면 처음부터 다시 전송하지 않고도 오류를 효과적으로 복구
🔹 6계층 · 표현 계층 (Presentation Layer)
한줄 요약: 데이터 표현의 차이를 극복 → 번역·암호화·압축 수행
  • 주요 기능 4가지:
    • 변환: 발신지에서는 송신자가 사용하는 메시지의 형식을 상호간에 수용할 수 있는 형식으로 변환. 목적지에서는 수신자가 이해할 수 있는 형식으로 변환 (ASCII↔EBCDIC)
    • 암호화: 암호화와 복호화를 통하여 데이터의 보안성 제공
    • 압축: 효율적인 전송을 위해 데이터를 압축하거나 압축해제
    • 보안: 패스워드와 로그인 코드를 이용해 보안 기능을 수행
  • 암호 방식 (HTTPS 하이브리드):
    • 평문(Plain text): 암호를 이용하여 보호해야 할 메시지
    • 암호문(Cipher text): 평문을 암호학적 방법으로 변환한 것
    • 암호화(Encryption): 평문을 암호문으로 변환
    • 복호화(Decryption): 암호문을 다시 평문으로 변환
    • 대칭키 방식: 계산 속도 빠름. DES, AES, SEED
    • 비대칭키(공개키) 방식: Public key cryptography. A와 B는 공개키와 개인키를 각각 생성. 공개키로 암호화된 데이터는 개인키로만 복호화. RSA
  • 데이터 압축:
    • 무손실 압축: 실행 길이 부호화(Run-length coding), 허프만 부호화, LZ 알고리즘
    • 손실 압축: JPEG, MPEG, DVI
    • JPEG(Joint Picture Experts Group): 정지 화상 압축 표준
    • H.261: 동영상 비디오 압축과 부호화 기법에 대한 표준
    • MPEG(Moving Picture Experts Group): 동영상 압축 표준
    • MHEG: 분산 환경 하에서 멀티미디어/하이퍼미디어 정보의 상호 교환 표준
🔹 7계층 · 응용 계층 (Application Layer)
한줄 요약: 응용 프로세스가 네트워크 환경에 접근하는 수단을 제공
  • 사용자가 네트워크에 접속하는 것을 가능하게 하고, 사용자 인터페이스를 제공
  • 파일 전송이나 이메일 같은 종단 사용자(end user) 서비스 제공
  • 응용 프로세스들이 상호간에 유용한 정보 교환 가능
  • 범용 응용 서비스:
    • X.400: 메시지 처리를 담당하는 서비스로 주로 전자 우편에 관한 표준
    • X.500: 전자적인 디렉토리로 개발하기 위한 표준 방식
    • FTAM: 파일에 접근, 생성, 삭제 등의 관리
  • 주요 기능:
    • NVT (Network Virtual Terminal): 사용자가 원격 시스템으로 로그인 가능
    • FTAM (File Transfer, Access, and Management): 원격 시스템에서 다른 시스템의 파일에 접근 및 전송
    • 우편 서비스: 전자 우편(E-mail) 사용에 필요한 메일 전송 및 저장 기능 제공
    • 디렉토리 서비스: 분산 데이터베이스의 자원들과 다양한 객체와 서비스 모델에 대한 정보 접근 방법 제공
6캡슐화 · SDU · PDU ⭐
🔹 SDU (Service Data Unit)
  • 상위 계층과 하위 계층 간의 인터페이스를 통해 전달되는 실제 정보
🔹 PDU (Protocol Data Unit)
  • 동일 계층 간에 운반(교환)되는 데이터
  • 공식: PDU = SDU + 헤더
  • 관계: PDU(N) = SDU(N) + PCI(N), 그리고 SDU(N-1) = PDU(N)
🔹 캡슐화 (Encapsulation)
  • 전송 데이터에 각 계층에서의 요구 조건과 처리 정보를 포함하는 헤더(Header)라는 고유의 제어 정보를 전달 메시지에 추가하여 다음 계층으로 보내는 과정
  • 2계층에서는 오류제어를 위한 트레일러(Trailer)도 붙임
⭐ 헤더 vs 트레일러 — 어디서 추가되는가?
  • 헤더(Header): 모든 계층에서 추가 (상위 계층 데이터 앞에 붙임)
  • 트레일러(Trailer): 2계층(데이터링크)에서만 추가 (데이터 뒤에 붙임)
🔹 송신 시 캡슐화 과정 (위→아래)
  • 7계층(응용) → 데이터 생성
  • 6계층 → [6헤더 + 데이터]
  • 5계층 → [5헤더 + 6헤더 + 데이터]
  • 4계층 → [4헤더 + ... + 데이터] = 세그먼트
  • 3계층 → [3헤더 + 세그먼트] = 패킷
  • 2계층 → [2헤더 + 패킷 + 트레일러] = 프레임 ← 트레일러 추가!
  • 1계층 → 비트로 변환되어 전송매체로 전송
💡 한줄 정리
각 계층은 상위에서 받은 SDU에 헤더를 붙여 PDU를 만들고, 이를 다시 하위 계층의 SDU로 전달한다. 트레일러는 2계층에서만 추가된다.

1아날로그 신호 vs 디지털 신호
아날로그 데이터/신호
연속적인 값. 음성·영상·오디오·비디오. 무한히 많은 값을 가짐.
디지털 데이터/신호
이산적인 값. 0과 1. 유한한 수의 값만 가짐.
주기 vs 비주기 신호
주기 신호: 일정 시간마다 반복 (사이클)
비주기 신호: 반복되지 않음
사인파 3요소
s(t) = A sin(2πft + φ) — 진폭(A)·주파수(f)·위상(φ)
2대역폭·비트율·주기·주파수
  • 대역폭 (Bandwidth) = 최고 주파수 − 최저 주파수 (Hz)
  • 예) 1000Hz~5000Hz → 대역폭 = 4000Hz
  • 유효 대역폭 (전화): 300~3300Hz → 3000Hz
  • 주기 T = 1/f, 주파수 f = 1/T
  • 비트율: 1초당 전송 비트 수 (bps)
  • 비트 간격: 1비트 전송 시간. 8bps → 1/8 = 0.125초
3채널 용량 공식 ⭐⭐
나이퀴스트: C = 2W log₂L
잡음 없는 환경. W=대역폭(Hz), L=신호 레벨 수
나이퀴스트 예제
  • W=1KHz, L=8 → C = 2×1000×log₂8 = 2000×3 = 6Kbps
  • W=400Hz, C=3200bps → 3200=800×log₂L → L = 16
샤논: C = W log₂(1 + S/N)
잡음 있는 환경. S/N=신호대잡음비
SNR(dB) = 10 log₁₀(S/N)
20dB→S/N=100, 30dB→S/N=1000
샤논 예제
  • W=3KHz, SNR=30dB → S/N=1000
  • C = 3000 × log₂(1001) ≈ 3000×9.967 ≈ 29.9Kbps
dB = 10 log₁₀(P₂/P₁)
전력비. 전압·전류는 20 log₁₀(V₂/V₁)
4전송 장애 3가지 ⭐
앞글자 암기법
감 · 왜 · 잡
감쇠 · 왜곡 · 잡음
① 감쇠 (Attenuation)
신호의 크기가 거리에 따라 작아지는 현상
유선 매체: 신호의 세기가 거리에 따라 처음에는 급격하게, 점차 완만하게 감소
무선 매체: 자유공간에서 손실 L은 거리의 제곱에 비례
→ 증폭기(아날로그) / 리피터(디지털)로 보상
예) P₂=0.5P₁ → -3dB
② 왜곡 (Distortion)
신호의 모양이나 형태가 변형되는 것
감쇠 왜곡: 주파수 스펙트럼에 따라 감쇠의 정도가 균일하지 못해 발생하는 신호의 변형. 디지털 신호에 비해 아날로그 신호에서 심각
지연 왜곡: 전송매체를 통한 신호의 전달 속도가 주파수에 따라 변하는 현상. 디지털 신호에서 심각
→ 등화기(Equalizer): 주파수 대역별로 다른 증폭을 수행하는 장치
③ 잡음 (Noise) — 종류
잡음: 신호를 전송하는 과정에서 발생하는 원하지 않는 신호
- 열잡음: 전도체 내부의 전자들이 열에 의해 불규칙하게 움직이면서 나타나는 잡음. 모든 주파수 범위에 대해 균일한 전력 스펙트럼. 백색잡음(White noise). N=KTW. 제거 불가
- 상호 변조 잡음: 동일한 전송 매체에서 서로 다른 주파수로 구성되는 신호들이 전송될 때 주파수의 합, 차 또는 배수에 해당하는 새로운 주파수가 만들어져 나타남. 통신 시스템의 선형성이 불완전하기 때문에 발생
- 누화(Crosstalk): 인접 회선 간 신호 간섭
- 충격 잡음: 번개·전원장애. 디지털 데이터에 큰 영향

6PCM 3단계 ⭐⭐⭐
아날로그 → 디지털 (PCM)
표 · 양 · 부
표본화(Sampling) · 양자화(Quantization) · 부호화(Encoding)
송신부: 표본화 → 양자화 → 부호화 → PAM 펄스
  1. ① 표본화 (Sampling)
    아날로그 신호에서 일정한 주기의 불연속적인 진폭을 갖는 PAM 펄스를 얻는 과정
    표본화 정리: 아날로그 신호에 포함된 최고 주파수를 f_m이라 할 때 적어도 1/2 f_m 의 주기(T_s)로 표본을 추출하면 추출된 데이터로부터 원래의 신호를 재생할 수 있다
    T_s ≤ 1/(2f_m), f_s ≥ 2f_m
  2. ② 양자화 (Quantization)
    펄스의 진폭 크기를 디지털 양으로 변환하는 것
    양자화 잡음(Quantization noise) 또는 양자화 오차(Quantization error)가 발생
    양자화 레벨 수(분해능, Resolution)를 늘리면 레벨 간의 간격이 좁아져 양자화 잡음이 감소 → 양자화 레벨 수가 많아지면 데이터 양이 많아진다는 단점
    SNR(dB) = 6.02n_b + 1.76 dB
    양자화 잡음을 줄이기 위해 비선형 양자화(Non-linear quantization)를 이용
  3. ③ 부호화 (Encoding)
    양자화한 값을 2진 디지털 부호로 변환하는 과정
    레벨 수 8 → 3비트(2³=8), 16 → 4비트(2⁴=16), 128 → 7비트(2⁷=128), 256 → 8비트(2⁸=256)
수신부: 재생 → 복호화 → 필터링
  • 송신부의 역순으로 아날로그 데이터를 복원
PCM 계산 예제
  • 음성(4KHz), 양자화 레벨 128개
  • → 표본화 주파수 = 2×4000 = 8KHz
  • → 2⁷=128 → 7비트
  • → 비트율 = 8000 × 7 = 56Kbps
7델타 변조 (DM)
델타 변조
PCM 간소화. 이전 표본과의 차이(증가/감소)만 1비트로 부호화.
- 경사 과부하 잡음: 급변을 못 따라감
- 입자 잡음: 변화 없을 때 불필요한 변동
8디지털 변조 4가지 ⭐⭐⭐
디지털 → 아날로그
A · F · P · Q
ASK · FSK · PSK · QAM
무엇을 변화시키는가?
  • ASK → 진폭(Amplitude) 변화
  • FSK → 주파수(Frequency) 변화
  • PSK → 위상(Phase) 변화
  • QAM → 진폭+위상 둘 다 변화
ASK (진폭 편이 변조)
반송파의 진폭을 변화시키는 방식. 이때 주파수와 위상은 변하지 않는다.
회로 구성이 간단하지만 잡음에 약함.
1일 때 A sin 2πf_c t, 0일 때 0 → OOK(On-Off Keying)
FSK (주파수 편이 변조)
반송파의 주파수를 변화시키는 방식. 이때 진폭과 위상은 변하지 않는다.
ASK보다 잡음에 강하고, 회로도 비교적 간단하기 때문에 많이 사용됨.
1일 때 f_c1, 0일 때 f_c0
PSK (위상 편이 변조)
반송파의 위상을 변화시키는 방식. 이때 진폭과 주파수는 변하지 않는다.
BPSK(2진 PSK): 1일 때 0°, 0일 때 180° → 1비트
QPSK(4진 PSK): 00=-135°, 01=135°, 10=-45°, 11=45° → 2비트/신호
QAM (직교 진폭 변조)
ASK와 PSK를 혼합한 형태. 진폭과 위상을 동시에 변화.
s_i(t) = A_i sin(2πf_c t + φ_i)
이동통신(5G, LTE), Wi-Fi(6/7), 위성 통신 등 고속 데이터 전송에 사용
보 레이트 vs 비트 레이트
  • 비트율(bps) = 1초당 비트 수
  • 보 레이트(Baud) = 1초당 신호 변화 수
  • 비트율 = n × 보 레이트 (n=한 신호당 비트 수)
  • 예) QPSK, 2400baud → 비트율 = 2×2400 = 4800bps
9회선 부호화 (디지털→디지털)
단극성 (Unipolar)
한 방향 전압만 사용. DC 성분 발생, 동기화 문제
NRZ (Non-Return to Zero)
0과 1을 (+)·(-)로. NRZ-L(레벨), NRZ-I(반전).
같은 비트 연속 시 동기화 문제
RZ (Return to Zero)
0=(-)→0, 1=(+)→0. 비트 중간에 항상 0으로.
NRZ보다 대역폭 2배 필요
맨체스터 / 차동 맨체스터
맨체스터: 비트 중간 전이. LAN(CSMA/CD·이더넷)
차동 맨체스터: 토큰링
AMI (Bipolar)
(+)·(-)·0 세 레벨. 1은 +/-교대, 0은 0V
0 연속 시 동기화 문제 → 스크램블링
B8ZS / HDB3
B8ZS: T-1에서 0이 8개 연속 시 특수패턴
HDB3: E-1에서 0이 4개 연속 시 특수패턴
4B/5B
4비트 → 5비트 (NRZ-I 함께). 100Base-FX
8B/10B
8비트 → 10비트. 1000Base-X, USB 3.0
10아날로그 변조 (AM·FM·PM)
  • AM (진폭 변조): 반송파 진폭 변화. B_AM = 2B
  • FM (주파수 변조): 반송파 주파수 변화. B_FM = 2(1+β)B
  • PM (위상 변조): 반송파 위상 변화. FM과 유사

직렬 · 병렬
직렬 전송 (Serial)
한 번에 한 비트씩 순서대로 데이터를 전송하는 방식.
- 송신 측은 병렬 데이터를 직렬 데이터로 변환 (병렬-직렬 변환기)
- 수신 측은 직렬 데이터를 병렬로 변환 (직렬-병렬 변환기)
- 직렬-병렬 변환은 시프트 레지스터(Shift register) 이용
- 예) RS-232C, USB, 현재 대부분 통신 방식
병렬 전송 (Parallel)
하나의 문자 데이터를 구성하는 여러 개의 비트를 그룹으로 묶어 동시에 전송하는 방식.
- 컴퓨터 내부나 주변 기기 간 데이터 전송에 주로 이용
- 전송 속도가 빠르지만 거리가 멀어지면 전송 비용이 증가하므로 일반적인 컴퓨터 통신에서는 사용하지 않는다
3동기 vs 비동기 전송
비동기 전송 (Asynchronous)
문자 앞 시작 비트 + 뒤 정지 비트(1, 1.5, 2비트).
유휴 상태는 1 유지. 2~3비트 오버헤드 발생. 저속.
동기 전송 (Synchronous)
블록 단위 연속 전송.
- 문자 지향: SYN·STX·ETX
- 비트 지향: Flag, 프레임. 고속·고효율
효율 계산 예제
  • 비동기: 7데이터 + 1시작 + 1정지 = 9비트 → 효율 = 7/9 = 77.78%
  • 동기: STX 8 + 100문자×8 + ETX 8 = 816비트 → 효율 = 800/816 = 98%
4회선 구성 4가지
  • 점대점 (Point-to-Point) — 1:1 전용 회선. PPP 프로토콜
  • 다중점 (Multipoint) — 3개 이상 공유. 폴링·셀렉션·경쟁
  • 회선 집중 (Concentration) — 여러 저속 → 소수 고속. m>n
  • 다중화 (Multiplexing) — 하나의 고속을 여러 저속이 공유. TDM·FDM
5전송 형태 (캐스팅)
유니캐스트
1:1 (하나 → 하나)
애니캐스트
1 : 가장 가까운 하나
멀티캐스트
1 : 특정 그룹
브로드캐스트
1 : 모든 수신자
6토폴로지 6가지 ⭐⭐
앞글자 암기법
버 · 성 · 링 · 메 · 트 · 혼
버스 · 성형 · 링형 · 메쉬 · 트리 · 혼합
① 버스형 (Bus type)
버스라 불리는 공통 배선을 모든 노드가 공유
근거리 통신망(LAN)의 일반적 방식
노드는 탭(Tap)과 유도선(Drop line)에 의해 버스로 연결
한 노드가 데이터를 전송하면 브로드캐스트되어 모든 노드가 수신
✔ 케이블링 비용 최소화, 확장성 양호, 한 노드 오류가 다른 노드에 영향 없음
✘ 버스 고장 시 네트워크 전체 정지, 둘 이상이 동시 전송 시 충돌 발생
② 성형 (Star type)
중앙 장치(허브/교환기)에 모든 장치를 개별적으로 연결
✔ 개별 고장이 전체에 영향 없음, 결함 탐지 용이
✘ 중앙 장치 고장 시 전체 마비
③ 링형 (Ring type)
각 노드는 자신의 양쪽에 있는 노드와 점대점 방식으로 연결
신호는 한 방향으로만 링을 따라 목적지에 도달할 때까지 전송
✔ 설치 쉬움, 신호 재생
✘ 한 장치 고장 시 전체 마비
④ 메쉬형 (Mesh type) ⭐
각 노드간 점대점 방식으로 직접 연결
n개 장치 → n(n-1)/2 개의 물리적인 채널 필요
각 장치는 (n-1) 개의 입출력 포트가 필요
장애 발생 시 대체 경로로 전달 가능
링형과 더불어 네트워크 백본을 구성하는 방식
⑤ 트리형 (Tree type)
스타형 토폴로지의 변형
중앙 허브가 중계기 기능을 갖춘 능동적인 허브
대부분의 노드는 중앙 허브에 연결된 2차 허브에 연결 (능동 또는 수동 허브)
2차 허브의 이점: 중앙 허브에 많은 노드 연결 가능, 네트워크에는 여러 노드로부터의 통신을 분리하거나 우선순위 부여 가능
⑥ 혼합형 (Hybrid type)
네트워크의 규모, 용도 등 다양한 요소에 따라 구성 가능
여러 형태의 LAN을 연결한 MAN 또는 WAN에서 자주 볼 수 있는 구조
여러 종류의 기술을 사용하기 때문에 관리하기 어려움
메쉬형 링크 수 = n(n-1)/2
예) n=120 → 120×119/2 = 7,140개
7네트워크 분류 (LAN·MAN·WAN)
LAN (Local Area Network, 근거리 통신망) — 폐쇄망
한 건물 또는 회사, 공장, 병원 내에 있는 장치들을 연결하기 위한 네트워크
반경 수 Km 이내, 수 Mbps 또는 수백 Mbps까지의 전송 속도
사설 기관에 속하는 통신 네트워크
특징: 단일 기관 소유의 네트워크, 광대역 전송 매체로 고속 통신, 신뢰성 높음, 오류율 낮음
MAN (Metropolitan Area Network, 도시형 통신망)
LAN과 WAN의 중간 정도 크기. 오류율과 지연 시간이 LAN보다 크다.
최근 LAN이 발달하면서 MAN은 LAN의 확장 형태로 간주되고 있음
IEEE에서는 MAN의 표준으로 DQDB(Distributed Queue Dual Bus, 분산 큐 이중 버스) 프로토콜을 권장
WAN (Wide Area Network, 광역 통신망)
국가, 대륙 등 넓은 영역을 포함하는 넓은 지역에 데이터, 음성, 영상 등의 정보를 전송
공중 네트워크(Public network)로 통신사업자가 구축한 망을 임대하여 사용
발전 과정: X.25(패킷 단위) → 프레임 릴레이(프레임 단위) → ATM(셀 단위)
종류: PSTN, PSDN, 인터넷
8인터페이스 표준
  • EIA-232 (RS-232C): DTE↔DCE. 25핀. 15m·20Kbps 이하
  • Null MODEM: 모뎀 없이 DTE간 직접. Crossover cable
  • EIA-449 / EIA-530 / X.21 / V.35: 고속·장거리 확장
  • USB: 최대 127개 장치. Plug-and-play, Hot plugging
    USB 1.0=12Mbps, 2.0=480Mbps, 3.0=5Gbps

D1. PCM 과정(아날로그→디지털)을 설명하시오.

모범답안:
PCM은 아날로그 신호를 디지털 신호로 변환하는 기술로 3단계로 구성된다.
① 표본화(Sampling): 아날로그 신호를 일정 간격으로 추출해 PAM 신호로 변환. 나이퀴스트 정리에 의해 최대 주파수의 2배 이상(f_s ≥ 2f_m)으로 표본화해야 원 신호 복원 가능.
② 양자화(Quantization): 표본값을 유한한 정수값으로 근사. 양자화 잡음(오차) 발생. 레벨이 많을수록 오차 감소.
③ 부호화(Encoding): 양자화된 값을 이진 코드로 변환. L개 레벨 → log₂L 비트.

D2. ASK·FSK·PSK·QAM을 각각 정의하시오.

모범답안:
① ASK(진폭 편이 변조): 반송파의 진폭을 변화시켜 디지털 데이터를 표현. 1=신호 있음, 0=신호 없음(OOK). 잡음에 가장 취약.
② FSK(주파수 편이 변조): 반송파의 주파수를 변화. 1=f₁, 0=f₀. ASK보다 잡음에 강함.
③ PSK(위상 편이 변조): 반송파의 위상을 변화. BPSK는 0°/180°, QPSK는 4위상으로 2비트씩 전송.
④ QAM(직교 진폭 변조): ASK+PSK 결합. 진폭과 위상을 동시에 변화. 5G·LTE·Wi-Fi에서 사용.

D3. 감쇠·왜곡·잡음을 설명하시오.

모범답안:
① 감쇠: 신호가 전송매체를 통과하며 에너지가 손실되어 약해지는 현상. 증폭기(아날로그)·리피터(디지털)로 보상.
② 왜곡: 신호의 형태가 변하는 현상. 지연 왜곡(주파수별 전파 속도 차이), 감쇠 왜곡(주파수별 감쇠 차이). 등화기로 보상.
③ 잡음: 원 신호에 없던 불필요한 신호. 열잡음(백색잡음), 상호변조 잡음, 누화, 충격 잡음.
