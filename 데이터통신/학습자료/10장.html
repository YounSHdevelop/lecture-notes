2LAN의 분류 (4가지 기준) ★
분류 기준종류

3토폴로지에 의한 분류
💡 토폴로지(Topology)란
  • 네트워크를 구성하는 노드와 노드 간의 연결 상태에 대한 배치를 의미
  • LAN에서 메쉬형(Mesh type)은 사용되지 않는다 ★
⭐ 스타형 (Star)
각 스테이션이 허브(Hub)라는 중앙 전송 제어 장치와 점대점 링크로 연결.
장점: 고장 발견·유지보수 용이 / 한 스테이션 고장이 전체에 영향 X / 증설·이전 용이.
단점: 중앙 장치 고장 시 전체 동작 불가 / 케이블링 비용·노력 / 통신량 많으면 전송 지연. → 성능 향상 위해 스위칭 허브 사용 추세.
⭐ 버스형 (Bus)
버스(공통 배선)에 모든 요소 연결. 끝에 종단 장치(Terminator)로 신호 반사 중첩 제거. 이더넷=버스형.
장점: 케이블링 비용 최소 / 한 스테이션 고장이 다른 부분에 영향 X(신뢰성).
단점: 베이스밴드는 거리 멀면 중계기 필요 / 버스 결함 시 전체 전송 불가 / 스테이션↑면 처리능력 급감 / 부하↑면 응답 느림.
링형 (Ring)
닫힌 루프 형태로 각 스테이션이 양쪽 스테이션과 전용 점대점 연결.
장점: 각 스테이션에서 신호 재생 → 잡음에 강함 / 단방향 전송로 → 광섬유에 잘 부합.
단점: 스테이션 변경·추가 어려움 / 한 스테이션 고장이 전체에 영향.
트리형 (Tree)
스타형의 변형. 1차 허브에 연결되지만 모든 장치가 중앙 장치에 직접 연결되진 않음.
2차 허브를 둠으로써: 1차 허브에 더 많은 스테이션 연결 / 2차 허브로 네트워크 분리·우선순위 부가.
4전송 매체에 의한 분류
매체특징
트위스티드 페어 (UTP/STP)2개 이상 구리 도선이 꼬임. 가장 많이 활용, 가장 값싸고 쉽게 설치. 대역폭 제한 많고 잡음 많음.
동축 케이블넓은 대역폭, 빠른 속도, 적은 전기적 간섭. 많이 쓰였으나 점차 사용 빈도 감소.
광케이블넓은 대역폭, 매우 높은 속도, 오류 적음. 전기적 간섭 X, 보안성 우수. 크기 작고 가볍지만 설치에 고도 기술 필요. 주로 백본(Backbone)에 사용.
무선 LAN (WiFi)유선 LAN 장점 + 제약 없는 연결성. 신뢰성·유연성·설치 용이성, 비용 절감. IEEE 802.11로 표준화.
5매체 액세스 방식에 의한 분류 ★
매체 접근 방식
경쟁 방식 vs 토큰 제어 방식
공유 전송 매체에 대한 채널 할당 문제를 해결하는 방식
💡 분류
  • 경쟁 방식 → CSMA/CD: 스테이션이 채널 상태를 미리 감지해 충돌을 피하는 방식
  • 토큰 제어 → 토큰 링: 토큰이라는 짧은 프레임으로 데이터를 보낼 권리를 정해 전달
  • 토큰 제어 → 토큰 버스: 토큰 링 + 이더넷 결합. 물리적 버스, 논리적 토큰 링
  • 토큰 개념 활용 분야: 공장 자동화(산업용 네트워크), 항공 및 군사 시스템
6전송 기술에 의한 분류 (베이스밴드 vs 브로드밴드) ★
베이스밴드 (Baseband)
디지털 신호를 그대로 전송. 높은 전송율의 하나의 전송 채널(TDM 사용). 전송 속도 빠르나 신호 감쇠 심해 거리에 민감.
브로드밴드 (Broadband)
주파수 분할 다중화(FDM) 사용. 데이터·음성 동시 전송, 동축/광케이블 사용. 한 방향으로만 전송(CATV와 유사). 거리에 둔감하지만 속도 느림.
7LAN의 표준 — IEEE 802 ★
IEEE 802 핵심 ★
데이터링크 = LLC + MAC
1985년 LAN 표준화 / 물리 계층 + 데이터링크 계층 기능 규정
LLC (Logical Link Control)
데이터링크 계층의 기본 기능: 에러 제어 및 흐름 제어. HDLC 프레임 구조 사용(논리 주소·제어 정보·데이터로 구성).
MAC (Medium Access Control)
물리적 매체·연결 방식에 따른 제어. 공유 매체에 대한 접근 제어 담당. 종류: 이더넷(CSMA/CD), 토큰 버스, 토큰 링.
💡 IEEE 802 프로젝트 번호 ★
  • 802.1 Internetworking · 802.2 LLC
  • 802.3 CSMA/CD · 802.4 Token bus · 802.5 Token ring
  • 802.6 DQDB · 802.11 Wireless LAN · 802.15 WPAN
02 ⚡ CSMA/CD 방식 LAN (이더넷)
1CSMA/CD의 의미 ★
CSMA/CD = ?
CS + MA + CD
버스형에 사용되는 매체 접근 방식, 이 방식의 LAN = 이더넷(Ethernet)
CS (Carrier Sense)
회선을 사용 중인지 감지한다.
MA (Multiple Access)
회선을 사용하고 있지 않다면 누구든지 사용 가능하다.
CD (Collision Detection)
프레임을 전송하면서 충돌 여부를 조사한다.
한 줄 정리
감지하고(CS) → 비어 있으면 보내고(MA) → 보내면서 충돌을 본다(CD).
2동작 과정 & 재전송 알고리즘 ★
N=0 → 채널 사용 중? (Yes면 대기) → 프레임 전송 → 충돌? → Jam 신호 전송 → N=N+1 → N>15 ? (Yes면 비정상 종료) → [0, 2ᴺ-1] 임의수 k 선택 → k×슬롯타임 대기
💡 재전송 알고리즘 (이진 지수 백오프)
  • 프레임 전송 중 충돌 시 정해진 최대 시도 횟수(N=15)만큼 재전송 시도
  • 충돌이 반복되면 통신량이 많다는 의미 → 재전송 대기 시간을 늘려 통신량 조절
  • N번 충돌 시 [0, 2ᴺ-1] 사이 임의의 수 k를 선택해 k × 슬롯타임 동안 대기
슬롯 타임(slot time) = 2 × 전송 지연시간 + 여유 마진
3지속 방식 (Persistent strategy)
💡 매체가 사용 중일 때 어떻게 할 것인가?
  • Non-persistent: 회선 사용 중이면 회선 감시를 중지하고 임의의 시간 기다렸다가 처음부터 다시 시작
  • Persistent: 회선 사용 중이면 회선을 계속 감시
  • └ 1-persistent: 사용 중이 아니면 즉시 전송(확률 1). CSMA/CD에서 사용. 유선
  • └ p-persistent: 회선이 비어 있어도 확률 p로 전송. 위성 통신. 충돌 가능성↓ 효율성↑
4최소 프레임 크기 ★
💡 핵심 원리
  • CSMA/CD에서는 하나의 프레임을 모두 전송하기 전에 충돌을 감지할 수 있어야 함
  • 프레임 전송시간(Tfr)은 최대 전파시간(Tp)의 2배 이상이 되어야 함
Tfr ≥ 2 Tp
최대 전파 지연 Tp = 25.6μs → 최소 전송시간 Tfr = 2 × 25.6 = 51.2μs
전송 속도 10Mbps → 최소 프레임 = 10Mbps × 51.2μs = 512비트(64바이트), 최대 길이 2,500m
📌 Note: 전송 지연 vs 전파 지연
• 전송 지연(Transmission delay): 채널 용량에 하나의 프레임을 완전히 송출하는 데 걸리는 시간.
  전송 지연 = (프레임 길이 [bit]) / (채널 전송 속도 [bps])
• 전파 지연(Propagation delay): 매체를 통해 전파적으로 이동하는 데 걸리는 시간(보통 매우 작음).
  전파 지연 = (총 이동 거리 [m]) / (이동 속도 [m/sec])
5이더넷 프레임 형식 ★
Preamble7바이트
SFD1바이트
DA6바이트
SA6바이트
Length/Type2바이트
Data46~1,500바이트
CRC4바이트
💡 필드 설명
  • Preamble: 프레임 동기를 위해 사용. 1과 0을 반복
  • SFD (Start Frame Delimiter): 10101011 비트 패턴, 프레임의 도착을 알림
  • Destination Address (DA): 목적지 물리 주소(MAC address)
  • Source Address (SA): 발신지 물리 주소(MAC address)
  • Length/Type: 데이터(PDU)의 바이트 수. 0x0600 = 1,536보다 작으면 Length, 크면 Type
  • Data: 46 ~ 1,500 바이트
  • CRC: 오류 검출. CRC-32 사용. 목적지 주소(DA)~데이터 필드까지의 오류 검사

구분속도핵심 특징

03 🪙 토큰 제어 방식 LAN
1토큰(Token) 개념 ★
토큰 = ?
채널 사용권
특정한 비트 패턴을 갖는 제어 패킷. 토큰을 가진 스테이션만 전송 가능
💡 특징과 장단점
  • 전송 원하는 스테이션 간 충돌 없이 매체에 접근 (CSMA/CD보다 안정적)
  • 매체 접근 지연시간이 어느 정도 예측 가능
  • 우선순위 개념 적용: 우선순위 높은 스테이션에 토큰 먼저 제공
  • 단점: 노드 수↑면 토큰 순회 시간이 길어져 네트워크 속도 저하
  • 단점: 구현 복잡, 토큰 분실 시 스테이션들이 무한히 대기
2토큰 버스 LAN (IEEE 802.4)
💡 핵심 정리
  • 토큰이 버스 구조 노드로 형성된 논리적인 링 구조를 따라 돌며, 토큰을 가진 노드가 특정 시간 동안 회선 점유해 패킷 전송
  • 전송을 마쳤거나 일정 시간 지나면 토큰은 논리적 순서대로 다음 노드로 넘어감
  • IEEE 802.4로 표준화 → 이더넷에 밀려 거의 사용되지 않음
  • 물리적으로는 버스, 논리적으로는 링 (예: 논리적 링 A→D→B→C→A)
3토큰 링 LAN (IEEE 802.5)
💡 핵심 정리
  • 프리 토큰(Free token)이 각 노드를 한 쪽 방향으로 순차적으로 옮겨가며 데이터 전송
  • IEEE 802.5로 표준화 → STP 케이블 사용, 16Mbps 전송
① 프리 토큰이 A 도착 → ② 비지 토큰으로 바꾸고 프레임을 링으로 전송 → ③ 수신 C가 프레임 수신, 복사 필드 마크 → ④ 프레임이 A로 돌아오면 프리 토큰 전송
4토큰 제어 LAN의 발전 — FDDI ★
FDDI
100Mbps 광 이중 링
Fiber Distributed Data Interface — 저속 LAN들을 상호 연결하는 기간 LAN
💡 핵심 정리
  • 저속 LAN들을 상호 연결하는 기간 LAN 역할. 고속 데이터 + 음성·데이터 전송
  • 100Mbps 고성능 광케이블 LAN, 이중 링(Dual ring)으로 구성
  • 200Km 범위에서 1,000개의 스테이션 연결, 노드 간 거리 2Km로 제한
  • 토큰 링 방식(IEEE 802.5) 사용: 토큰 조기 해제 방식 → 효율적 전송
💡 FDDI의 계층 구조
  • PMD 계층: 광섬유 종류별 광 송수신기 포함한 각종 전송 장비 내역 규정
  • PHY 계층: 부호화(4B/5B) 및 고장 난 스테이션 처리 방식 규정. 스테이션 간 최대 거리 = 다중 모드 2Km, 단일 모드 40Km
  • SMT (Station Management): 연결 관리, 링 관리, SMT 프레임 서비스
5DQDB (IEEE 802.6)
💡 핵심 정리

  • 이중 버스로 구성 → 네트워크 용량 증가 (단방향 버스 A + 단방향 버스 B, 양 끝 Head end)
  • 영상 서비스를 위한 MAN용으로 개발

4IEEE 802.11 MAC 계층 (PCF · DCF) ★
PCF (Point Coordination Function)
비경쟁 방식. AP로 스테이션들의 데이터 전송을 중앙에서 제어하는 방식.
DCF (Distributed Coordination Function)
경쟁 방식. CSMA/CA 사용. 무선에서는 충돌 여부를 검출할 수 없어 아예 충돌을 회피한다.
5CSMA/CA ★
CSMA/CA 핵심 ★
충돌 회피 · NAV
CSMA/CD의 변형 — 무선은 충돌 검출 불가 → 아예 충돌을 회피
💡 핵심 정리
  • CSMA/CD의 변형 → 무선에서는 충돌 검출 불가, 아예 충돌을 회피하는 방법 사용
  • 반드시 ACK가 필요 → 수신 스테이션이 데이터를 잘 받았는지 송신 측이 알 수 없기 때문
  • 충돌 회피의 핵심은 NAV(Network Allocation Vector)에 있다
  • 한 스테이션이 RTS 프레임 전송 시 채널 점유 시간이 포함 → 이 시간 동안 다른 스테이션은 전송 시도하지 않음
DIFS → RTS → SIFS → CTS → SIFS → data → SIFS → ACK
💡 경쟁 윈도 (Contention window)
  • 전송 시도 전 충돌 회피 위해 슬롯타임의 정수 배 시간 동안 대기
  • 초기 대기 시간은 슬롯타임 1개 → 대기 후 매체 비어 있으면 RTS 전송
  • 사용 중이면 다시 이전 대기 시간의 2배에 해당하는 대기 시간 내에서 임의 슬롯타임 개수만큼 대기 (시도 횟수 N=3이면 0~7 (0과 2ᴺ-1) 사이 임의값 선택)
6숨겨진 터미널 vs 노출된 터미널 ★
숨겨진 터미널 문제 (Hidden terminal)
중간 B는 A와 C 모두와 통신 가능하나 A와 C는 직접 통신 불가. A가 B에 전송 시 C는 모르므로 C가 B에 전송하면 충돌.
→ 해결: RTS/CTS. A가 RTS 전송, B가 CTS 응답 → C도 CTS 수신 → NAV 기간 동안 전송 시도 안 함으로 충돌 회피.
노출된 터미널 문제 (Exposed terminal)
B가 A로 전송하면 C도 신호 감지해 매체 사용 불가로 판단. C가 D에 전송해도 되지만 B 전송 완료까지 대기.
→ 이처럼 동시 전송이 가능함에도 전송하지 못하는 경우를 의미.

1WPAN 개요
WPAN = ?
IEEE 802.15 · 10m 내외
Wireless Personal Area Network — 블루투스·지그비·UWB
💡 핵심 정리
  • 무선 기반 이동성·편리성, 언제·어디서나 맞춤형 서비스 → 유비쿼터스 네트워크 핵심 기술
  • 10m 내외의 비교적 단거리에서 디바이스 간 무선 연결
  • 저전력·소형·저가격, 저속(Kbps)~초고속(Gbps) 다양한 속도

  • IEEE 802.15 표준화 그룹: 블루투스, 지그비, UWB
2블루투스 (Bluetooth) ★
블루투스 한 줄
1994 에릭슨 · 79채널 FHSS
10m 짧은 거리 장치 연결용 무선 LAN의 일종 (PC·마우스·프린터·스피커·헤드셋)
💡 네트워크 구조
  • 일반적으로 기기 간 1:1 데이터 통신
  • 피코넷(Piconet): 하나의 마스터를 중심으로 여러 개(최대 7대)의 슬레이브 연결
  • 스케터넷(Scatternet): 2개의 피코넷이 겹치는 형태
💡 프로토콜 계층 구조
  • RF(무선 계층): 물리 계층. 총 79개 채널(f = 2402 + k MHz, k=0~78). FHSS 방식. 초당 1,600번 호핑 → 각 주파수 체류 시간 625μs (=1/1600)
  • Baseband(베이스밴드): LAN의 MAC 계층과 유사. 슬롯타임(625μs) TDMA 접근. 마스터=0,2,4,6 / 슬레이브=1,3,5,7 슬롯 → TDD-TDMA. 프레임: 액세스 코드(72비트)·헤더(54비트)·페이로드(0~2,740비트)
  • Link Manager: 두 장치 사이 링크 설정·관리·해제
  • HCI(Host Controller Interface): 호스트와 호스트 컨트롤러 사이 인터페이스 담당
  • L2CAP: LAN의 LLC 부계층에 해당. 다중화, 분할·재조립, QoS 관리
  • RFCOMM/SDP: RFCOMM은 가상 직렬 포트 제공 / SDP(Service Discovery Protocol)는 사용 가능 서비스 종류·특성 파악
💡 블루투스 표준의 변화
  • 1.1: 2002 IEEE 표준 승인, 723Kbps · 2.0+EDR: 3.0Mbps(실제 2.1Mbps)
  • 3.0+HS: 최대 24Mbps · 4.0+LE: 저전력(BLE) 1Mbps
  • 4.2: IoT, IPv6/6LoWPAN · 5.0: 사물인터넷 초점, 속도·도달 범위 trade-off

Q16.CSMA/CD의 슬롯 타임을 구하는 식을 쓰시오.
슬롯 타임 = 2 × 전송 지연시간 + 여유 마진. 한 프레임을 모두 보내기 전에 충돌을 감지할 수 있어야 하므로 Tfr ≥ 2Tp 조건이 필요하다.
Q17.토큰 링 LAN의 IEEE 표준 번호와 전송 속도를 쓰시오.
IEEE 802.5, 16Mbps — STP 케이블을 사용하며 프리 토큰이 한 방향으로 순차적으로 옮겨가며 데이터를 전송한다.
Q18.무선 LAN에서 충돌 회피의 핵심이 되는, 채널 점유 시간을 나타내는 값의 약어는?
NAV (Network Allocation Vector) — RTS 프레임에 채널 점유 시간이 포함되어, 이 시간 동안 다른 스테이션은 전송을 시도하지 않아 충돌을 회피한다.
Q19.블루투스 RF 계층은 총 몇 개의 채널을 사용하며, 1초당 호핑 횟수는?
79개 채널, 초당 1,600번 호핑 — FHSS 방식. 각 주파수에서 머무는 시간은 625μs(=1/1600)이며 f = 2402 + k MHz (k=0~78).
Q20.지그비의 IEEE 표준 번호와 전송 속도를 쓰시오.
IEEE 802.15.4, 250Kbps — 소형·저전력·저비용 WPAN으로 긴 배터리 수명과 보안을 요구하는 분야, IoT에 주로 사용된다.

▪ 서술형 연습

Q21.스타형 LAN의 장점과 단점을 각각 설명하시오.
▸ 스타형은 각 스테이션이 허브라는 중앙 전송 제어 장치와 점대점 링크로 연결된 형태다.
▸ 장점: 고장 발견이 쉽고 유지보수가 용이하다 / 한 스테이션의 고장이 전체 네트워크에 영향을 미치지 않는다 / 스테이션 증설·이전이 용이하다.
▸ 단점: 중앙 전송 제어 장치가 고장 나면 네트워크 전체가 동작 불가능하다 / 설치 시 케이블링에 많은 노력·비용이 든다 / 통신량이 많으면 전송 지연이 발생한다.
▸ 최근에는 성능 향상을 위해 스위칭 기능을 갖는 허브를 사용하는 추세이다.
Q22.CSMA/CD에서 최소 프레임 크기가 필요한 이유와, 10Mbps·Tp=25.6μs일 때의 최소 프레임 크기를 계산 과정과 함께 설명하시오.
▸ CSMA/CD는 하나의 프레임을 모두 전송하기 전에 충돌을 감지할 수 있어야 한다. 그래야 충돌을 인지하고 재전송할 수 있기 때문이다.
▸ 따라서 프레임 전송시간 Tfr은 최대 전파시간 Tp의 2배 이상이어야 한다: Tfr ≥ 2Tp.
▸ Tp = 25.6μs → 최소 전송시간 Tfr = 2 × 25.6μs = 51.2μs.
▸ 전송 속도 10Mbps → 최소 프레임 크기 = 10Mbps × 51.2μs = 512비트(64바이트).
▸ 실제 이더넷의 최소 프레임 길이는 512비트(64바이트)이며 최대 길이는 2,500m로 규정된다.
Q23.숨겨진 터미널 문제와 노출된 터미널 문제를 비교 설명하시오.
▸ 숨겨진 터미널 문제: 중간의 B는 A와 C 모두와 통신할 수 있지만 A와 C는 서로 직접 통신할 수 없는 거리에 있다. A가 B에 전송 중인 것을 C가 모르고 C도 B에 전송하면 충돌이 발생한다. 해결책으로 A가 RTS를 보내고 B가 CTS로 응답하면, C도 CTS를 수신하여 NAV 기간 동안 전송을 시도하지 않아 충돌을 회피한다.
▸ 노출된 터미널 문제: B가 A로 전송하면 C도 신호를 감지해 매체를 사용할 수 없다고 판단한다. 실제로는 C가 D에 전송해도 되지만 B의 전송이 끝날 때까지 대기한다. 즉 동시 전송이 가능함에도 전송하지 못하는 비효율이 발생한다.
Q24.블루투스의 네트워크 구조(1:1, 피코넷, 스케터넷)를 설명하시오.
▸ 블루투스는 일반적으로 기기 간 1:1 데이터 통신을 위해 사용된다.
▸ 피코넷(Piconet): 하나의 마스터를 중심으로 여러 개(최대 7대)의 슬레이브가 연결되는 형태다.
▸ 스케터넷(Scatternet): 2개의 피코넷이 겹치는 형태로, 한 장치가 두 피코넷에 동시에 속하여(M/S) 두 네트워크를 이어준다.
▸ 베이스밴드 계층에서 마스터와 슬레이브는 슬롯타임(625μs)을 이용한 TDMA로 매체에 접근하며, 마스터는 0,2,4,6 슬롯을, 슬레이브는 1,3,5,7 슬롯을 사용하는 TDD-TDMA 방식으로 반이중 통신한다.
Q25.지그비, 블루투스, 와이파이의 특성을 전송 거리·속도·소비 전력 관점에서 비교 설명하시오.
▸ 지그비: 전송 거리 ~100m, 속도 ~250Kbps로 느리지만 소비 전력이 매우 낮고 복잡도·비용이 낮다. 긴 배터리 수명과 보안이 필요한 IoT·센서 제어에 적합하다.
▸ 블루투스: 전송 거리 ~10m, 속도 ~24Mbps, 소비 전력 중간. 근거리 유선 대체(마우스·헤드셋 등)에 사용된다.
▸ 와이파이: 전송 거리 ~10m(핫스팟 범위는 더 넓음), 속도 11/54Mbps로 가장 빠르지만 소비 전력이 높고 복잡도·비용이 높다.
▸ 정리하면 속도는 와이파이 > 블루투스 > 지그비 순이고, 저전력·저비용은 지그비가 가장 우수하다.
