데이터 통신 개요

데이터·통신의 기본 개념 · 시스템 구성 · 네트워크 분류 · 프로토콜 · 표준화 기구

② 핵심 요약

📦 데이터 vs 정보

  • 데이터: 관찰·측정으로 수집한 사실을 문자·숫자·기호로 표현한 것 (원시 상태)
  • 정보: 데이터를 가공·처리하여 가치와 의미를 부여한 것

📡 통신 vs 데이터 통신

  • 통신: 두 장치 이상이 프로토콜에 따라 정보를 전달하는 과정
  • 데이터 통신: 통신 기능을 가진 장치들이 전송매체를 통해 데이터를 교환하는 과정

➕ 데이터 통신 = 처리 + 전송

데이터 통신 = 데이터 처리 + 데이터 전송

컴퓨터(처리)와 통신(전송)의 결합으로 탄생

🌐 데이터 통신 네트워크

  • 지리적으로 분산된 정보원을 상호 연결한 시스템
  • 데이터 통신 네트워크 = 컴퓨터 네트워크 = 네트워크 (세 용어 동일)

📶 통신회선 (전송매체)

  • 유선: 트위스티드 페어, 동축케이블, 광케이블
  • 무선: 전자파, 적외선

🔗 네트워크의 필요성

  • 점대점(P2P): 가장 단순하지만 비용 비경제적
  • 네트워크 연결: 포트 1개로 노드에 접속, 설비 공유로 비용 절감

🖥️ 단말장치 (DTE)

  • DTE (Data Terminal Equipment): 데이터 단말 장치
  • 입출력 기능, 전송제어 기능, 기억 기능
  • 예) 컴퓨터, 프린터, 터미널

🔄 신호변환 장치 (DCE)

  • DCE (Data Circuit-terminating Equipment): 데이터 회선 종단 장치
  • 모뎀 (Modem): 디지털 ↔ 아날로그 변환
  • DSU: 디지털 → 디지털 신호 변환
  • CSU: 여러 채널 다중화 전송 (T-1, E-1 방식)

🎛️ 통신제어장치 (CCP/FEP)

  • 대형 컴퓨터가 데이터 처리에만 전념할 수 있도록 데이터 전송을 대신 제어
  • 기능: 전송제어, 동기 및 오류제어, 기타

⑥ LAN · MAN · WAN 비교

🏢 LAN
Local Area Network · 근거리 통신망
반경 수 km 이내 사설 기관 소유
  • 한 건물/회사/공장/병원 내 장치들을 연결
  • 수 Mbps ~ 수백 Mbps 고속 전송 지원
  • 단일 기관 소유 → 확장·재배치 유리
  • 광대역 전송 매체 → 고속 통신 가능
  • 신뢰성 높음, 오류율 낮음
  • 초기: 공유채널 → 현재: LAN 스위치 구조
  • 기가비트 이더넷, 무선 LAN 등 다양한 방식 사용
🏙️ MAN
Metropolitan Area Network · 도시형 통신망
LAN과 WAN 중간 경계 모호화
  • 하나의 도시/지역을 연결
  • 오류율과 지연시간이 LAN보다 큼
  • 최근 LAN이 발달하면서 LAN의 확장 형태로 간주
  • "MAN"이라는 용어는 잘 사용되지 않음
  • IEEE 표준: DQDB(Distributed Queue Dual Bus) 프로토콜 권장
🌍 WAN
Wide Area Network · 광역 통신망
국가·대륙·전세계 공중망 임대
  • 국가, 대륙, 전 세계를 포괄
  • 데이터·음성·영상 등 다양한 정보 전송
  • 통신사업자가 구축한 공중망을 임대하여 사용
  • 네트워크 형태가 매우 복잡
  • 스위칭 개념 사용
  • 구축 비용이 많이 들고 전송 속도가 LAN보다 느림

💡 WAN이 스위칭 개념을 사용하는 이유

WAN은 수천 km에 걸쳐 무수히 많은 노드가 분산되어 있습니다. 모든 노드 쌍 사이에 전용 회선(dedicated line)을 깔면 비용이 천문학적으로 증가합니다.

대신 스위칭(교환)을 사용하면 하나의 물리적 링크를 여러 통신이 공유할 수 있어 효율적으로 자원을 활용할 수 있습니다.

📌 WAN에서 사용하는 스위칭 방식: 회선 교환(Circuit Switching), 패킷 교환(Packet Switching), 메시지 교환(Message Switching)

⑧ 프로토콜 (Protocol)

프로토콜(Protocol)은 원래 '의정서, 조서'를 의미하는 외교상의 용어입니다.
통신 프로토콜이란 통신을 위한 약속들의 집합으로, 서로 다른 장치 간에 데이터를 주고받기 위한 규칙을 정의합니다.

무엇을? (What?)
구문 (Syntax)

데이터의 구조나 형식을 정의합니다. 데이터가 어떤 순서로 표현되는지를 의미하며, 순서에 따라 의미가 달라집니다.

예) IP 패킷 헤더에서 출발지 주소가 앞에 오는지 뒤에 오는지는 구문(문법)의 문제
어떻게? (How?)
의미 (Semantics)

데이터의 의미·뜻을 정의합니다. 특정 패턴이 어떻게 해석되며, 그 해석에 따라 어떤 동작을 취할지를 결정합니다.

예) 헤더의 특정 비트가 '1'이면 오류 발생을 의미하고, 재전송을 요청해야 함
언제? (When?)
타이밍 (Timing)

언제 전송할지, 얼마나 빠르게 전송할지를 결정합니다. 흐름 제어(Flow Control)와 관련이 있습니다.

🤔 송신기: 100Mbps 전송 / 수신기: 10Mbps 처리
→ 버퍼 오버플로우 발생! 데이터 손실 위험
요소 질문 핵심 키워드
구문 무엇을? 데이터 구조·형식, 순서
의미 어떻게? 패턴 해석, 동작 결정
타이밍 언제? 전송 시점·속도, 흐름 제어

⑨ 프로토콜의 주요 기능

📍 주소지정 (Addressing)

데이터가 목적지까지 정확하게 전송될 수 있도록 목적지 주소와 경로를 부여하는 기능.

🔢 순서 제어 (Sequencing)

전송되는 패킷에 전송 순서를 부여하는 기능. 흐름 제어 및 오류 제어를 용이하게 함.

✂️ 단편화 및 재조립

단편화(Fragmentation): 송신측에서 데이터를 작은 패킷으로 분할하여 전송.
재조립(Reassembly): 수신측에서 패킷들을 원래 데이터로 복원.
이유: 지연시간 최소화 + 오류 발생 확률 감소

📦 캡슐화 (Encapsulation)

주소, 오류검출 부호 등 프로토콜 제어정보를 부가하는 것. 보통 헤더(Header)와 트레일러(Trailer)를 덧붙이는 방식으로 수행.

🔗 연결 제어 (Connection Control)

  • 연결 지향형: 전송 전 연결 설정 후 통신
  • 비연결 지향형: 연결 없이 바로 전송

🌊 흐름 제어 (Flow Control)

수신 측에서 데이터가 넘치지 않도록 수신 측의 처리 능력에 맞게 송신 측의 송신 데이터 양을 조절하는 기능.

🛠️ 오류 제어 (Error Control)

전송 도중 발생하는 오류를 검출하고 정정하는 기능.

  • 패리티 비트 (Parity Bit)
  • CRC (순환 중복 검사)
  • 검사합 (Checksum)

⏱️ 동기화 (Synchronization)

송수신 측이 같은 상태를 유지하도록 타이밍을 맞추는 기능.

📡 다중화 (Multiplexing)

하나의 통신 회선을 여러 가입자가 동시에 이용할 수 있도록 하는 기능.

🗺️ 라우팅 (Routing)

출발지에서 목적지까지 최적의 경로를 설정하는 기능.

🎛️ 전송 서비스 (Transmission Service)

우선순위 결정 및 서비스 등급과 보안 요구 제어 등의 서비스를 말한다.

⑩ 표준의 분류 & 표준화 기구

👥 참여 범위에 따른 분류

  • 국제 표준: 세계 모든 국가가 참여해 합의
  • 지역 표준: 특정 지역 소속 국가들의 합의
  • 국가 표준: 특정 국가 내 이해 당사자 합의
  • 단체 표준: 특정 단체·산업 내 제정

📋 규정 내용에 따른 분류

  • 기본 표준: 가장 기초가 되는 원칙·용어 정의
  • 기능 표준: 특정 기능 수행을 위한 세부 규정
  • 이용자 표준: 사용자 관점의 요구사항 규정
  • 시험 표준: 표준 적합성 검증 방법 규정

⚖️ 적용 방법에 따른 분류

  • 강제 표준: 반드시 따라야 하는 법적 강제력이 있는 표준
  • 권고 표준: 따르도록 권장하지만 강제성은 없는 표준

🏛️ 공식 표준 (De Jure Standard)

공인된 표준화 기구가 공식 절차를 거쳐 제정한 표준.
대표적 기구: ITU, ISO, IEC, ISO/IEC
De Jure = "법에 의해" (라틴어)

🌐 사실상의 표준 (De Facto Standard)

정부 기관이 관여하지 않고 민간 차원에서 자율적인 표준화 작업을 수행하는 표준화 기구에 의해 만들어진 표준. 시장에서 널리 채택되어 사실상 표준이 된 것.
De Facto = "사실에 의해" (라틴어) · 예: Wi-Fi, Bluetooth

🏢 주요 표준화 기구
ISO
International Organization for Standardization · 국제표준화기구
  • 1947년 창설
  • 현재 163개국 국가 표준단체로 구성
  • OSI 참조 모델 등 다양한 국제 표준 제정
  • 공식 표준(De Jure) 기구
OSI 참조 모델
Open Systems Interconnection Reference Model
  • 다른 기종 간의 상호접속을 가능케 하는 표준 개방형 통신망
  • 네트워크를 위한 7계층 참조 모델 정의
  • ISO가 제정한 대표적 네트워크 표준
ITU
International Telecommunication Union · 국제전기통신연합
  • 공식 표준화 기구, 전기통신 분야 국제 표준 담당
  • ITU-T: 전화통신 표준 — V시리즈(전화망 모뎀), X시리즈(디지털망)
  • ITU-R: 무선통신 표준 담당
  • ITU-D: 개발도상국 통신 개발 지원
IEEE
Institute of Electrical and Electronics Engineers · 전기전자기술자협회
  • 1963년 미국 전기학회와 무선학회의 합병으로 창설
  • 세계 최대의 전기·전자·컴퓨터 분야 전문가 단체
  • IEEE 802 표준안: 현재 널리 사용되는 LAN 관련 권고 표준안
  • IEEE 표준은 국제 표준으로 채택되거나 그 바탕이 되기도 함
EIA
Electronic Industries Association · 전자산업협회
  • 1924년 RMA로 창설 → 1957년 EIA로 개칭
  • 신호 품질, 디지털 인터페이스, 통신망 인터페이스 등 주로 하드웨어에 관한 규격 개발
  • RS-232-C: 9핀/25핀 직렬 인터페이스 표준 (PC ↔ 모뎀 연결)
  • RS-449: RS-232-C의 개선판, 더 높은 속도·거리 지원
IEC
International Electrotechnical Commission · 국제전기기술위원회
  • 전기·전자 기술 분야의 국제 표준 제정
  • ISO와 함께 ISO/IEC 공동 표준도 발행
ANSI
American National Standards Institute · 미국 국립표준협회
  • 1918년 설립
  • 미국의 규격공업 표준 제정
  • ANSI-C: C 프로그래밍 언어 표준화 (ISO C 표준의 기반)
  • ISO의 미국 대표 기관
KS / KICS
한국 산업표준 / 한국 정보통신표준
  • KS: 한국 산업표준
  • KICS: 한국 정보통신표준
  • 1997년 정보기술 분야 표준 개편: KS-C 시리즈 → KS X 시리즈(정보산업)
IETF
Internet Engineering Task Force · 국제인터넷 표준화 기구
  • 인터넷 관련 기술 표준 개발 및 제정
  • RFC (Request for Comments) 문서를 통해 표준 발행
  • 사실상의 표준(De Facto) 기구 성격
  • TCP/IP, HTTP, SMTP 등 인터넷 핵심 프로토콜 표준화
W3C
World Wide Web Consortium · 월드 와이드 웹 컨소시엄
  • 팀 버너스리가 1994년 설립
  • HTML, CSS, XML 등 웹 표준 제정·관리
  • 사실상의 표준(De Facto) 기구 성격

⑪ 핵심 캐치 — 시험 포인트

🚨

데이터 통신 시스템의 5가지 구성요소는 시험 필수: 송신기, 수신기, 전송매체, 메시지, 프로토콜

🚨

역사의 "최초" 타이틀: SAGE(최초 데이터 통신 시스템), SABRE(최초 상업용 데이터 통신), ENIAC(최초 전자식 컴퓨터), CTSS(최초 시분할), ARPANET(최초 패킷 통신망), ALOHA(최초 무선 패킷 통신망)

🔥

중간고사 출제 확정: "프로토콜의 주요 요소 3가지를 작성하고 각 요소의 설명을 작성하시오." — 구문(Syntax) · 의미(Semantics) · 타이밍(Timing) 반드시 암기!

💡

데이터(raw)와 정보(processed)는 다르다. 데이터를 가공해야 비로소 정보가 된다.

💡

DTE = 데이터 단말 장치(Data Terminal Equipment), DCE = 데이터 회선 종단 장치(Data Circuit-terminating Equipment). DTE는 사용자 측 장비, DCE는 전송로 연결 장비.

💡

모뎀은 디지털↔아날로그 변환, DSU/CSU는 디지털↔디지털 변환. 변환 방향을 구분하라!

🚨

ARPANET(1969)은 최초의 패킷 통신망이자 인터넷의 효시. ALOHA(1970)는 최초의 무선 패킷 통신망. 연도도 함께 암기!

⚠️

MAN 핵심 포인트: 최근 LAN이 발달하면서 MAN이라는 용어 자체가 잘 사용되지 않음. MAN = LAN의 확장 형태로 간주. IEEE 표준은 DQDB(Distributed Queue Dual Bus) 프로토콜.

🏛️

공식 표준 vs 사실상의 표준 구분: 공식 표준(De Jure) = ITU·ISO·IEC 등 공인 기구 제정. 사실상의 표준(De Facto) = 민간 차원 자율적 표준화. IETF(RFC), W3C(HTML/XML) 는 De Facto 성격.

📡

ITU 세부 조직 구분: ITU-T(전화통신, V·X시리즈) / ITU-R(무선통신) / ITU-D(개발도상국). EIA의 RS-232-C(9핀/25핀 직렬인터페이스)는 하드웨어 규격의 대표 사례.

🌐

ISO 수치 암기: 1947년 창설, 163개국 참여. OSI 참조 모델 = ISO가 정의한 7계층 네트워크 참조 모델.

🔥

IEEE 핵심 암기: 1963년 창설 (미국 전기학회 + 무선학회 합병). IEEE 802 표준안 = 현재 널리 사용되는 LAN 관련 권고 표준. 세계 최대 전기·전자·컴퓨터 전문가 단체.

📅

기구별 설립 연도 암기: ISO 1947년 / ANSI 1918년 / EIA 1924년(1957년 개칭) / IEEE 1963년. 시험에서 연도 혼동 주의!

✂️

단편화 이유 2가지: ① 지연시간 최소화 ② 오류 발생 확률 감소. 단순 암기보다 이유를 이해해두면 서술형에서도 활용 가능.

🇰🇷

KS 표준 개편: 1997년에 정보기술 분야 표준이 KS-C 시리즈 → KS X 시리즈(정보산업)로 개편됨.

⑫ 핵심 키워드

Data
데이터
관찰·측정으로 수집한 사실이나 값을 문자·숫자·기호로 표현한 원시 상태의 것.
Information
정보
데이터를 가공·처리하여 가치와 의미를 부여한 것.
Data Communication
데이터 통신
통신 기능을 가진 둘 이상의 장치 사이에서 전송매체를 통해 규칙에 따라 데이터를 교환하는 과정.
DTE (Data Terminal Equipment)
데이터 단말 장치
데이터를 송수신하는 사용자 측 장치. 컴퓨터, 터미널, 프린터 등.
DCE (Data Circuit-terminating Equipment)
데이터 회선 종단 장치
DTE와 전송로 사이에서 신호를 변환하는 장치. 모뎀, DSU, CSU 등.
Modem
모뎀
디지털 데이터를 아날로그 신호로 변환(변조)하거나, 아날로그 → 디지털로 역변환(복조)하는 장치.
DSU / CSU
디지털 서비스/채널 서비스 유닛
DSU: 디지털 데이터를 디지털 신호로 변환. CSU: 여러 채널을 다중화하여 전송(T-1, E-1 방식).
CCP / FEP
통신제어장치
대형 컴퓨터 대신 데이터 전송의 전반적인 제어 기능을 수행. 전송제어·동기·오류제어 담당.
ARPANET
아파넷
1969년 미국 국방성이 개발한 최초의 패킷 통신망. 오늘날 인터넷의 효시.
Local Area Network
LAN (근거리 통신망)
반경 수 km 이내, 단일 기관 소유의 고속 사설망.
Metropolitan Area Network
MAN (도시형 통신망)
도시 규모의 네트워크. 최근 LAN 확장 형태로 간주됨.
Wide Area Network
WAN (광역 통신망)
국가·대륙을 아우르는 대규모 공중망 기반 통신망.
Syntax
구문
데이터의 구조·형식·순서 (무엇을?)
Semantics
의미
데이터 패턴의 해석과 그에 따른 동작 (어떻게?)
Timing
타이밍
전송 시점과 속도, 흐름 제어 관련 (언제?)
Fragmentation & Reassembly
단편화 및 재조립
데이터를 작은 패킷으로 나눠 전송 후 수신측에서 원래대로 복원. 지연시간 최소화 + 오류율 감소 목적.
Encapsulation
캡슐화
헤더·트레일러 형태로 제어정보를 데이터에 부가하는 것.
Flow Control
흐름 제어
수신 측 처리 능력에 맞춰 송신 측의 전송량을 조절하는 기능.
Error Control
오류 제어
패리티 비트·CRC·검사합으로 오류를 검출하고 정정하는 기능.
Multiplexing
다중화
하나의 통신 회선을 여러 가입자가 동시에 이용 가능하게 하는 기능.
De Jure Standard
공식 표준
ITU, ISO, IEC 등 공인 기구가 공식 절차를 거쳐 제정한 표준.
De Facto Standard
사실상의 표준
정부 관여 없이 민간 차원에서 자율적으로 만들어져 시장에서 통용되는 표준.
RFC (Request for Comments)
IETF 표준 문서
IETF가 인터넷 표준을 발행하는 문서 형식. TCP/IP, HTTP, SMTP 등이 RFC로 표준화됨.
EIA RS-232-C
직렬 인터페이스 표준
EIA가 제정한 9핀/25핀 직렬 통신 인터페이스 표준. PC와 모뎀 연결에 사용.
ITU-T V/X Series
ITU-T 권고 시리즈
V시리즈: 전화망을 이용한 모뎀 관련 권고. X시리즈: 디지털망 데이터 통신 관련 권고.
DQDB (Distributed Queue Dual Bus)
분산 큐 이중 버스
IEEE 권장 MAN 표준 프로토콜. 분산 큐 이중 버스 방식.
OSI Reference Model
OSI 참조 모델
다른 기종 간 상호접속을 위한 개방형 통신망 표준. 네트워크를 7계층으로 정의. ISO 제정.
IEEE 802
IEEE 802 표준안
현재 널리 사용되는 LAN 관련 권고 표준안. IEEE가 제정하여 국제표준으로도 채택됨.
W3C (World Wide Web Consortium)
월드 와이드 웹 컨소시엄
팀 버너스리가 1994년 설립. HTML, CSS, XML 등 웹 표준 관리.
