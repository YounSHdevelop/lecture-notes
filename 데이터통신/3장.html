신호 (Signal)

아날로그·디지털 신호의 특성과 채널 용량, 전송 손상

3

📌 핵심 요약

데이터 vs 신호 — 아날로그 vs 디지털

아날로그(Analog)

  • 데이터: 연속적인 값 (음성, 화상, 음향, 영상)
  • 신호: 연속적인 파형, 시간에 따라 연속 변화
  • 주로 무선 전송에 사용
  • 잡음 증폭 문제 → 증폭기(Amplifier) 사용

디지털(Digital)

  • 데이터: 이산적인 값 (0과 1)
  • 신호: 이산적인 파형, 순간적으로 변화
  • 주로 유선 전송에 사용
  • 신호 재생 → 리피터(Repeater) 사용

주기적 신호 vs 비주기적 신호

  • 주기적: 특정 패턴이 주기(Period) T 동안 반복. 완성된 하나의 패턴 = 사이클(Cycle)
  • 비주기적: 반복 패턴 없이 불규칙하게 변화하는 신호

데이터 통신: 주기적 아날로그 신호 또는 비주기적 디지털 신호 사용

T와 f의 관계

T = 1/f    f = 1/T

  • 주기 T: 한 사이클 완성에 걸리는 시간 (단위: 초)
  • 주파수 f: 초당 반복되는 사이클 수 (단위: Hz)

대역폭 (Bandwidth)

신호가 가지고 있는 주파수 성분들의 범위.

대역폭 = 최고 주파수 − 최저 주파수

아날로그: Hz 단위 / 디지털: bps 단위로 표현

채널 용량 공식 2가지

  • 나이퀴스트: 무잡음 채널 → C = 2W log₂L
  • 섀넌: 잡음 있는 채널 → C = W log₂(1+S/N)

전송 손상 3가지

  • 감쇠(Attenuation): 신호 크기가 거리에 따라 감소
  • 왜곡(Distortion): 신호의 모양/형태 변형
  • 잡음(Noise): 원하지 않는 신호 발생

증폭기 vs 리피터

  • 증폭기(Amplifier): 아날로그 신호 증폭 → 잡음도 함께 증폭
  • 리피터(Repeater): 디지털 신호 재생 → 비트 오류 발생 가능
〰️ 아날로그 신호

정현파 (Sine Wave)

단순 아날로그 신호의 기본 형태. 복합 아날로그 신호는 여러 정현파의 합.

y(t) = A · sin(2πft + φ)

A: 진폭 · f: 주파수 · φ: 위상

진폭 (Amplitude)

파형의 높이를 나타낸 것. 물리적으로는 신호의 세기를 의미한다.

단위: 볼트(V), 진폭이 클수록 신호가 강하다.

주파수와 주기

  • 주기(Period) T: 신호가 한 사이클을 완성하는 데 걸리는 시간 (단위: 초)
  • 주파수(Frequency) f: 초당 반복되는 사이클의 수 (단위: Hz)
  • T = 1/f

위상 (Phase)

시각 0시에 대한 파형의 상대적인 위치.

단위: 도(Degree) 또는 라디안(Radian)으로 측정.

예: 위상이 90° 차이나면 파형이 1/4주기 앞서거나 뒤처짐.

대역폭과 주파수 스펙트럼

복합 신호

데이터 통신에서는 주파수가 다른 다수의 정현파가 합쳐진 복합 신호를 사용한다. (전화, 팩스, 모뎀 등)
파형만으로는 주파수 성분 파악이 어려우므로 푸리에 해석(Fourier Analysis)을 이용해 주파수 영역으로 표현한다.

대역폭 계산

대역폭 = f최고 − f최저

예: 주파수 성분이 1000~5000Hz라면
→ 대역폭 = 5000 − 1000 = 4000 Hz

유효 대역폭(Effective Bandwidth): 무시해도 무방한 범위 밖 신호 성분을 제외한 실질적 대역폭. 예) 사람 음성: 300~3300Hz → 유효 대역폭 3000Hz

전송 매체의 대역폭: 전송 매체는 무한대의 대역폭을 갖지 않으므로 모든 주파수 성분을 통과시키지 못한다. 신호의 대역폭과 전송 매체의 대역폭을 구분해서 이해해야 한다.

📶 디지털 신호

비주기적 특성

대부분의 디지털 신호는 비주기적이므로 주기나 주파수를 사용할 수 없다.

대신 비트 간격과 비트율을 사용하여 표현한다.

비트 간격 (Bit Interval)

비트 하나를 전송하는 데 필요한 시간.

주기(Period)에 대응하는 디지털 신호의 개념.

비트 간격 = 1 / 비트율

비트율 (Bit Rate)

1초 동안 전송된 비트 수를 의미하는 속도 측정.

주파수(Frequency)에 대응하는 개념. 단위: bps (bits per second)

예) 비트율 8bps → 비트 간격 = 1/8 = 0.125초

Hz vs bps

전송 매체의 동일한 성질을 서로 다른 척도로 나타낸 것.

  • 아날로그 신호 전송 → Hz (아날로그 대역폭)
  • 디지털 신호 전송 → bps (디지털 대역폭)

푸리에 해석과 디지털 신호

비주기 신호는 주파수 영역에서 무한 개의 주파수 성분을 더해야만 만들 수 있다 (푸리에 해석). 즉, 디지털 신호를 완벽하게 전송하려면 이론상 무한한 대역폭이 필요하지만, 실제 전송 매체는 대역폭이 제한되어 있다.

📊 채널 용량 (Channel Capacity)

채널 용량이란?

전송 매체가 전송할 수 있는 최대 비트율. 다음 3가지 요소에 의해 결정된다.

① 대역폭

아날로그: Hz, 디지털: bps

② 신호 준위 수 (L)

부호화 방법에 따른 신호 레벨 수

2ⁿ = L  →  n = log₂L

n: 비트 수, L: 신호 레벨 수

③ 채널 품질

잡음의 정도 (S/N비)

① 나이퀴스트 비트율 (무잡음 채널)

C = 2W × log₂L
C: 채널 용량 (bps) W: 채널의 대역폭 (Hz) L: 신호 레벨 수 (부호화 방법)

나이퀴스트 비트율은 이론적인 최대 전송율을 정의한다. 무잡음 채널을 가정한 공식이다.

② 섀넌 용량 (잡음이 있는 채널)

C = W × log₂(1 + S/N)
C: 채널 용량 (bps) W: 채널의 대역폭 (Hz) S/N: 신호 대 잡음비 (Signal-to-Noise Ratio, SNR)

데시벨(dB) 공식

전력비

dB = 10 × log₁₀(P₂/P₁)

전압비

dB = 20 × log₁₀(V₂/V₁)

전류비

dB = 20 × log₁₀(I₂/I₁)

SNR dB 변환: SNRdB = 10 × log₁₀(S/N)
• 10dB → S/N = 10  |  20dB → S/N = 100  |  30dB → S/N = 1000
• 예) P₁=10W, P₂=100W → 10×log₁₀(100/10) = 10dB

채널 용량을 향상시키는 방법

  • 대역폭(W)을 늘린다.
  • 신호 크기(S)를 크게 한다.
  • 잡음 크기(N)를 작게 한다.
⚡ 전송 손상 (Transmission Impairment)

신호가 목적지로 전달되는 과정에서 여러 가지 이유로 인해 신호에 손상이 발생한다.

① 감쇠 (Attenuation)

신호의 크기가 거리에 따라 작아지는 현상.

유선 매체

신호의 세기가 거리에 따라 처음에는 급격하게, 점차 완만하게 감소

무선 매체

거리와 주변 대기 환경에도 영향을 받음. 자유공간에서 손실 L은 거리의 제곱에 비례

증폭기 (Amplifier)

아날로그 신호 증폭 → 잡음도 함께 증폭

리피터 (Repeater)

디지털 신호 재생 → 비트 오류 발생 가능

감쇠량 dB 표현

dB = 10 × log₁₀(P₂/P₁)

P₁: 송신 전력, P₂: 수신 전력 (P₂ < P₁ → dB 값은 음수)

예) 전력이 절반으로 감소 → 10×log₁₀(0.5) = −3dB

② 왜곡 (Distortion)

신호의 모양이나 형태가 변형되는 것.

감쇠 왜곡

주파수 스펙트럼에 따라 감쇠의 정도가 균일하지 못해 발생. 디지털보다 아날로그에서 심각.
등화기(Equalizer)로 보완.

지연 왜곡

신호의 전달속도가 주파수에 따라 변하는 현상. 디지털 신호에서 심각.

③ 잡음 (Noise)

신호를 전송하는 과정에서 발생하는 원하지 않는 신호. 4가지 종류가 있다.

열잡음 (Thermal Noise)

전도체 내부의 전자들이 열에 의해 불규칙하게 움직이면서 나타나는 잡음. 모든 주파수 범위에 균일한 전력 스펙트럼을 가지며, 제거될 수 없다.

= 백색잡음(White Noise)

N = K × T × W

K: 볼츠만 상수 · T: 절대온도(K) · W: 대역폭(Hz)

상호 변조 잡음
(Inter-modulation Noise)

동일한 전송 매체에서 서로 다른 주파수들이 전송될 때 주파수의 합·차·배수에 해당하는 새로운 주파수가 생성되어 발생하는 잡음. 통신 시스템의 선형성이 불완전하기 때문에 발생.

누화 (Crosstalk)

서로 다른 신호 채널의 전자기파가 서로 영향을 주어 발생하는 현상. 전화 통화 중 다른 사람의 말이 약하게 들리는 혼선과 같은 현상.

충격 잡음 (Impulse Noise)

번개, 기계적 충격 등 예측할 수 없는 외부 요인에 의해 발생하는 돌발적인 잡음. 순간적이지만 크기가 크다. 디지털 전송에서 다수 비트의 집단적 오류를 일으킬 수 있다.

📝 예제 풀이
예제 3-1  |  정현파의 진폭·주파수·위상 구하기
다음 조건의 파형에 대한 신호 식을 써보시오.
① A=3, f=5Hz, φ=0°   ② A=6, f=10Hz, φ=0°   ③ A=4, f=3Hz, φ=180°
① s(t) = 3 sin(2π·5·t + 0°) = 3 sin(10πt)
② s(t) = 6 sin(2π·10·t + 0°) = 6 sin(20πt)
③ s(t) = 4 sin(2π·3·t + 180°) = 4 sin(6πt + 180°)
예제 3-2  |  주파수 영역에서 대역폭 계산
어떤 신호의 주파수 성분이 1Hz ~ 11Hz 범위에 존재할 때, 대역폭을 구하시오.
대역폭 = 최고 주파수 − 최저 주파수
= 11 − 1 = 10 Hz
예제 3-3  |  비트율로 비트 간격 계산
디지털 신호의 비트율이 2,000 bps일 때 비트 간격을 계산하시오.
비트 간격 = 1 / 비트율 = 1 / 2,000 = 0.0005초
= 500 μs
예제 3-4  |  나이퀴스트 비트율 계산
디지털 신호 레벨 수 L = 8이고, 채널 대역폭이 1 KHz일 때 이론적 최대 전송율을 계산하시오.
C = 2W log₂L = 2 × 1,000 × log₂8 = 2 × 1,000 × 3
= 6,000 bps = 6 Kbps
예제 3-5  |  나이퀴스트 — 신호 레벨 수 역산
채널 대역폭이 400 Hz이고 원하는 전송율이 3,200 bps일 때 필요한 신호 레벨 수 L을 구하시오.
(단, 잡음의 영향은 없다고 가정)
C = 2W log₂L  →  3,200 = 2 × 400 × log₂L
3,200 = 800 × log₂L  →  log₂L = 4  →  L = 2⁴ = 16
예제 3-6  |  섀넌 용량 계산
대역폭 3 KHz, SNR = 30 dB인 음성급 채널의 채널 용량을 계산하시오.
① SNR 변환: 30 = 10 × log₁₀(S/N) → S/N = 10³ = 1,000
② C = W log₂(1 + S/N) = 3,000 × log₂(1,001)
   = 3,000 × 9.967 ≈ 29,901 bps ≈ 29.9 Kbps
예제 3-7  |  감쇠량 dB 계산
신호가 전송 매체를 통해 목적지에 도착했을 때 전력이 절반으로 감소하였다. 신호 감쇠를 계산하라.
P₂ = 0.5 × P₁ 이므로
dB = 10 × log₁₀(P₂/P₁) = 10 × log₁₀(0.5)
= 10 × (−0.301) = −3 dB
(음수 = 신호 손실, 전력이 절반 감소 시 항상 약 −3 dB)
🔥 핵심 캐치 & 시험 포인트
⭐ 나이퀴스트 vs 섀넌 — 구분법
  • 나이퀴스트: 무잡음 채널, L(신호 레벨 수)가 변수 → C = 2W log₂L
  • 섀넌: 잡음 있는 채널, S/N비가 변수 → C = W log₂(1 + S/N)
  • 실제 채널 용량 = min(나이퀴스트, 섀넌)
⭐ dB 변환 공식

SNRdB = 10 × log₁₀(S/N)

  • 10dB → S/N = 10
  • 20dB → S/N = 100
  • 30dB → S/N = 1000
⭐ 아날로그 신호 3요소 (정현파)

진폭(Amplitude) · 주파수(Frequency) · 위상(Phase)
→ 이 3가지로 정현파를 완전히 정의할 수 있다.

⭐ 열잡음의 특징

모든 주파수 범위에서 균일 → 백색잡음(White Noise) 불림.
제거 불가능하다는 점이 핵심!

⭐ 감쇠 왜곡 vs 지연 왜곡 — 어디서 심각한가?

• 감쇠 왜곡: 아날로그 신호에서 더 심각
• 지연 왜곡: 디지털 신호에서 더 심각

⭐ 증폭기 vs 리피터 비교

• 증폭기(Amplifier): 아날로그 신호 처리, 잡음도 함께 증폭
• 리피터(Repeater): 디지털 신호 처리, 신호를 재생(재생성), 비트 오류 가능

⭐ 감쇠 −3dB의 의미

전력이 절반으로 감소하면 항상 약 −3 dB이다.
10 × log₁₀(0.5) = 10 × (−0.301) ≈ −3 dB
→ dB 값이 음수면 신호 손실, 양수면 신호 증폭

⭐ 신호 준위 수 L과 비트 수 n의 관계

2ⁿ = L  →  n = log₂L
예) L=8 (8가지 신호 레벨) → n = log₂8 = 3비트
예) L=16 → n = 4비트  |  L=2 → n = 1비트

⭐ 나이퀴스트로 L 역산하는 법

C = 2W log₂L 에서 L을 구하려면:
log₂L = C / (2W) → L = 2^(C/2W)
예) C=3200bps, W=400Hz → log₂L = 4 → L = 16

📚 핵심 키워드
Analog Signal
아날로그 신호
연속적인 파형으로 시간에 따라 연속적으로 변화하는 신호. 주기적 아날로그 신호의 기본 형태는 정현파(Sine Wave).
Digital Signal
디지털 신호
이산적인 파형으로 순간적으로 변화하는 신호. 대부분 비주기적이며 비트 간격과 비트율로 표현한다.
Amplitude
진폭
파형의 높이. 신호의 세기를 의미한다. 정현파를 정의하는 3요소 중 하나(진폭·주파수·위상).
Frequency / Period
주파수 / 주기
주파수(f): 초당 반복되는 사이클 수(Hz). 주기(T): 한 사이클 완성에 걸리는 시간(초). T = 1/f.
Phase
위상
시각 0시에 대한 파형의 상대적인 위치. 도(°) 또는 라디안(rad)으로 측정.
Bandwidth
대역폭
신호가 가진 주파수 성분의 범위(최고 - 최저 주파수). 아날로그: Hz, 디지털: bps로 표현.
Bit Rate / Bit Interval
비트율 / 비트 간격
비트율: 1초간 전송된 비트 수(bps). 비트 간격: 비트 1개 전송 시간. 디지털에서 주파수·주기에 대응하는 개념.
Nyquist Bit Rate
나이퀴스트 비트율
무잡음 채널의 이론적 최대 전송율. C = 2W log₂L. W: 대역폭(Hz), L: 신호 레벨 수.
Shannon Capacity
섀넌 용량
잡음이 있는 채널의 최대 전송율. C = W log₂(1+S/N). SNR이 높을수록 용량이 커진다.
SNR (Signal-to-Noise Ratio)
신호 대 잡음비
신호 크기와 잡음 크기의 비율. dB 단위: SNR_dB = 10×log₁₀(S/N). 20dB → SNR = 100.
Attenuation
감쇠
신호의 크기가 거리에 따라 작아지는 현상. 증폭기(아날로그)나 리피터(디지털)로 보상한다.
Thermal Noise (White Noise)
열잡음 (백색잡음)
전도체 내 전자의 열운동으로 발생. 모든 주파수에서 균일한 스펙트럼. 제거 불가능.
Crosstalk
누화
서로 다른 신호 채널의 전자기파가 서로 영향을 주어 발생하는 현상. 전화 혼선이 대표적 예.
Impulse Noise
충격 잡음
번개·기계 충격 등 예측 불가 외부 요인으로 발생하는 돌발적 잡음. 디지털 전송에서 집단 비트 오류 유발.
Fourier Analysis
푸리에 해석
복합 신호를 주파수 영역으로 분해하는 수학적 기법. 조제프 푸리에가 정립. 신호의 주파수 스펙트럼 표현에 사용.
✏️ 연습문제
Q1. 아날로그 신호의 3가지 특성이 아닌 것은?
비트율은 디지털 신호의 특성입니다. 정현파(아날로그 신호)는 진폭, 주파수, 위상으로 정의됩니다.
Q2. 주기 T와 주파수 f의 관계로 옳은 것은?
Q3. 나이퀴스트 비트율 공식으로 옳은 것은?
나이퀴스트(무잡음): C = 2W log₂L, 섀넌(잡음 있음): C = W log₂(1+S/N)
Q4. S/N비가 30dB일 때, 실제 S/N 비율은?
30dB = 10×log₁₀(S/N) → log₁₀(S/N) = 3 → S/N = 10³ = 1000
Q5. 다음 잡음 중 제거가 불가능하며 '백색잡음'이라고도 불리는 것은?
열잡음은 전도체 내 전자의 열운동으로 항상 발생하며 제거 불가능합니다. 모든 주파수에서 균일한 전력 스펙트럼을 가져 백색잡음이라고 합니다.
Q6. 다음 중 왜곡(Distortion)의 종류에 해당하지 않는 것은?
왜곡의 종류는 감쇠 왜곡과 지연 왜곡 2가지입니다. '충격 잡음'은 왜곡이 아닌 잡음(Noise)의 종류입니다.
Q7. [단답형] 아날로그 신호를 증폭할 때 사용하는 장치의 이름은? (한글로 입력)
Q8. [단답형] 전화 통화 중 다른 사람의 말이 약하게 들리는 혼선 현상은 어떤 잡음인가?
Q9. [단답형] 복합 신호의 주파수 성분을 분석하는 데 사용하는 수학적 기법의 이름은?
Q10. [계산] 채널 대역폭 W=2KHz, 신호 레벨 수 L=4일 때 나이퀴스트 비트율 C는?
C = 2W log₂L = 2 × 2,000 × log₂4 = 4,000 × 2 = 8,000 bps = 8 Kbps (log₂4 = 2)
Q11. [계산] SNR이 30dB일 때, 실제 S/N 비율은?
30dB = 10 × log₁₀(S/N) → log₁₀(S/N) = 3 → S/N = 10³ = 1,000
Q12. [계산] 비트율이 4,000 bps일 때 비트 간격은?
비트 간격 = 1 / 4,000 = 0.00025초 = 250 μs
Q13. [단답형] 신호 전력이 절반으로 감소했을 때 감쇠량은 몇 dB인가? (정수로 입력)
