📌 핵심 요약

OSI 참조 모델이란?

1984년 ISO에서 이기종 컴퓨터 간 통신을 가능하게 하기 위해 개발한 통신 프로토콜 표준 모델. 통신의 전 과정을 7개 계층으로 분리하여 정의한다.

참조 모델 vs 실제 표준

OSI는 실제 사용되는 프로토콜로 개발되지 못하였지만, 통신 프로토콜을 이해하고 설명하는 기준 모델로 사용된다. 실제적인 표준은 TCP/IP이다.

계층화의 개념

하나의 일을 수행하기 위해 관련 기능들을 모아 그룹화한 구조. 각 계층은 인접한 하위 계층의 서비스를 이용하고, 바로 위 계층에 서비스를 제공한다.

중간 노드의 동작 범위

중간 노드(라우터 등)들은 3계층(네트워크 계층)까지만 동작하며, 종단 간 연결을 위한 상위 계층은 종단 시스템에서만 동작한다.

캡슐화 (Encapsulation)

전송 데이터에 각 계층의 제어 정보(헤더)를 추가하여 다음 계층으로 전달하는 과정. 2계층에서는 오류 제어를 위한 트레일러도 추가한다.

데이터 단위

  • SDU: 상·하위 계층 간 인터페이스를 통해 전달되는 실제 정보
  • PDU: 동일 계층 간에 운반(교환)되는 데이터
    (PDU = SDU + 헤더)

5 세션 계층

4 전송 계층

3 네트워크 계층

2 데이터링크 계층
Data Link		 인접 노드 사이의 데이터 전송 기능 수행. 인접 노드 사이의 오류 제어, 흐름 제어, 전송 제어. 트레일러 추가

Physical		 물리적인 전송로를 제공. 전송 방식: 신호 형태, 케이블 형태 등 물리적인 전송 매체를 통해 데이터를 목적지까지 전송하기 위해 필요한 기능들을 제어
💡 주요 개념

프로토콜 (Protocol)

각 계층의 프로토콜은 동일 계층 사이(peer-to-peer)에 존재한다. 같은 계층끼리 약속된 규칙으로 통신한다.

인터페이스 (Interface)

동일한 장치 내에서 다른 계층과 상호작용하는 것. 같은 장치 안의 인접 계층 간 연결 방식.

서비스 프리미티브
(Service Primitive)

인터페이스를 통해 이루어지는 계층 간 상호 작용을 추상화하여 단순한 모습으로 제공하기 위한 서비스 단위.

SDU vs PDU

  • SDU (Service Data Unit): 상·하위 계층 간 인터페이스를 통해 전달되는 실제 정보
  • PDU (Protocol Data Unit): 동일 계층 간에 운반되는 데이터
    PDU = SDU + 헤더

캡슐화 (Encapsulation)

전송 데이터에 각 계층의 요구 조건과 처리 정보를 포함하는 헤더를 추가하며 하위 계층으로 전달. 2계층은 트레일러도 추가.

역캡슐화 (Decapsulation)

수신 측에서 각 계층이 자신의 헤더를 제거하며 상위 계층으로 데이터를 전달하는 과정. 캡슐화의 반대 과정.

캡슐화 과정 (송신 측)

7 응용 데이터 ← 사용자 데이터 생성
6 표현 H6 데이터
5 세션 H5 H6 데이터
4 전송 H4 … → 세그먼트 (Segment)
3 네트워크 H3 … → 패킷 (Packet)
2 데이터링크 H2 … T2 → 프레임 (Frame) + 트레일러
1 물리 비트(Bit) 스트림으로 전송

⭐ OSI vs TCP/IP 핵심 차이

OSI는 참조 모델(이해·설명 기준), TCP/IP는 실제 표준. OSI가 1984년 ISO에서 먼저 나왔으나, 실제 인터넷은 TCP/IP 기반으로 동작한다.

⭐ 오류 제어 범위 구분

• 데이터링크 계층(2): 인접 노드 사이의 오류 제어, 흐름 제어
• 전송 계층(4): 종단 간(end-to-end)의 오류 제어, 흐름 제어

⭐ 트레일러는 2계층(데이터링크)에서만!

헤더는 모든 계층에서 추가하지만, 트레일러(오류 제어용)는 2계층 데이터링크 계층에서만 추가한다.

⭐ 중간 노드는 3계층까지만 동작

라우터 같은 중간 노드는 1~3계층(물리·데이터링크·네트워크)까지만 처리한다. 4~7계층은 종단 시스템(호스트)에서만 동작한다.

OSI Reference Model
OSI 참조 모델
1984년 ISO에서 이기종 컴퓨터 간 통신 표준화를 위해 개발한 7계층 네트워크 구조 모델. 실제 프로토콜은 아니며 참조·이해용 기준 모델.
Protocol
프로토콜
동일 계층(peer-to-peer) 사이에 존재하는 통신 규약. 서로 다른 시스템 간에 데이터를 교환하기 위한 규칙의 집합.
Interface
인터페이스
동일한 장치 내에서 인접한 계층들이 상호 작용하는 방식. 같은 기계 안에서 계층 간 통신 방법.
Service Primitive
서비스 프리미티브
인터페이스를 통한 계층 간 상호 작용을 추상화한 서비스 단위. 계층 간 교환되는 기본적인 서비스 요청/응답 형식.
Encapsulation / Decapsulation
캡슐화 / 역캡슐화
캡슐화: 송신 시 각 계층이 헤더(+트레일러)를 추가하는 과정. 역캡슐화: 수신 시 각 계층이 자신의 헤더를 제거하는 과정.
SDU (Service Data Unit)
서비스 데이터 단위
상위 계층과 하위 계층 간의 인터페이스를 통해 전달되는 실제 정보(페이로드).
PDU (Protocol Data Unit)
프로토콜 데이터 단위
동일 계층 간에 운반(교환)되는 데이터. PDU = SDU + 헤더. 계층마다 다른 이름(패킷, 프레임, 비트 등)으로 불린다.
Header / Trailer
헤더 / 트레일러
헤더: 각 계층이 캡슐화 시 추가하는 제어 정보. 트레일러: 2계층(데이터링크)에서 오류 제어를 위해 데이터 뒤에 추가하는 정보.
