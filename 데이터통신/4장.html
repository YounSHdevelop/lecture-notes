데이터통신 4장 — 신호 변환

Signal Conversion · 디지털/아날로그 신호의 변환과 변조 기법

🎯 학습 목표

1

디지털 전송(기저대역)과 아날로그 전송(광대역)의 개념을 구분하고 각각의 특성을 설명할 수 있다.

2

회선 부호화의 다양한 방식(단극형, 극형, 양극형, 블록코드형, 멀티레벨형)을 이해하고, 각 방식의 특징과 파형을 설명할 수 있다.

3

디지털 데이터를 아날로그 신호로 변조(ASK, FSK, PSK, QAM)하는 방법을 설명하고, 비트율과 보오율 관계를 계산할 수 있다.

4

아날로그 신호를 디지털로 변환하는 PCM 과정(표본화 → 양자화 → 부호화)과 관련 공식을 이해하고 적용할 수 있다.

5

아날로그-아날로그 변조(AM, FM, PM)의 원리와 특성을 설명할 수 있다.

6

각 신호 변환 기법에 관련된 수식 및 예제 문제를 해결할 수 있다.

📌 핵심 요약

디지털 전송 (Baseband / 기저대역)

  • 디지털 신호를 변조 없이 직접 전송
  • 저역 대역폭 사용 (0 Hz부터 시작)
  • 회선 부호화(Line Coding) 사용
  • 근거리 통신(LAN)에 적합
  • 예: 이더넷 케이블 전송

아날로그 전송 (Broadband / 광대역)

  • 디지털 신호를 아날로그 반송파에 실어 전송
  • 고주파 대역 사용 (대역 이동/분리 가능)
  • 변조(Modulation) 기술 사용
  • 원거리 통신, 무선에 적합
  • 예: AM/FM 라디오, 모뎀

비트율 vs 보오율

비트율(Bit Rate): 초당 전송 비트 수 [bps]

보오율(Baud Rate): 초당 신호 변화 수 [baud]

비트율 = n × 보오율
n = log₂L (L = 신호 레벨 수)

4가지 신호 변환 유형

  • 디지털 → 디지털: 회선 부호화
  • 디지털 → 아날로그: ASK / FSK / PSK / QAM
  • 아날로그 → 디지털: PCM, 델타변조
  • 아날로그 → 아날로그: AM / FM / PM

PCM 핵심 공식 모음

표본화 정리: fs ≥ 2fm
양자화 레벨: L = 2n
PCM 비트율: fs × nb bps
SNRdB = 6.02nb + 1.76

회선 부호화 분류

  • 단극형: Unipolar NRZ
  • 극형: NRZ-L, NRZ-I, RZ, 맨체스터, 차등맨체스터
  • 양극형: AMI, B8ZS, HDB3
  • 블록코드형: 4B/5B, 8B/10B
  • 멀티레벨형: 2B1Q

변조 방식 요약

  • ASK: 진폭으로 데이터 구분
  • FSK: 주파수로 데이터 구분
  • PSK: 위상으로 데이터 구분
  • QAM: 진폭 + 위상 동시 변조 (가장 효율적)

아날로그 변조 요약

  • AM: 반송파 진폭 변화, B = 2fm
  • FM: 반송파 주파수 변화, 고품질
  • PM: 반송파 위상 변화, FM과 수학적 연관

FM/PM은 서로 밀접히 연관됨

💻 회선 부호화 (Line Coding)

디지털 데이터를 디지털 신호로 변환하는 과정. 송신측에서 비트열을 전기적 파형으로 변환하고 수신측에서 복원한다.

회선 부호화의 주요 특성

기저대역 대역폭

비트율 N이 주어질 때, NRZ 신호의 최소 대역폭은 N/2 Hz. 대역폭이 클수록 더 높은 비트율 지원 가능하다.

DC 성분

직류(DC) 성분이 없어야 한다. DC 성분이 있으면 변압기를 통과하지 못하고 전력 소비가 증가한다.

자기 동기화 (Self-Synchronization)

수신측이 별도 채널 없이 데이터에서 클록을 추출할 수 있어야 한다. 맨체스터 방식이 대표적이다.

오류 감지 능력

일부 방식은 전송 중 오류를 내장 감지할 수 있다. 예: AMI에서 동일 극성 연속 출현 = 오류.

1. 단극형 (Unipolar) — NRZ DC 성분 문제

Unipolar NRZ (Non-Return-to-Zero)

  • 양전압 하나만 사용 (0V = 0, +V = 1)
  • 구현 단순하지만 DC 성분 문제 심각
  • 연속 0 또는 1일 때 클록 동기화 불가
  • 실용성 낮아 현재 거의 사용하지 않음
비트열: 1 1 0 0 1 0 1 ┌───┐ ┌───┐ ┌───┐ +V │ │ │ │ │ │ 0 ────┘ └───┘ └───────┘ └───

2. 극형 (Polar) — 양/음 전압 사용 DC 성분 감소

방식 원리 특징 장단점
NRZ-L
Non-Return-to-Zero Level		 0 = +V, 1 = −V
(또는 반대)		 신호 레벨로 비트 결정 구현 간단. DC 성분 존재. 클록 동기 어려움.
NRZ-I
Non-Return-to-Zero Inversion		 1이 나타날 때 신호 반전
0이면 현재 레벨 유지		 신호 변화로 비트 결정 연속 1에 강함. 연속 0에는 취약.
RZ
Return-to-Zero		 1 = +V → 0 (중간 복귀)
0 = −V → 0 (중간 복귀)		 매 비트 중간에 0으로 복귀 자기 동기화 가능. NRZ의 2배 대역폭 필요.
맨체스터
Manchester		 0 = 양→음 전이
1 = 음→양 전이
(비트 중앙에서 전이)		 매 비트 중앙에 반드시 전이 자기 동기화 우수. 이더넷(10BASE-T) 사용. RZ의 두 배 대역폭.
차등 맨체스터
Differential Manchester		 0 = 비트 시작 추가 전이
1 = 비트 시작 전이 없음
(중간 전이는 항상 존재)		 비트 시작점 전이 유무로 판단 자기 동기화, 노이즈에 강함. 토큰링(Token Ring) 사용.
비트열: 1 0 1 1 0 0 1 NRZ-L (1=−V, 0=+V): ┌──────┐ ┌─────────────┐ +V │ │ │ │ −V ─────┘ └──────┘ └────── NRZ-I (초기=+V, 1마다 반전): ┌──────┐ ┌─────────────┐ ┌ +V │ │ │ │ │ −V ─────┘ └──────┘ └──────┘ 맨체스터 (0=↓, 1=↑, 중앙에서 전이): ┌──┐ ┌┐ ┌──┐ ┌──┐ ┌┐ ┌┐ ┌ │ │ ││ │ │ │ │ ││ ││ │ ────────┘ └───┘└──┘ └──┘ └───┘└───┘└──┘

3. 양극형 (Bipolar) — 3전압 레벨 오류 감지 가능

AMI (Alternate Mark Inversion)

  • 0 = 0V (전압 없음)
  • 1 = 교대로 +V, −V
  • 연속된 1은 반드시 극성 교대
  • DC 성분 없음 → 장거리 전송 유리
  • 오류 감지: 같은 극성 연속 출현 = 오류
  • 약점: 연속 0일 때 동기화 어려움
비트열: 1 0 1 1 0 0 1 ┌──────┐ ┌──────┐ ┌ +V │ │ │ │ │ 0 ────┘ ─── ┘ └───────┘ (−V 부분: 다음 1에서 −V로 교대)

B8ZS (Bipolar 8-Zero Substitution)

  • AMI 기반, 8개의 연속 0 대체
  • 북미 T-캐리어(T1)에 사용
  • 이전 펄스 +면: 000+−0−+ 패턴으로 대체
  • 이전 펄스 −면: 000−+0+− 패턴으로 대체
  • 의도적 AMI 규칙 위반으로 수신측이 감지

HDB3 (High-Density Bipolar 3)

  • AMI 기반, 4개의 연속 0 대체
  • 유럽 E-캐리어(E1)에 사용
  • 4개 0 → 000V 또는 B00V 패턴으로 대체
  • V = 위반 펄스, B = 정상 펄스
  • 이전 위반 이후 1의 개수에 따라 패턴 선택

4. 블록코드형 (Block Coding) 중복성 추가

4B/5B

  • 4비트 데이터 → 5비트 코드로 변환
  • 연속 0이 3개 이상 없는 코드만 사용 (32개 중 16개 선택)
  • 대역폭 25% 증가 (5/4배)
  • 동기화 문제 해결
  • FDDI, Fast Ethernet(100BASE-TX)에서 NRZ-I와 함께 사용
효율 = 4/5 = 80%

8B/10B

  • 8비트 → 10비트로 변환 (5B/6B + 3B/4B 두 단계)
  • 기가비트 이더넷(1000BASE-T), USB에 사용
  • DC 균형 유지 (0과 1의 개수 균등)
  • 오류 감지 능력 강화
효율 = 8/10 = 80%

5. 멀티레벨형 (Multilevel) — 2B1Q 4레벨 신호

2B1Q (Two Binary, One Quaternary)

2비트를 4레벨 신호 1개로 변환. DSL(디지털 가입자 회선)에 사용.

2비트 조합신호 레벨전압
00−3−3V
01−1−1V
11+1+1V
10+3+3V
n = log₂4 = 2 → 비트율 = 2 × 보오율

비트율 vs 보오율 관계 정리

핵심 공식

비트율 = log₂(L) × 보오율
L = 신호 레벨 수
  • L=2 (2레벨, NRZ): 비트율 = 보오율
  • L=4 (4레벨, 2B1Q): 비트율 = 2 × 보오율
  • L=8 (8레벨): 비트율 = 3 × 보오율

방식별 최소 대역폭 비교

  • NRZ: Bmin = N/2 Hz
  • RZ / 맨체스터: Bmin = N Hz (NRZ의 2배)

맨체스터는 대역폭이 넓지만 자기동기화 우수 → 이더넷 선호

📡 디지털→아날로그 변조 (Digital-to-Analog)

디지털 신호를 고주파 아날로그 반송파(carrier wave)에 실어 전송하는 변조 방식. 반송파 s(t) = A·cos(2πft + φ)에서 A(진폭), f(주파수), φ(위상) 중 하나 이상을 변화시킨다.

ASK 진폭편이변조

Amplitude Shift Keying

  • 반송파 진폭(A)을 변화시켜 데이터 표현
  • 0 = 낮은 진폭(또는 0), 1 = 높은 진폭
  • 노이즈에 취약 (진폭 변화에 민감)
  • 광섬유 전송에 주로 사용
  • OOK(On-Off Keying): 0 = 반송파 없음

FSK 주파수편이변조

Frequency Shift Keying

  • 반송파 주파수(f)를 변화시켜 데이터 표현
  • 0 = 낮은 주파수 f₁, 1 = 높은 주파수 f₂
  • ASK보다 노이즈에 강함
  • 구현 간단, 고속에는 부적합
  • 초기 모뎀, VHF 라디오에 사용

PSK 위상편이변조

Phase Shift Keying

  • 반송파 위상(φ)을 변화시켜 데이터 표현
  • BPSK: 2위상 (0°,180°) — 1비트/신호
  • QPSK: 4위상 (0°,90°,180°,270°) — 2비트/신호
  • 8-PSK: 8위상 — 3비트/신호
  • 노이즈에 강하고 대역폭 효율적

QAM (Quadrature Amplitude Modulation) 진폭+위상 동시 변조

QAM 원리

  • 진폭(A)과 위상(φ) 동시에 변조 = ASK + PSK 결합
  • 4-QAM: 2비트/신호 (= QPSK)
  • 16-QAM: 4비트/신호
  • 64-QAM: 6비트/신호
  • 256-QAM: 8비트/신호
  • 케이블 TV, ADSL, LTE, 5G에 사용

비트율–보오율 관계 (변조)

비트율 = n × 보오율
n = log₂(신호 상태 수)
  • QPSK: n=2, 비트율 = 2 × 보오율
  • 8-PSK: n=3, 비트율 = 3 × 보오율
  • 16-QAM: n=4, 비트율 = 4 × 보오율
  • 64-QAM: n=6, 비트율 = 6 × 보오율

성상도 (Constellation Diagram)

성상도 읽는 법

X축 = 동위상 성분(I), Y축 = 직교 성분(Q). 각 점 = 하나의 신호 상태(보오).

BPSK (2점): QPSK (4점): 16-QAM (16점): Q Q Q | 01× ×00 × × × × | | × × × × ×───────×I ───────┼───────I ───┼───────I (180°, 0°) | × × × × 11× ×10 × × × × 1비트/보오 2비트/보오 4비트/보오 점이 많을수록 → 더 많은 비트/보오 → 더 좁은 간격 → 노이즈에 취약

🎙️ 아날로그→디지털 변환 (PCM)

아날로그 신호를 디지털로 변환하는 표준 기법 — PCM(Pulse Code Modulation, 펄스 부호 변조). 전화망(T1/E1), CD 오디오 등에 광범위하게 사용된다.

1. 표본화 (Sampling) — 나이퀴스트 정리

표본화 정리 (Nyquist Sampling Theorem)

fs ≥ 2fm
fs = 표본화 주파수, fm = 원 신호 최고 주파수
  • 나이퀴스트율(Nyquist rate) = 2fm (최소값)
  • 전화 음성(최대 4kHz) → 표본화: 8,000 Hz
  • CD 오디오(최대 22kHz) → 표본화: 44,100 Hz

에일리어싱 (Aliasing)

  • fs < 2fm 이면 원 신호 복원 불가
  • 복원 신호에 저주파 왜곡 발생
  • 해결: 표본화 전 저역통과 필터(Anti-aliasing filter) 적용
  • 고속으로 변하는 성분이 느리게 보이는 현상

2. 양자화 (Quantization)

양자화 과정

  • 신호 범위를 L개의 구간으로 균등 분할
  • 각 표본값을 가장 가까운 레벨로 근사
  • L = 2ⁿ, n = 비트 수
  • n↑ → 정밀도↑, 비트율↑
양자화 레벨 수: L = 2n
비트 수: n = log₂L

SNR (신호 대 잡음비)

SNRdB = 6.02 · nb + 1.76
nb = 비트 수
  • 비트 수 1 증가 → SNR 약 6 dB 향상
  • 8비트: SNR ≈ 49.9 dB
  • 16비트: SNR ≈ 98.1 dB (CD 품질)

3. PCM 비트율 계산

PCM 비트율 공식

비트율 = fs × nb [bps]
fs = 표본화 주파수 [Hz], nb = 샘플당 비트 수
  • 전화 음성 (8kHz, 8비트): 8,000 × 8 = 64 kbps (DS0)
  • CD 오디오 (44.1kHz, 16비트, 스테레오): 44,100 × 16 × 2 = 1.41 Mbps

4. 델타 변조 (Delta Modulation)

델타 변조 원리

  • PCM의 단순화된 형태
  • 이전 값보다 크면 1, 작으면 0만 전송 (1비트)
  • 계단 근사(staircase approximation)로 신호 추적
  • 구현 매우 간단
  • 변화가 빠른 신호에는 경사 과부하 발생

델타 변조 문제점

  • 경사 과부하(Slope Overload): 신호 변화가 너무 빠를 때 추적 불가
  • 입도 잡음(Granular Noise): 신호가 일정할 때 1과 0을 번갈아 출력
  • 해결: 적응형 델타 변조(ADM) — 스텝 크기를 신호에 맞게 동적 조정

📻 아날로그→아날로그 변조 (Analog-to-Analog)

아날로그 정보 신호를 더 높은 주파수의 반송파(carrier)에 실어 전송. 반송파: s(t) = A·cos(2πfct + φ). A, fc, φ 중 하나를 정보 신호로 변화시킨다.

AM (진폭 변조)

Amplitude Modulation

  • 반송파의 진폭(A)을 정보 신호에 비례하여 변화
  • 주파수와 위상은 일정 유지
  • 필요 대역폭 = 2fm
  • 구현 간단, 노이즈에 취약
  • AM 라디오(530~1700 kHz) 사용
BAM = 2fm

FM (주파수 변조)

Frequency Modulation

  • 반송파의 주파수(f)를 정보 신호에 비례하여 변화
  • 진폭과 위상은 일정 유지
  • 필요 대역폭 = 2(1+β)fm
  • AM보다 노이즈에 훨씬 강함
  • FM 라디오(88~108 MHz), 무선 통신에 사용
BFM = 2(1+β)fm

PM (위상 변조)

Phase Modulation

  • 반송파의 위상(φ)을 정보 신호에 비례하여 변화
  • 진폭과 주파수는 일정 유지
  • FM과 수학적으로 밀접히 연관
  • PM: 위상 변화량 ∝ 신호값
  • FM: 위상 변화량 ∝ 신호의 적분값
  • 위성 통신, 일부 모뎀에 사용

⚡ 핵심 캐치 — 시험 포인트

📐

표본화 정리 공식

fs ≥ 2fm. 최고 주파수의 2배 이상 표본화해야 원 신호 완벽 복원 가능. 이 최소값이 나이퀴스트율.

🎯

SNR 공식 (자주 출제)

SNRdB = 6.02nb + 1.76. 비트 수 1 증가 → SNR 약 6 dB 향상. 계산 문제 자주 출제!

⚡

비트율 vs 보오율

비트율 = n × 보오율 (n = log₂L). QAM이 PSK보다 대역폭 효율이 좋은 이유 — 더 많은 비트를 한 신호에 담음.

🔄

맨체스터 vs 차등 맨체스터

맨체스터: 비트 중앙에서 전이(0=↓, 1=↑). 차등 맨체스터: 0=시작점에 추가 전이, 1=시작점 전이 없음. 중간 전이는 항상 존재.

🌊

AMI의 특징 3가지

① 1 → 교대 +/−V ② DC 성분 없음 ③ 오류 감지 가능(동일 극성 연속 = 오류). 단, 연속 0에 취약.

📦

B8ZS vs HDB3

B8ZS: 8개 연속 0 대체 (북미 T1). HDB3: 4개 연속 0 대체 (유럽 E1). AMI의 연속 0 동기화 문제 해결.

🔢

4B/5B와 8B/10B 효율 동일

두 방식 모두 효율 80%. 4B/5B = FDDI, Fast Ethernet. 8B/10B = 기가비트 이더넷, USB. 차이: 8B/10B가 DC 균형까지 보장.

📡

QAM이 PSK보다 유리

PSK는 위상만 변조 → 레벨 수 제한(위상 간격 문제). QAM은 진폭+위상 동시 변조 → 더 많은 비트/보오 가능 → 대역폭 효율 우수.

🎵

전화 음성 PCM 표준 (DS0)

음성 0~4kHz → 표본화 8kHz, 8비트 양자화 → 비트율 = 64 kbps. T1 = 24채널 × 64k = 1.544 Mbps.

📻

AM vs FM 대역폭 차이

AM = 2fm (좁음). FM = 2(1+β)fm (넓음 → 더 높은 음질). FM이 AM보다 노이즈에 강한 이유 = 더 넓은 대역폭 활용.

📚 핵심 키워드

Line Coding
회선 부호화
디지털 데이터를 디지털 신호로 변환하는 과정. 비트열을 전기 파형으로 표현.
Baseband / Broadband
기저대역 / 광대역
기저대역: 변조 없이 직접 전송. 광대역: 반송파에 실어 전송. 기저대역 = 디지털 전송.
Baud Rate
보오율
초당 신호 변화 수 [baud]. 비트율 = log₂L × 보오율 (L = 신호 레벨 수).
NRZ-L / NRZ-I
비복귀 레벨형 / 비복귀 반전형
NRZ-L: 신호 레벨로 비트 결정. NRZ-I: 1이 나타날 때마다 신호 반전.
Manchester / Differential Manchester
맨체스터 / 차등 맨체스터
맨체스터: 비트 중앙 전이로 비트 구분(자기동기화). 차등 맨체스터: 시작점 전이 유무로 판단.
AMI (Alternate Mark Inversion)
교대 표시 반전
1을 교대로 +V, −V로 표현. DC 성분 없음. 오류 감지 가능. 연속 0에 동기화 취약.
B8ZS / HDB3
8비트 영 대체 / 고밀도 양극형 3
AMI의 연속 0 문제 해결. B8ZS = 8개 0 대체(북미). HDB3 = 4개 0 대체(유럽).
4B/5B / 8B/10B
블록 코딩
연속 0 방지 재부호화. 효율 80%. 4B/5B = FDDI/Fast Ethernet. 8B/10B = 기가비트 이더넷.
ASK / FSK / PSK / QAM
디지털-아날로그 변조
ASK: 진폭 변조. FSK: 주파수 변조. PSK: 위상 변조. QAM: 진폭+위상 동시 변조(가장 효율적).
PCM (Pulse Code Modulation)
펄스 부호 변조
아날로그→디지털 변환. 표본화 → 양자화 → 부호화. 전화망(DS0=64kbps), CD의 표준 방식.
Nyquist Sampling Theorem
나이퀴스트 표본화 정리
fs ≥ 2fm. 원 신호 최고 주파수의 2배 이상으로 표본화해야 완벽 복원 가능.
Quantization
양자화
표본값을 L=2ⁿ개 이산 레벨로 근사. SNRdB=6.02n+1.76. n↑ → 품질↑ → 비트율↑.
Delta Modulation
델타 변조
1비트로 증가/감소만 표현. 구현 간단. 경사 과부하(slope overload)와 입도 잡음(granular noise) 문제 존재.
AM / FM / PM
진폭 / 주파수 / 위상 변조
아날로그-아날로그 변조. AM = 진폭 변화. FM = 주파수 변화(고품질). PM = 위상 변화. FM과 PM은 수학적으로 연관.
Constellation Diagram
성상도
I(동위상)-Q(직교) 2차원 평면에 신호 상태를 점으로 표현. QAM, PSK 분석에 활용.
Aliasing
에일리어싱
표본화 부족(fs < 2fm) 시 발생. 원 신호 복원 불가, 왜곡. Anti-aliasing 필터로 방지.

📝 예제 풀이

예제 4-1 | 표본화율(나이퀴스트율) 계산

아날로그 신호의 최고 주파수가 4 kHz일 때, 원 신호를 완벽히 복원할 수 있는 최소 표본화율을 구하라.

fs ≥ 2 × fm = 2 × 4,000 = 8,000 Hz
∴ 나이퀴스트율 = 8,000 samples/sec = 8 kHz
예제 4-2 | PCM 비트율 계산 (전화 음성)

음성 신호(최고 주파수 4 kHz)를 PCM으로 변환, 8비트 양자화를 사용할 때 비트율을 구하라.

표본화율 fs = 2 × 4,000 = 8,000 samples/sec
비트율 = fs × nb = 8,000 × 8 = 64,000 bps = 64 kbps
예제 4-3 | 양자화 레벨 수와 SNR

8비트 양자화를 사용할 때 양자화 레벨 수와 SNR(dB)을 구하라.

양자화 레벨 수: L = 2n = 28 = 256 레벨
SNRdB = 6.02 × 8 + 1.76 = 48.16 + 1.76 = 49.92 dB ≈ 49.9 dB
예제 4-4 | 비트율과 보오율 관계 (QPSK)

보오율이 2,000 baud인 시스템에서 QPSK(4위상)를 사용할 때 비트율은?

QPSK: 신호 상태 L = 4 → n = log₂(4) = 2 비트/신호
비트율 = n × 보오율 = 2 × 2,000 = 4,000 bps = 4 kbps
예제 4-5 | 16-QAM 비트율

보오율이 1,000 baud인 시스템에서 16-QAM을 사용한다면 비트율은?

16-QAM: L = 16 → n = log₂(16) = 4 비트/신호
비트율 = 4 × 1,000 = 4,000 bps = 4 kbps
예제 4-6 | 비트율에서 보오율 역산

64-QAM을 사용하는 시스템의 비트율이 12 Mbps일 때 보오율은?

64-QAM: L = 64 → n = log₂(64) = 6 비트/신호
보오율 = 비트율 / n = 12,000,000 / 6 = 2,000,000 baud = 2 Mbaud
예제 4-7 | PCM 전송 시 필요 대역폭 (맨체스터)

표본화율 8 kHz, 8비트 양자화의 PCM 신호를 맨체스터 부호화로 전송할 때 최소 대역폭은?

비트율 = 8,000 × 8 = 64,000 bps
맨체스터 최소 대역폭 = 비트율 × 1 = 64,000 Hz = 64 kHz
(NRZ는 32 kHz, 맨체스터는 NRZ의 2배 대역폭 필요)
예제 4-8 | AM 대역폭

최고 주파수 5 kHz인 아날로그 신호를 AM 변조할 때 필요한 대역폭은?

BAM = 2 × fm = 2 × 5,000 = 10,000 Hz = 10 kHz
예제 4-9 | 4B/5B 실제 회선 비트율

데이터 비트율 100 Mbps인 FDDI에서 4B/5B 부호화를 사용할 때 실제 회선 비트율은?

4B/5B: 4비트 데이터 → 5비트 코드 전송 (25% 오버헤드)
실제 회선 비트율 = 100 Mbps × (5/4) = 125 Mbps
예제 4-10 | 2B1Q 비트율 계산

2B1Q 부호화를 사용하는 DSL 시스템에서 보오율이 80,000 baud일 때 비트율은?

2B1Q: 2비트 → 4레벨 신호 1개 → n = log₂(4) = 2
비트율 = n × 보오율 = 2 × 80,000 = 160,000 bps = 160 kbps
