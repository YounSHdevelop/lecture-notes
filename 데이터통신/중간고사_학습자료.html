1데이터통신 정의
Q. 데이터란?
특정 형태로 정리되지 않은 사실, 개념, 명령어 등의 집합 (문자·숫자·기호)
Q. 정보란?
데이터를 가공·처리하여 의미를 부여한 것
Q. 통신이란?
송신자에서 전송매체를 통해 수신자에게 정보를 전달하는 것
Q. 데이터통신 정의 ⭐
컴퓨터와 컴퓨터 간 또는 컴퓨터와 단말장치 사이에서 통신회선을 이용하여 데이터를 송수신하는 것. 데이터통신 = 데이터처리 + 통신
2데이터통신 시스템 구성요소 5가지 ⭐⭐⭐
앞글자 암기법
송 · 수 · 전 · 메 · 프
송신자 · 수신자 · 전송매체 · 메시지 · 프로토콜
  1. 송신자 (Sender) — 데이터를 보내는 장치 (컴퓨터, 전화기)
  2. 수신자 (Receiver) — 데이터를 받는 장치
  3. 전송매체 (Medium) — 데이터가 이동하는 물리적 통로 (꼬임쌍선·동축·광섬유·무선)
  4. 메시지 (Message) — 전달하려는 데이터 (텍스트·숫자·이미지·오디오·비디오)
  5. 프로토콜 (Protocol) — 데이터 통신을 지배하는 규칙의 집합
3프로토콜 정의 + 3가지 구성요소 ⭐⭐⭐
프로토콜 정의
통신을 위해 통신 양단 간에 약속된 규칙의 집합
앞글자 암기법
구 · 의 · 타
구문(Syntax) · 의미(Semantics) · 타이밍(Timing)
  1. 구문 (Syntax) — 데이터의 형식·구조·부호화를 정의
  2. 의미 (Semantics) — 데이터의 의미·해석·제어 정보를 정의
  3. 타이밍 (Timing) — 데이터의 전송 속도와 순서를 정의 (예: 100Mbps vs 10Mbps)
4OSI 7계층 나열 ⭐⭐⭐
OSI 참조 모델이란?
1984년 ISO(국제표준화기구)가 제정한 네트워크 통신의 7계층 표준 모델. 서로 다른 시스템 간 상호 연결을 위한 참조 모델.
아래 → 위 (1계층 → 7계층)
물 · 데 · 네 · 전 · 세 · 표 · 응
물리 · 데이터링크 · 네트워크 · 전송 · 세션 · 표현 · 응용
PDU란? (Protocol Data Unit)
각 계층에서 전송되는 데이터의 단위 (= 처리 단위)
PDU = SDU(상위에서 내려온 원본 데이터) + 헤더(제어정보)
계층마다 부르는 이름이 다름 → 아래 참고
각 계층 PDU (1~4계층만 고유 이름 있음)
비 · 프 · 패 · 세
1.비트 · 2.프레임 · 3.패킷 · 4.세그먼트
※ 5·6·7계층은 고유 이름이 없고 모두 "데이터/메시지"라고 부름
계층이름PDU한 줄 기능
7응용데이터사용자에게 네트워크 서비스 제공 (이메일·FTAM)
6표현데이터변환·암호화·압축 (ASCII↔EBCDIC, JPEG, MPEG)
5세션데이터세션 설정·유지·종료, 동기화, 대화 제어(반/전이중)
4전송세그먼트프로세스↔프로세스 End-to-End, 포트 주소
3네트워크패킷논리 주소·라우팅, End-to-End 전달
2데이터링크프레임프레임화·물리주소·흐름제어·오류제어, Hop-by-hop
1물리비트비트 전송, 전기·기계·기능·절차적 특성, DTE↔DCE
5계층별 서술 포인트 (시험 빈출)
⭐ 물리(1)의 4가지 특성
  • 전기적: 전압 레벨·임피던스
  • 기계적: 커넥터 모양·핀 배치
  • 기능적: 각 핀의 기능 정의
  • 절차적: 비트 전송 순서·타이밍
⭐ 데이터링크(2) 기능 = Hop-by-hop
  • 프레임화 · 물리주소(MAC) · 흐름제어(Stop-and-wait / Sliding window) · 오류제어 · 접근제어
  • 대표 프로토콜: HDLC · BSC · PPP · LLC
⭐ 네트워크(3) vs 전송(4)
  • 네트워크: 호스트↔호스트 End-to-End, 논리 주소(IP), 라우팅
  • 전송: 프로세스↔프로세스 End-to-End, 포트 주소
⭐ 표현(6)의 3대 기능
  • 변환: 코드 변환 (ASCII ↔ EBCDIC)
  • 암호화: 대칭키(DES·AES·SEED) / 공개키(RSA)
  • 압축: JPEG · MPEG · DVI · H.261
6캡슐화 · SDU · PDU
캡슐화 (Encapsulation)
상위 계층 데이터에 헤더를 붙여 하위 계층으로 전달. 2계층은 트레일러도 추가.
SDU vs PDU
SDU: 상위에서 내려온 원본 데이터
PDU = SDU + 헤더 (프로토콜 데이터 단위)

📌 내일 외워야 할 것
1아날로그 신호 vs 디지털 신호
아날로그 데이터/신호
연속적인 값. 음성·영상·오디오·비디오. 무한히 많은 값을 가짐.
디지털 데이터/신호
이산적인 값. 0과 1. 유한한 수의 값만 가짐.
주기 vs 비주기 신호
주기 신호: 일정 시간마다 반복 (사이클)
비주기 신호: 반복되지 않음
사인파 3요소
s(t) = A sin(2πft + φ) — 진폭(A)·주파수(f)·위상(φ)
2대역폭·비트율·주기·주파수
  • 대역폭 (Bandwidth) = 최고 주파수 − 최저 주파수 (Hz)
  • 예) 1000Hz~5000Hz → 대역폭 = 4000Hz
  • 유효 대역폭 (전화): 300~3300Hz → 3000Hz
  • 주기 T = 1/f, 주파수 f = 1/T
  • 비트율: 1초당 전송 비트 수 (bps)
  • 비트 간격: 1비트 전송 시간. 8bps → 1/8 = 0.125초
3채널 용량 공식 ⭐⭐
나이퀴스트: C = 2W log₂L
잡음 없는 환경. W=대역폭(Hz), L=신호 레벨 수
나이퀴스트 예제
  • W=1KHz, L=8 → C = 2×1000×log₂8 = 2000×3 = 6Kbps
  • W=400Hz, C=3200bps → 3200=800×log₂L → L = 16
샤논: C = W log₂(1 + S/N)
잡음 있는 환경. S/N=신호대잡음비
SNR(dB) = 10 log₁₀(S/N)
20dB→S/N=100, 30dB→S/N=1000
샤논 예제
  • W=3KHz, SNR=30dB → S/N=1000
  • C = 3000 × log₂(1001) ≈ 3000×9.967 ≈ 29.9Kbps
dB = 10 log₁₀(P₂/P₁)
전력비. 전압·전류는 20 log₁₀(V₂/V₁)
4전송 장애 3가지 ⭐
앞글자 암기법
감 · 왜 · 잡
감쇠 · 왜곡 · 잡음
① 감쇠 (Attenuation)
신호가 전송매체를 통과하며 에너지가 손실되어 약해지는 현상.
→ 증폭기(아날로그) / 리피터(디지털)로 보상
예) P₂=0.5P₁ → -3dB
② 왜곡 (Distortion)
신호의 형태가 변하는 현상.
- 지연 왜곡: 주파수마다 전파 속도 다름
- 감쇠 왜곡: 주파수마다 감쇠 정도 다름
→ 등화기(Equalizer)로 보상
③ 잡음 (Noise) — 종류
- 열잡음 (전자의 무작위 운동, 백색잡음, N=KTW)
- 상호변조 잡음 (서로 다른 주파수 혼합)
- 누화(Crosstalk) (인접 회선 간 간섭)
- 충격 잡음 (번개·전원장애, 디지털에 큰 영향)
5신호 변환 4가지 유형
  • 디지털 → 디지털: 회선 부호화 (NRZ·RZ·Biphase·AMI)
  • 디지털 → 아날로그: 디지털 변조 (ASK·FSK·PSK·QAM)
  • 아날로그 → 디지털: PCM (표본화·양자화·부호화)
  • 아날로그 → 아날로그: 아날로그 변조 (AM·FM·PM)
6PCM 3단계 ⭐⭐⭐
아날로그 → 디지털 (PCM)
표 · 양 · 부
표본화(Sampling) · 양자화(Quantization) · 부호화(Encoding)
  1. ① 표본화 (Sampling)
    아날로그 신호를 일정 간격으로 추출 → PAM 신호.
    나이퀴스트 정리: f_s ≥ 2f_m (최대 주파수의 2배 이상 표본화)
  2. ② 양자화 (Quantization)
    표본값을 유한한 정수값으로 근사.
    양자화 잡음(오차) 발생. 레벨 많을수록 오차↓
    SNR(dB) = 6.02n_b + 1.76
  3. ③ 부호화 (Encoding)
    양자화 값을 이진 코드로 변환.
    레벨 128개 → 7비트(2⁷=128), 256개 → 8비트(2⁸=256)
PCM 계산 예제
  • 음성(4KHz), 양자화 레벨 128개
  • → 표본화 주파수 = 2×4000 = 8KHz
  • → 2⁷=128 → 7비트
  • → 비트율 = 8000 × 7 = 56Kbps
7델타 변조 (DM)
델타 변조
PCM 간소화. 이전 표본과의 차이(증가/감소)만 1비트로 부호화.
- 경사 과부하 잡음: 급변을 못 따라감
- 입자 잡음: 변화 없을 때 불필요한 변동
8디지털 변조 4가지 ⭐⭐⭐
디지털 → 아날로그
A · F · P · Q
ASK · FSK · PSK · QAM
무엇을 변화시키는가?
  • ASK → 진폭(Amplitude) 변화
  • FSK → 주파수(Frequency) 변화
  • PSK → 위상(Phase) 변화
  • QAM → 진폭+위상 둘 다 변화
ASK (진폭 편이 변조)
1=신호 있음, 0=신호 없음 → OOK(On-Off Keying)
잡음에 가장 취약
FSK (주파수 편이 변조)
1=f₁(높음), 0=f₀(낮음)
ASK보다 잡음에 강함
PSK (위상 편이 변조)
BPSK(2-PSK): 0°/180° → 1비트
QPSK(4-PSK): 45°·135°·-45°·-135° → 2비트/신호
QAM (직교 진폭 변조)
ASK + PSK 결합. 진폭·위상 동시 변화.
5G·LTE·Wi-Fi(6/7)에서 사용
보 레이트 vs 비트 레이트
  • 비트율(bps) = 1초당 비트 수
  • 보 레이트(Baud) = 1초당 신호 변화 수
  • 비트율 = n × 보 레이트 (n=한 신호당 비트 수)
  • 예) QPSK, 2400baud → 비트율 = 2×2400 = 4800bps
9회선 부호화 (디지털→디지털)
단극성 (Unipolar)
한 방향 전압만 사용. DC 성분 발생, 동기화 문제
NRZ (Non-Return to Zero)
0과 1을 (+)·(-)로. NRZ-L(레벨), NRZ-I(반전).
같은 비트 연속 시 동기화 문제
RZ (Return to Zero)
0=(-)→0, 1=(+)→0. 비트 중간에 항상 0으로.
NRZ보다 대역폭 2배 필요
맨체스터 / 차동 맨체스터
맨체스터: 비트 중간 전이. LAN(CSMA/CD·이더넷)
차동 맨체스터: 토큰링
AMI (Bipolar)
(+)·(-)·0 세 레벨. 1은 +/-교대, 0은 0V
0 연속 시 동기화 문제 → 스크램블링
B8ZS / HDB3
B8ZS: T-1에서 0이 8개 연속 시 특수패턴
HDB3: E-1에서 0이 4개 연속 시 특수패턴
4B/5B
4비트 → 5비트 (NRZ-I 함께). 100Base-FX
8B/10B
8비트 → 10비트. 1000Base-X, USB 3.0
10아날로그 변조 (AM·FM·PM)
  • AM (진폭 변조): 반송파 진폭 변화. B_AM = 2B
  • FM (주파수 변조): 반송파 주파수 변화. B_FM = 2(1+β)B
  • PM (위상 변조): 반송파 위상 변화. FM과 유사

단방향 · 반이중 · 전이중

2데이터 전송방식 ⭐
앞글자 암기법
직 · 병
직렬 · 병렬
직렬 전송 (Serial)
하나의 회선으로 한 비트씩 순차 전송.
- 장거리에 적합
- 회선 비용 저렴
- 시프트 레지스터 사용
- 예) RS-232C, USB
병렬 전송 (Parallel)
여러 회선으로 여러 비트 동시 전송.
- 고속 (직렬의 n배)
- 근거리에만 사용 (비용 높음)
- 타이밍 동기화 필요
- 예) 프린터 케이블, 내부 버스
3동기 vs 비동기 전송
비동기 전송 (Asynchronous)
문자 앞 시작 비트 + 뒤 정지 비트(1, 1.5, 2비트).
유휴 상태는 1 유지. 2~3비트 오버헤드 발생. 저속.
동기 전송 (Synchronous)
블록 단위 연속 전송.
- 문자 지향: SYN·STX·ETX
- 비트 지향: Flag, 프레임. 고속·고효율
효율 계산 예제
  • 비동기: 7데이터 + 1시작 + 1정지 = 9비트 → 효율 = 7/9 = 77.78%
  • 동기: STX 8 + 100문자×8 + ETX 8 = 816비트 → 효율 = 800/816 = 98%
4회선 구성 4가지
  • 점대점 (Point-to-Point) — 1:1 전용 회선. PPP 프로토콜
  • 다중점 (Multipoint) — 3개 이상 공유. 폴링·셀렉션·경쟁
  • 회선 집중 (Concentration) — 여러 저속 → 소수 고속. m>n
  • 다중화 (Multiplexing) — 하나의 고속을 여러 저속이 공유. TDM·FDM
5전송 형태 (캐스팅)
유니캐스트
1:1 (하나 → 하나)
애니캐스트

멀티캐스트

앞글자 암기법

① 버스형 (Bus)
공유 회선에 모든 장치 연결. 탭·드롭 라인.
✔ 설치 쉬움, 케이블 저렴
✘ 한 곳 끊기면 전체 중단
② 성형 (Star)
중앙 장치(허브)에 모든 장치 연결.
✔ 개별 고장이 전체 영향 없음
✘ 중앙 고장 시 전체 마비
③ 링형 (Ring)
원형 연결, 단방향 전송.
✔ 설치 쉬움, 신호 재생
✘ 한 장치 고장 시 전체 마비
④ 메쉬형 (Mesh) ⭐
모든 장치가 서로 직접 연결.
n개 → n(n-1)/2 링크
각 장치 (n-1) 포트
✔ 높은 신뢰성 ✘ 케이블 비용 큼
⑤ 트리형 (Tree)
성형의 확장. 허브 계층적 연결. 2차 허브.
✔ 확장 쉬움
✘ 루트 고장 시 전체 마비
⑥ 혼합형 (Hybrid)
여러 토폴로지 결합. 대규모 LAN·MAN·WAN.
✔ 유연함 ✘ 복잡함
메쉬형 링크 수 = n(n-1)/2
예) n=120 → 120×119/2 = 7,140개
7네트워크 분류 (LAN·MAN·WAN)
LAN
건물·사무실 등 근거리. 수 Km 이내, Mbps 수준. 사설 네트워크.
MAN
LAN과 WAN 중간. 도시 내. IEEE DQDB 표준.
WAN
국가·대륙 간. 공중망. X.25·ATM. LAN보다 느리고 에러율 높음.
8인터페이스 표준
  • EIA-232 (RS-232C): DTE↔DCE. 25핀. 15m·20Kbps 이하
  • Null MODEM: 모뎀 없이 DTE간 직접. Crossover cable
  • EIA-449 / EIA-530 / X.21 / V.35: 고속·장거리 확장
  • USB: 최대 127개 장치. Plug-and-play, Hot plugging

D1. PCM 과정(아날로그→디지털)을 설명하시오.

모범답안:
PCM은 아날로그 신호를 디지털 신호로 변환하는 기술로 3단계로 구성된다.
① 표본화(Sampling): 아날로그 신호를 일정 간격으로 추출해 PAM 신호로 변환. 나이퀴스트 정리에 의해 최대 주파수의 2배 이상(f_s ≥ 2f_m)으로 표본화해야 원 신호 복원 가능.
② 양자화(Quantization): 표본값을 유한한 정수값으로 근사. 양자화 잡음(오차) 발생. 레벨이 많을수록 오차 감소.
③ 부호화(Encoding): 양자화된 값을 이진 코드로 변환. L개 레벨 → log₂L 비트.

D2. ASK·FSK·PSK·QAM을 각각 정의하시오.

모범답안:
① ASK(진폭 편이 변조): 반송파의 진폭을 변화시켜 디지털 데이터를 표현. 1=신호 있음, 0=신호 없음(OOK). 잡음에 가장 취약.
② FSK(주파수 편이 변조): 반송파의 주파수를 변화. 1=f₁, 0=f₀. ASK보다 잡음에 강함.
③ PSK(위상 편이 변조): 반송파의 위상을 변화. BPSK는 0°/180°, QPSK는 4위상으로 2비트씩 전송.
④ QAM(직교 진폭 변조): ASK+PSK 결합. 진폭과 위상을 동시에 변화. 5G·LTE·Wi-Fi에서 사용.

D3. 감쇠·왜곡·잡음을 설명하시오.

모범답안:
① 감쇠: 신호가 전송매체를 통과하며 에너지가 손실되어 약해지는 현상. 증폭기(아날로그)·리피터(디지털)로 보상.
② 왜곡: 신호의 형태가 변하는 현상. 지연 왜곡(주파수별 전파 속도 차이), 감쇠 왜곡(주파수별 감쇠 차이). 등화기로 보상.
③ 잡음: 원 신호에 없던 불필요한 신호. 열잡음(백색잡음), 상호변조 잡음, 누화, 충격 잡음.
