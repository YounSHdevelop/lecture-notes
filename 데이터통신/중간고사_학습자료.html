📘 1장 — 데이터통신 개요

1. 데이터통신의 정의

데이터 (Data)
특정 형태로 정리되지 않은 사실, 개념, 명령어 등의 집합. 문자, 숫자, 기호 등을 포함한다.
정보 (Information)
데이터를 가공·처리하여 의미를 부여한 것
통신 (Communication)
송신자(발신측)에서 전송매체(통신회선)를 통해 수신자(착신측)에게 정보를 전달하는 것
데이터통신 (Data Communication)
컴퓨터와 컴퓨터 간 또는 컴퓨터와 단말장치 사이에서 통신회선을 이용하여 데이터를 송수신하는 것. 데이터통신 = 데이터처리 + 통신
정보통신
데이터뿐만 아니라 음성, 영상 등 멀티미디어를 포함하는 넓은 의미의 통신. 정보통신 = 정보처리 = 데이터통신

2. 데이터통신 시스템의 구성요소 5가지 ⭐

시험 핵심 — 5가지 구성요소와 각각의 특징을 반드시 암기!
① 송신자 (Sender)
데이터를 보내는 장치. 컴퓨터, 전화기 등
② 수신자 (Receiver)
데이터를 받는 장치. 컴퓨터, 전화기 등
③ 전송매체 (Medium)
데이터가 이동하는 물리적 통로. 꼬임쌍선(Twisted-pair), 동축케이블, 광섬유, 무선 등
④ 메시지 (Message)
전달하려는 데이터(정보). 텍스트, 숫자, 이미지, 오디오, 비디오 등
⑤ 프로토콜 (Protocol)
데이터 통신을 지배하는 규칙의 집합. 통신 양 끝에서 약속된 규약

3. 데이터통신 시스템의 장치 구성

단말장치 (Terminal)
- 더미 터미널 (Dummy Terminal): 중앙 컴퓨터에 종속적이며 독자적 처리 능력 없음
- 지능형 터미널 (Intelligent Terminal): 자체 처리 능력을 가진 단말장치 (PC 등)
MODEM (Modulator and Demodulator, 변복조기)
아날로그 회선에서 디지털 데이터를 전송하기 위해 변조·복조를 수행하는 장치
DSU/CSU (Digital Service Unit / Channel Service Unit)
디지털 회선에서 사용하는 신호 변환 장치. CSU는 디지털 전용회선(T-1, E-1 등)에 접속
CCU (Communication Control Unit, 통신제어장치)
데이터 전송과 관련된 모든 제어 기능을 담당. CCP(통신제어 프로세서), FEP(전처리기) 포함
DTE (Data Terminal Equipment)
데이터를 생성하거나 소비하는 장치. 컴퓨터, 단말기 등. DCE를 통해 네트워크에 접속
DCE (Data Communication Equipment)
DTE의 데이터를 통신 회선에 적합한 형태로 변환하는 장치. 모뎀, DSU 등

4. 네트워크 분류

LAN (Local Area Network)

근거리

건물, 사무실 등 제한된 지역 내 네트워크. 수 Km 이내, Mbps~Gbps급 고속. 사설 네트워크.

MAN (Metropolitan Area Network)

도시

LAN과 WAN 중간 규모. 도시 내 LAN들을 연결. IEEE의 DQDB(Distributed Queue Dual Bus) 표준.

WAN (Wide Area Network)

광역

국가, 대륙 간 연결. 공중 네트워크(통신사업자 제공). X.25, ATM 등 사용. LAN보다 느리고 에러율 높음.

네트워크 공식

공식

N개 장치 → N(N-1)/2 링크 (완전연결 시). 장치가 많을수록 통신망 필요.

5. 프로토콜의 정의와 구성요소 3가지 ⭐

시험 핵심 — 프로토콜 정의 + 구성요소 3가지와 의미를 외우기!
프로토콜 (Protocol) 정의
통신을 위해 통신 양단 간에 약속된 규칙의 집합. 데이터 형식, 전송 순서, 오류 처리 등을 규정한다.
구성요소 ① 구문 (Syntax)
데이터의 형식, 구조, 부호화를 정의. 어떤 순서로, 어떤 크기로 데이터를 보낼 것인지 규정.
구성요소 ② 의미 (Semantics)
전송되는 데이터의 의미, 해석, 제어 정보를 정의. 오류가 발생했을 때 어떻게 처리할지 등.
구성요소 ③ 타이밍 (Timing)
데이터의 전송 속도와 순서를 정의. 예: 송신측이 100Mbps로 보내는데, 수신측이 10Mbps만 처리 가능하면?

6. 프로토콜의 주요 기능

주소 지정 (Addressing)

발신지, 목적지 주소를 포함하여 데이터가 올바른 수신자에게 전달되도록 함

순서 제어 (Sequencing)

전송되는 데이터의 순서를 명시하여 올바른 순서로 재조립

단편화·재조립 (Fragmentation / Reassembly)

큰 데이터를 작은 블록(세그먼트)으로 나누어 전송하고, 수신 측에서 재조립

캡슐화 (Encapsulation)

데이터에 제어정보(헤더, 트레일러)를 붙여 전송 단위를 구성

흐름 제어 (Flow Control)

수신측의 처리 속도에 맞춰 송신 속도를 조절하여 데이터 손실 방지

오류 제어 (Error Control)

전송 중 발생하는 오류를 검출·수정. 패리티, CRC, 체크섬 등 사용

동기화 (Synchronization)

송수신 측의 타이밍을 맞추어 데이터를 정확히 송수신

다중화 (Multiplexing)

하나의 통신 회선을 여러 사용자가 공유하여 효율적으로 사용

📙 2장 — OSI 7계층 모델

1. OSI 모델 개요

OSI (Open System Interconnection) 참조 모델
1984년 ISO(국제표준화기구)가 제정한 네트워크 통신의 7계층 표준 모델. 서로 다른 시스템 간의 상호 연결을 위한 참조 모델(Reference Model)이다.

3. 계층별 상세 설명

물리 계층 (Physical Layer) — 1계층
비트(0, 1)를 전송매체를 통해 전달하는 역할
4가지 특성:
- 전기적 특성: 전압 레벨, 임피던스 등
- 기계적 특성: 커넥터의 모양, 핀 배치 등
- 기능적 특성: 각 핀의 기능 정의
- 절차적 특성: 비트 전송 순서, 타이밍 등
데이터링크 계층 (Data Link Layer) — 2계층
인접 노드 간(hop-by-hop) 프레임 단위로 데이터 전달
- 프레임화: 비트열을 프레임으로 구성
- 물리 주소 지정: MAC 주소를 사용하여 프레임 전달
- 흐름 제어: Stop-and-wait, Sliding window 방식
- 오류 제어: 손상·분실 프레임 감지 및 재전송
- 접근 제어: 공유 링크에서의 매체 접근 제어
네트워크 계층 (Network Layer) — 3계층
발신지에서 목적지까지(End-to-end) 패킷을 전달
- 논리 주소 지정: IP 주소 등 논리적 주소 부여
- 라우팅(경로 설정): 최적 경로를 결정하여 패킷 전달
- 2계층이 hop-by-hop이라면, 3계층은 end-to-end 전달
전송 계층 (Transport Layer) — 4계층
프로세스 대 프로세스(Process-to-process) End-to-end 전달
- 포트 주소(Port address)를 사용하여 프로세스 식별
- 네트워크 계층(3계층)이 컴퓨터까지 전달한다면, 전송 계층은 해당 컴퓨터의 특정 프로세스까지 전달
세션 계층 (Session Layer) — 5계층
통신 장치 간 세션(대화)을 설정·유지·종료
- 동기화: 동기점을 설정하여 장애 시 재전송 위치 결정
- 대화 제어: 반이중(Half-duplex) 또는 전이중(Full-duplex) 방식 결정
- 체크포인트: 오류 복구를 위한 동기점 삽입
표현 계층 (Presentation Layer) — 6계층
데이터의 형식 변환을 담당 (3가지 핵심 기능):
- 변환(Translation): 코드 변환 (예: ASCII ↔ EBCDIC)
- 암호화(Encryption): 보안을 위한 데이터 암호화·복호화
- 압축(Compression): 전송 효율을 위한 데이터 압축 (JPEG, MPEG 등)
응용 계층 (Application Layer) — 7계층
사용자에게 네트워크 서비스를 직접 제공
- NVT (Network Virtual Terminal): 가상 터미널 서비스
- FTAM: 파일 전송, 접근, 관리
- 전자우편: X.400 표준
- 디렉토리 서비스: X.500 표준

4. 핵심 개념

캡슐화 (Encapsulation)
상위 계층의 데이터에 헤더(Header)를 붙여 하위 계층으로 전달. 2계층은 트레일러(Trailer)도 추가.
SDU vs PDU
SDU (Service Data Unit): 상위 계층에서 내려온 원본 데이터
PDU (Protocol Data Unit): SDU + 제어정보(헤더). 즉 PDU = SDU + 헤더
동료 프로세스 (Peer-to-Peer Process)
같은 계층끼리는 논리적으로 직접 통신하는 것처럼 보임. 실제로는 하위 계층을 통해 전달.

5. 암호화 방식

대칭 키 암호화 (비밀 키)

Secret Key

암호화와 복호화에 같은 키를 사용. 키 배포 문제가 있음.

알고리즘
  • DES, AES, SEED

비대칭 키 암호화 (공개 키)

Public Key

공개 키로 암호화, 개인 키로 복호화. 공개 키로는 복호화 불가.

알고리즘
  • RSA

📗 3장 — 신호

1. 아날로그 신호 vs 디지털 신호 ⭐

아날로그 데이터/신호

연속적

아날로그 데이터: 연속적인 값을 가지는 데이터 (음성, 영상, 오디오, 비디오)

아날로그 신호: 연속적인 전자기 신호로, 무한히 많은 값을 가짐

디지털 데이터/신호

이산적

디지털 데이터: 이산적인 값을 가지는 데이터 (0과 1)

디지털 신호: 이산적인 전자기 신호로, 유한한 수의 값만 가짐

2. 사인파(정현파)의 3요소

s(t) = A sin(2πft + φ)
A: 진폭, f: 주파수, φ: 위상
진폭 (Amplitude, A)
신호의 세기(높이). 에너지의 크기를 나타냄.
주파수 (Frequency, f) / 주기 (Period, T)
주기(T): 한 사이클을 완성하는 데 걸리는 시간 (초)
주파수(f): 1초 동안 반복되는 사이클 수 (Hz)
f = 1/T, T = 1/f
위상 (Phase, φ)
시간 0에서의 파형의 상대적 위치. 도(Degree) 또는 라디안(Radian)으로 표현.

3. 대역폭 (Bandwidth) ⭐

대역폭 (Bandwidth)
신호가 차지하는 주파수의 범위. 최고 주파수 - 최저 주파수로 계산.
예) 1000Hz~5000Hz → 대역폭 = 4000Hz
유효 대역폭(Effective Bandwidth): 실제로 사용되는 주파수 범위 (예: 전화 300~3300Hz → 3000Hz)

4. 비트율 (Bit Rate) ⭐

비트 간격 (Bit Interval)
1비트를 전송하는 데 걸리는 시간
비트율 (Bit Rate)
1초 동안 전송되는 비트 수. 단위: bps (bits per second)
예) 8bps → 비트 간격 = 1/8 = 0.125초 = 125ms

5. 채널 용량 (Channel Capacity) ⭐

두 가지 공식을 모두 암기! 계산 문제 출제 가능성 높음
나이퀴스트: C = 2W log₂L
W: 대역폭(Hz), L: 신호 레벨 수, C: 채널 용량(bps). 잡음이 없는 이상적 환경
나이퀴스트 공식 예제
예1) L=8, W=1KHz → C = 2×1000×log₂8 = 2×1000×3 = 6Kbps
예2) 대역폭 400Hz, 비트율 3200bps → 3200 = 2×400×log₂L → L = 2⁴ = 16
샤논: C = W log₂(1 + S/N)
W: 대역폭(Hz), S/N: 신호대잡음비, C: 채널 용량(bps). 잡음이 있는 현실 환경
S/N비와 데시벨 변환
SNR(dB) = 10 log₁₀(S/N)
예) SNR = 20dB → 20 = 10×log₁₀(S/N) → S/N = 10² = 100
예) SNR = 30dB → S/N = 10³ = 1000
샤논 공식 예제
W=3KHz, SNR=30dB → S/N=1000
C = 3000 × log₂(1+1000) = 3000 × 9.967 ≈ 29,901 bps ≈ 29.9Kbps

6. 데시벨 (dB)

dB = 10 log₁₀(P₂/P₁)
전력비. 전압/전류의 경우: dB = 20 log₁₀(V₂/V₁)

7. 전송 장애 ⭐

① 감쇠 (Attenuation)
신호가 전송매체를 통과하면서 에너지가 손실되어 약해지는 현상.
- 증폭기(Amplifier): 아날로그 신호 증폭
- 리피터(Repeater): 디지털 신호 재생
- 예) P₂ = 0.5×P₁ → 10×log₁₀(0.5) = -3dB
② 왜곡 (Distortion)
신호의 형태가 변하는 현상
- 지연 왜곡: 주파수마다 전파 속도가 달라 신호 형태가 변형
- 등화기(Equalizer): 왜곡을 보상하는 장치
- 감쇠 왜곡: 주파수에 따라 감쇠 정도가 달라 발생
③ 잡음 (Noise)
원래 신호에 포함되지 않은 불필요한 신호
- 열잡음(Thermal noise): 전자의 무작위 운동으로 발생. 백색잡음(White noise). N = KTW
- 상호변조 잡음: 서로 다른 주파수 신호가 합쳐질 때 발생
- 누화(Crosstalk): 인접 회선 간 신호 간섭
- 충격 잡음(Impulse noise): 번개, 전원 장애 등으로 순간적으로 발생. 디지털 데이터에 큰 영향

📕 4장 — 신호 변환

1. 신호 변환의 4가지 유형

4가지 변환 유형을 구분하고, 각각의 대표 기술을 정리!

디지털→디지털

회선 부호화

디지털 데이터를 디지털 신호로 변환. NRZ, RZ, Biphase, AMI 등

디지털→아날로그

디지털 변조

디지털 데이터를 아날로그 신호로 변환. ASK, FSK, PSK, QAM

아날로그→디지털

PCM

아날로그 데이터를 디지털 신호로 변환. 표본화→양자화→부호화

아날로그→아날로그

아날로그 변조

아날로그 데이터를 아날로그 신호로 변환. AM, FM, PM

2. 디지털→디지털: 회선 부호화 (Line Coding)

단극성 (Unipolar)
0과 1을 한 방향의 전압만으로 표현 (예: 0=0V, 1=+5V)
문제점: DC 성분 발생, 동기화 문제
극성 (Polar) — NRZ
NRZ (Non-Return to Zero): 0과 1을 (+)와 (-) 전압으로 표현
- NRZ-L: 0=양전압, 1=음전압 (레벨에 의해 구분)
- NRZ-I: 1일 때만 전압이 반전 (반전에 의해 구분)
문제점: 같은 비트가 연속되면 동기화 문제 발생
극성 (Polar) — RZ (Return to Zero)
0은 (-)→0, 1은 (+)→0으로 표현. 비트 중간에 항상 0으로 돌아감.
동기화 문제는 해결되지만, NRZ보다 대역폭이 2배 필요.
극성 (Polar) — Biphase (맨체스터)
맨체스터(Manchester): 비트 중간에 반드시 전이. 양→음=0, 음→양=1. LAN(CSMA/CD, 이더넷)에서 사용.
차동 맨체스터(Differential Manchester): 0이면 비트 시작에서 전이, 1이면 비트 시작에서 전이 없음. 비트 중간에는 항상 전이. 토큰링(Token Ring)에서 사용.
양극성 (Bipolar) — AMI
AMI (Alternate Mark Inversion): (+), (-), 0 세 가지 레벨 사용
- 0: 전압 없음 (0V)
- 1: (+)와 (-) 전압을 교대로 사용
문제점: 0이 연속되면 동기화 문제 → 스크램블링으로 해결
B8ZS (Bipolar 8-Zero Substitution)
T-1 회선에서 사용. AMI의 0이 8개 연속되면 특수 패턴으로 대체.
- 이전 1이 (+): 00000000 → 000+-0-+
- 이전 1이 (-): 00000000 → 000-+0+-
HDB3 (High Density Bipolar 3)
E-1 회선에서 사용. AMI의 0이 4개 연속되면 특수 패턴으로 대체. 이전 1의 수가 홀수인지 짝수인지에 따라 달라짐.
- 홀수: +0000 → +000+, -0000 → -000-
- 짝수: +0000 → +-00-, -0000 → -+00+
mB/nB 부호화
m비트를 n비트 패턴으로 변환 (n > m)
- 4B/5B: 4비트를 5비트로. 0이 3개 이상 연속 불가. NRZ-I와 함께 사용. 100Base-FX (이더넷)
- 8B/10B: 8비트를 10비트로. 1000Base-X, USB 3.0에서 사용

3. 디지털→아날로그: 디지털 변조 방식 ⭐⭐

ASK, FSK, PSK, QAM 각각의 정의와 특징을 정리해서 암기!
보 레이트 (Baud Rate) vs 비트 레이트 (Bit Rate)
비트율(Bit rate): 1초당 전송되는 비트 수 (bps)
보 레이트(Baud rate): 1초당 전송되는 신호 변화 횟수 (Baud)
비트율 = n × 보 레이트 (n = 한 신호당 비트 수)
① ASK (Amplitude Shift Keying, 진폭 편이 변조)
반송파의 진폭(크기)을 변화시켜 디지털 데이터를 표현.
1=신호 있음, 0=신호 없음 → OOK (On-Off Keying)
잡음에 가장 취약.
② FSK (Frequency Shift Keying, 주파수 편이 변조)
반송파의 주파수를 변화시켜 디지털 데이터를 표현.
1=높은 주파수(f₁), 0=낮은 주파수(f₀)
ASK보다 잡음에 강함.
③ PSK (Phase Shift Keying, 위상 편이 변조)
반송파의 위상을 변화시켜 디지털 데이터를 표현.
- BPSK (2-PSK): 1=0°, 0=180° → 1비트/신호
- QPSK (4-PSK): 00=135°, 01=45°, 10=-135°, 11=-45° → 2비트/신호
예) QPSK, 2400baud → 비트율 = 2×2400 = 4800bps
④ QAM (Quadrature Amplitude Modulation, 직교 진폭 변조)
ASK + PSK를 결합. 진폭과 위상을 동시에 변화.
s(t) = A_i sin(2πf_c t + φ_i)
5G, LTE, Wi-Fi(6/7) 등에서 광범위하게 사용.

4. 아날로그→디지털: PCM ⭐⭐⭐

PCM 과정(표본화→양자화→부호화)을 서술형으로 설명할 수 있어야 함!
아날로그 신호
→
① 표본화
(Sampling)
→
② 양자화
(Quantization)
→
③ 부호화
(Encoding)
→
디지털 신호
① 표본화 (Sampling)
아날로그 신호를 일정 간격으로 추출(샘플링)하여 PAM(Pulse Amplitude Modulation) 신호로 변환.
나이퀴스트 정리: 원래 신호의 최대 주파수(f_m)의 2배 이상으로 표본화해야 원래 신호를 복원할 수 있다.
f_s ≥ 2f_m (표본화 주파수 ≥ 2 × 최대 주파수)
T_s = 1/(2f_m). 예) 음성(4KHz) → f_s ≥ 8KHz, 즉 1초에 8000번 표본화
② 양자화 (Quantization)
표본화된 값을 유한한 정수값으로 근사하는 과정.
- 양자화 잡음(Quantization noise): 원래 값과 양자화된 값의 차이 → 양자화 오차
- 양자화 레벨이 많을수록 오차가 줄어듦
- 비균일 양자화(Non-linear quantization): 작은 신호에 더 세밀한 양자화 적용
SNR(dB) = 6.02n_b + 1.76 dB
n_b: 양자화 비트 수. 예) SNR ≥ 40dB → 40 = 6.02n_b + 1.76 → n_b = 6.35 → 최소 7비트(실제 8비트 사용)
③ 부호화 (Encoding)
양자화된 값을 2진수(이진 코드)로 변환.
- 양자화 레벨 8개 → 3비트 (2³=8)
- 양자화 레벨 16개 → 4비트 (2⁴=16)
- 양자화 레벨 128개 → 7비트 (2⁷=128)
PCM 계산 예제 ⭐
음성 신호(최대 주파수 4KHz)를 PCM으로 변환, 양자화 레벨 128개:
1. 표본화 주파수: f_s = 2 × 4000 = 8000Hz = 8KHz
2. 양자화 비트 수: 2⁷ = 128 → 7비트
3. 비트율 = 8000 × 7 = 56Kbps

5. 델타 변조 (DM, Delta Modulation)

델타 변조 (Delta Modulation)
PCM을 간소화한 방식. 이전 표본값과의 차이(증가/감소)만을 1비트로 부호화.
- 경사 과부하 잡음(Slope overload noise): 급격한 변화를 따라가지 못할 때 발생
- 입자 잡음(Granular noise): 변화가 거의 없을 때 불필요한 변동 발생
예) 표본화 주파수 8000Hz, 1비트/표본 → 비트율 = 8Kbps

6. 아날로그→아날로그 변조

AM (Amplitude Modulation, 진폭 변조)
반송파의 진폭을 변화시켜 아날로그 신호 전송. 대역폭 B_AM = 2B
FM (Frequency Modulation, 주파수 변조)
반송파의 주파수를 변화시켜 아날로그 신호 전송. 대역폭 B_FM = 2(1+β)B (β=변조지수, 보통 β=4)
PM (Phase Modulation, 위상 변조)
반송파의 위상을 변화시켜 아날로그 신호 전송. FM과 유사.

📒 5장 — 데이터 통신 기초

1. 통신회선 이용방식 ⭐

단방향, 반이중, 전이중의 정의와 예시를 정확히 구분!
① 단방향 (Simplex)
한 방향으로만 데이터 전송 가능. 역방향 전송 불가.
예) TV, 라디오 방송. 키보드 → 모니터 방향의 on/off 제어.
② 반이중 (Half-duplex)
양방향 전송 가능하지만 동시에는 불가. 한 번에 한 방향만.
예) 무전기. 한 쪽이 말하면 다른 쪽은 들어야 함.
③ 전이중 (Full-duplex)
양방향 동시 전송 가능.
예) 전화. 양쪽이 동시에 말하고 들을 수 있음.

2. 데이터 전송방식 ⭐

직렬 전송 (Serial Transmission)

한 비트씩

비트를 하나의 통신 회선을 통해 한 비트씩 순차적으로 전송.

특징
  • 장거리 전송에 적합 (원거리 통신)
  • 회선 비용이 저렴
  • 시프트 레지스터 사용
  • 예: RS-232C, USB

병렬 전송 (Parallel Transmission)

여러 비트 동시

여러 개의 통신 회선을 통해 여러 비트를 동시에 전송.

특징
  • 고속 전송 (직렬의 n배)
  • 근거리에서만 사용 (회선 비용 높음)
  • 타이밍 동기화 문제 존재
  • 예: 프린터 케이블, 컴퓨터 내부 버스
병렬 전송 계산 예제
8비트 데이터를 병렬로 전송 → 8개 회선 동시 사용 → 직렬 대비 8배 빠름

3. 동기 전송 vs 비동기 전송

비동기 전송 (Asynchronous)

Start-Stop

각 문자 앞에 시작 비트(Start bit), 뒤에 정지 비트(Stop bit, 1~2비트)를 붙여 전송.

특징
  • 유휴 상태(Idle)에서 1 유지
  • 오버헤드 20~30%
  • 저속 전송에 적합

동기 전송 (Synchronous)

블록 단위

데이터를 블록 단위로 전송. 시작/정지 비트 없이 연속 전송.

두 가지 방식
  • 문자 지향: SYN, STX, ETX 사용
  • 비트 지향: 플래그(Flag) 사용, 프레임 단위
  • 고속 전송에 적합, 효율 높음
비동기 전송 효율 계산 예제
7비트 데이터 + 1비트 시작 + 1비트 정지 = 9비트
효율 = 7/9 × 100 = 77.78%
동기 전송 효율 계산 예제
STX 8비트 + 데이터 100문자×8비트 + ETX 8비트 = 816비트
효율 = 800/816 × 100 = 98%
오류 검출 포함 시(100비트): 800/1000 × 100 = 80%

4. 회선 구성

점대점 (Point-to-Point)
두 장치를 전용 회선으로 1:1 연결. 예: PPP (Point-to-Point Protocol)
다중점 (Multipoint, Multi-drop)
3개 이상의 장치가 하나의 회선을 공유. 폴링(Polling)과 셀렉션(Selection) 방식 사용.
회선 집중 (Line Concentration)
집중기(Concentrator)를 사용하여 여러 저속 회선을 소수 고속 회선으로 집중. 단말 m대, 회선 n개 (m > n).
다중화 (Multiplexing)
하나의 고속 회선을 여러 저속 채널이 공유. 시분할(TDM), 주파수분할(FDM) 등.

5. 전송 형태 (캐스팅)

유니캐스트 (Unicast)

하나의 송신자 → 하나의 수신자

애니캐스트 (Anycast)

하나의 송신자 → 가장 가까운 하나의 수신자

멀티캐스트 (Multicast)

하나의 송신자 → 특정 그룹의 수신자

브로드캐스트 (Broadcast)

하나의 송신자 → 모든 수신자

6. 인터페이스 표준

EIA-232 (RS-232C)
DTE와 DCE 간 인터페이스 표준. 25핀(IBM 9핀 사용). 15m 이내, 20Kbps 이하. 기계적, 전기적, 기능적, 절차적 특성 정의.
Null MODEM
모뎀 없이 DTE 간 직접 연결. Crossover cable 사용. 15m 이내, 20Kbps 이하.
USB (Universal Serial Bus)
범용 직렬 버스. 최대 127개 장치 연결. Plug-and-Play, Hot-plugging 지원.
USB 1.0: 12Mbps / USB 2.0: 480Mbps / USB 3.0: 5Gbps

🔗 토폴로지 (Topology) ⭐

토폴로지 (Topology) 정의
네트워크를 구성하는 장치들의 물리적 또는 논리적 연결 구조. 네트워크의 성능, 확장성, 신뢰성을 결정.
📊

버스형 (Bus)

하나의 공유 회선(버스)에 모든 장치를 연결. LAN에서 주로 사용. 탭(Tap)과 드롭 라인(Drop line)으로 연결.

장점: 설치 용이, 케이블 비용 저렴, 장치 추가/제거 용이, 장치 고장이 다른 장치에 영향 없음
단점: 한 곳이 끊어지면 전체 통신 불가, 장치가 많아지면 성능 저하, 결함 탐지 어려움
⭐

성형 (Star)

중앙 장치(허브/스위치)에 모든 장치를 개별적으로 연결.

장점: 개별 장치 고장이 전체에 영향 없음, 장치 추가/제거 쉬움, 결함 탐지 용이, 보안성 높음
단점: 중앙 장치 고장 시 전체 마비, 케이블 비용 많음, 중앙 장치 필요
🔄

링형 (Ring)

각 장치가 양옆 장치와 연결되어 원형 구조 형성. 단방향 전송.

장점: 설치 쉬움, 케이블 사용량 적음, 결함 탐지 비교적 쉬움, 신호 재생으로 거리 연장
단점: 한 장치 고장 시 전체 통신 마비, 장치 추가/제거 시 전체 중단 필요
🕸️

메쉬형 (Mesh) ⭐

모든 장치가 서로 직접 연결. n개 장치 → n(n-1)/2 링크, 각 장치에 (n-1)개 포트

장점: 높은 신뢰성(이중화), 보안성 우수, 한 회선 고장 시 다른 경로 사용 가능
단점: 케이블 비용 매우 높음, 설치·관리 복잡
🌳

트리형 (Tree)

성형의 확장. 허브를 계층적으로 연결. 2차 허브 사용(능동 허브 + 수동 허브).

장점: 확장 용이, 허브 하나 고장 시 해당 하위만 영향, 2차 허브로 거리 연장 가능
단점: 루트 허브 고장 시 전체 마비, 버스형 백본 고장 시 전체 분리
🔀

혼합형 (Hybrid)

버스, 성형, 링형 등을 결합. 대규모 LAN, MAN, WAN 구성에 사용.

장점: 유연한 구성, 각 토폴로지의 장점 활용 가능
단점: 구성이 복잡, 비용이 높을 수 있음
메쉬형 링크 수 = n(n-1)/2
예) n=120 → 120×119/2 = 7,140개 링크 필요

📝 서술형 문제

D1. 아날로그 신호를 디지털 신호로 변환하는 PCM(Pulse Code Modulation) 과정을 단계별로 설명하시오.

모범답안:

PCM은 아날로그 신호를 디지털 신호로 변환하는 기술로, 3단계로 진행된다.

① 표본화(Sampling): 아날로그 신호를 일정 시간 간격으로 표본을 추출하여 PAM(Pulse Amplitude Modulation) 신호로 변환하는 과정이다. 나이퀴스트 정리에 의해 원래 신호의 최대 주파수(f_m)의 2배 이상의 주파수(f_s ≥ 2f_m)로 표본화해야 원래 신호를 완벽하게 복원할 수 있다.

② 양자화(Quantization): 표본화된 아날로그 값을 유한한 개수의 정수값으로 근사하는 과정이다. 이 과정에서 원래 값과 양자화된 값의 차이인 양자화 잡음(양자화 오차)이 발생한다. 양자화 레벨(단계 수)이 많을수록 오차가 줄어든다.

③ 부호화(Encoding): 양자화된 정수값을 이진 코드(2진수)로 변환하는 과정이다. 양자화 레벨이 L개이면 log₂L 비트가 필요하다. 예를 들어 양자화 레벨 128개 → 7비트(2⁷=128), 256개 → 8비트(2⁸=256)가 필요하다.

예시: 음성 신호(최대 4KHz)를 128단계로 양자화 → 표본화 주파수 8KHz, 7비트 부호화 → 비트율 = 8000×7 = 56Kbps.

D2. OSI 7계층 모델의 각 계층별 이름, 처리 단위(PDU), 핵심 기능을 설명하시오.

모범답안:

1계층 물리 계층(Physical) — PDU: 비트(Bit). 전기적·기계적·기능적·절차적 특성을 정의하여 비트를 전송매체를 통해 전달한다.

2계층 데이터링크 계층(Data Link) — PDU: 프레임(Frame). 인접 노드 간(hop-by-hop) 프레임 전달을 담당하며, 프레임화, 물리 주소 지정(MAC), 흐름 제어, 오류 제어, 접근 제어 기능을 수행한다.

3계층 네트워크 계층(Network) — PDU: 패킷(Packet). 발신지에서 목적지까지(end-to-end) 패킷을 전달하며, 논리 주소 지정(IP)과 라우팅(경로 설정)을 수행한다.

4계층 전송 계층(Transport) — PDU: 세그먼트(Segment). 프로세스 대 프로세스(process-to-process) End-to-end 전달을 담당하며, 포트 주소로 프로세스를 식별한다.

5계층 세션 계층(Session) — PDU: 데이터. 통신 세션의 설정·유지·종료를 관리하고, 동기화 및 대화 제어(반이중/전이중)를 담당한다.

6계층 표현 계층(Presentation) — PDU: 데이터. 데이터의 변환(Translation, ASCII↔EBCDIC), 암호화(Encryption), 압축(Compression)을 담당한다.

7계층 응용 계층(Application) — PDU: 데이터. 사용자에게 네트워크 서비스를 직접 제공한다. 이메일(X.400), 파일 전송(FTAM), 디렉토리 서비스(X.500) 등.

D3. 디지털→아날로그 변조 방식의 종류(ASK, FSK, PSK, QAM)를 각각 정의하고 특징을 설명하시오.

모범답안:

디지털 데이터를 아날로그 신호로 변환하는 변조 방식에는 4가지가 있다.

① ASK (진폭 편이 변조, Amplitude Shift Keying): 반송파의 진폭(크기)을 변화시켜 디지털 데이터를 표현하는 방식이다. 1일 때 신호가 있고 0일 때 신호가 없는 OOK(On-Off Keying) 방식이 대표적이다. 잡음에 가장 취약하다는 단점이 있다.

② FSK (주파수 편이 변조, Frequency Shift Keying): 반송파의 주파수를 변화시켜 디지털 데이터를 표현하는 방식이다. 1이면 높은 주파수(f₁), 0이면 낮은 주파수(f₀)를 사용한다. ASK보다 잡음에 강하다.

③ PSK (위상 편이 변조, Phase Shift Keying): 반송파의 위상을 변화시켜 디지털 데이터를 표현하는 방식이다. BPSK(2-PSK)는 0°와 180°로 1비트를 표현하고, QPSK(4-PSK)는 4개의 위상으로 2비트를 동시에 표현한다.

④ QAM (직교 진폭 변조, Quadrature Amplitude Modulation): ASK와 PSK를 결합한 방식으로, 진폭과 위상을 동시에 변화시킨다. 8-QAM, 16-QAM 등으로 한 번에 더 많은 비트를 전송할 수 있다. 5G, LTE, Wi-Fi 등에서 광범위하게 사용된다.

D4. 감쇠(Attenuation), 왜곡(Distortion), 잡음(Noise)을 각각 설명하시오.

모범답안:

① 감쇠(Attenuation): 신호가 전송매체를 통과하면서 에너지가 손실되어 신호의 세기가 약해지는 현상이다. 감쇠를 보상하기 위해 아날로그 신호에는 증폭기(Amplifier), 디지털 신호에는 리피터(Repeater)를 사용한다.

② 왜곡(Distortion): 신호의 형태(모양)가 변하는 현상이다. 지연 왜곡은 주파수마다 전파 속도가 달라 발생하며, 감쇠 왜곡은 주파수에 따른 감쇠 정도의 차이로 발생한다. 등화기(Equalizer)를 사용하여 보상한다.

③ 잡음(Noise): 원래 신호에 포함되지 않은 불필요한 신호이다. 종류로는 열잡음(전자의 무작위 운동, 백색잡음), 상호변조 잡음(서로 다른 주파수 혼합), 누화(인접 회선 간 간섭), 충격 잡음(번개, 전원 장애 등 순간적 발생)이 있다.
