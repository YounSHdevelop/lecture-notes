데이터통신 5장 — 데이터 통신 기초

회선 접속·이용 방식 · 직렬/병렬 · 동기/비동기 · 물리 인터페이스 · 토폴로지

🎯 학습 목표

1

통신 회선의 접속 방식(점대점·다중점·집선·다중)을 이해하고 설명할 수 있다.

2

단방향(Simplex)·반이중(Half-duplex)·전이중(Full-duplex) 방식을 구분할 수 있다.

3

직렬/병렬 전송과 동기식/비동기식 전송 방식의 종류와 특성, 전송 효율을 설명·계산할 수 있다.

4

물리 인터페이스(EIA-232/449/530, X.21, V.35, USB)의 종류와 특성을 설명할 수 있다.

5

캐스팅 모드(유니/애니/멀티/브로드캐스트)와 6가지 토폴로지의 의미·종류·장단점을 설명할 수 있다.

📋 핵심 요약

회선 구성과 링크

  • 회선 구성(Line config.): 둘 이상의 장치가 하나의 링크에 연결되는 방식
  • 링크(Link): 장치 간 데이터를 전달하는 물리적 통신 경로
  • 변조(Modulation): 데이터를 반송파에 싣는 과정

회선 접속 4종

  • 점대점 / 다중점 / 집선 / 다중
  • 다중점 = 멀티드롭, 폴링·셀렉션·경쟁 사용
  • 집선: 순차 독점 / 다중화: 주파수·시간 분할 동시 사용

회선 이용 방식

  • Simplex: TV·라디오 (단방향)
  • Half-duplex: 무전기 (교대 송수신)
  • Full-duplex: 전화·컴퓨터 통신 (동시 송수신)

전송 방식

  • 직렬 vs 병렬 (전송 회선 수)
  • 직렬 → 비동기식(Start-stop) / 동기식(블록)
  • 동기식 → 문자 위주(SYN/STX/ETX) / 비트 위주(Flag)

물리 인터페이스

  • DTE(컴퓨터) ↔ DCE(모뎀·DSU·라우터)
  • EIA-232: 25/9핀, 15m, 20Kbps
  • USB 3.0: 5Gbps, 전이중, 최대 127개

토폴로지 6종

  • 버스 / 스타 / 링 / 메쉬 / 트리 / 혼합
  • 메쉬 회선 수: n(n−1)/2, 포트 수: n−1
  • 스타·트리: 허브 고장 시 전체 마비

🔌 01. 통신 회선의 접속 방식

① 점대점 회선 방식 (Point-to-point) PPP

  • 두 장치를 전용 회선으로 직접 연결, 채널 용량을 두 장치가 독점
  • 응답 속도가 빨라 고속 처리에 이용
  • TCP/IP 환경에서 PPP(Point-to-Point Protocol)로 두 노드 1:1 연결

② 다중점 회선 방식 (Multipoint, 멀티드롭) 공유

  • 3개 이상의 장치가 하나의 링크를 공유
  • 데이터 전송: 폴링(Polling) + 셀렉션(Selection), 또는 경쟁(Contention) 방식
  • 단말당 송수신 데이터가 적을 때 효과적, 회선 비용 절감

③ 집선 회선 방식 (Line concentration) 독점

  • 집선 장치(Concentrator): 다수 입력 회선을 소수 출력 회선으로 집중화
  • 저속 단말 데이터를 모아 컴퓨터로 고속 전송
  • 단말 수 m, 채널 수 n일 때 m > n
  • 도착 순서대로 한 단말이 회선을 독점 사용

④ 다중 회선 방식 (Multiplexing) 동시

  • 다중화 장비로 주파수·시간을 분할하여 여러 단말이 동시에 회선 사용
  • 집선과 유사하지만 동시 사용 가능 (집선은 순차 독점)
  • 고속 단일 링크를 다수의 저속 단말이 공유

↔️ 02. 통신 회선의 이용 방식

단방향 (Simplex)

한쪽은 송신만, 다른 쪽은 수신만. 채널은 늘 한 방향.

예: TV, 라디오 방송, 켜기/끄기 신호

반이중 (Half-duplex)

송수신 모두 가능하지만 동시 불가. 시간상 교대로 데이터 교환.

예: 무전기(워키토키)

전이중 (Full-duplex)

양쪽이 동시에 송수신. 링크 용량을 양방향으로 공유 → 회선 사용 효율 높음.

예: 전화, 일반 컴퓨터 통신

📡 03. 데이터 전송 방식

동기화(Synchronization): 송신측에서 정보의 시작과 끝을 알려, 수신측이 올바르게 수신하도록 하는 절차.

데이터 전송 ─┬─ 병렬 전송 └─ 직렬 전송 ─┬─ 비동기식 전송 └─ 동기식 전송 ─┬─ 문자 위주 └─ 비트 위주

① 직렬 전송 vs ② 병렬 전송

회선 수1개비트 수만큼

비용경제적회선 비용 큼
변환기병렬↔직렬 변환기 필요(시프트 레지스터)불필요
예RS-232C, USB컴퓨터 내부 버스

③ 비동기식 전송 (Asynchronous, Start-stop) 저속

  • 송수신 클럭을 일치시키는 절차 없음
  • 시작 비트(1) + 데이터(5~8비트) + 패리티 + 종료 비트(1·1.5·2)
  • 휴지 상태(Idle)에서는 비트 1을 계속 전송
  • 문자마다 2~3 비트의 오버헤드 → 전송 효율 낮음
  • 동기는 문자 단위, 송수신이 항상 동기 상태일 필요 없음
전송 효율 = (정보 비트 수 / 전체 비트 수) × 100 [%]

④ 동기식 전송 (Synchronous) 고속

  • 블록 단위로 전송, 동기 신호로 시작·끝 구분
  • 고속 데이터 통신에 사용, 단말은 반드시 버퍼 보유
  • 한 묶음(Packet) 내에서 휴지 간격 없음

문자 위주 방식

제어 문자(SYN, STX, ETX 등) 사용

[SYN][SYN][SOH][Heading][STX][data][ETX/ETB][BCC]

플래그(Flag, 8비트) 사용 → 프레임 단위 전송. 대용량 전송에 유리.

🔧 04. 물리 인터페이스

DTE - DCE 인터페이스

DTE (Data Terminal Equipment)

정보 처리 장치 = 컴퓨터, 단말

DCE (Data Circuit-terminating Equipment)

DTE와 전송 매체 사이 데이터 전송 담당 = 모뎀, DSU, 라우터

관련 개념

널 모뎀 (Null MODEM)

모뎀 없이 두 컴퓨터를 케이블로 직접 연결 (Crossover cable). 15m 이내, 20Kbps.

UART

EIA-232와 논리 호환, 물리 규격은 다름. UART(0~5V TTL) ↔ EIA(±12V). 변환 IC: MAX232.

불균형 vs 균형 모드

불균형(Unbalanced): 짧은 거리·저속·저비용 / 균형(Balanced): 보수 신호로 잡음 제거, 더 높은 전송률

USB 속도

USB 1.0 = 12Mbps / USB 2.0 = 480Mbps(반이중) / USB 3.0 = 5Gbps(전이중). OTG: 4번 핀, 스마트폰을 호스트로.

📢 05. 캐스팅 모드의 전송 방식

유니캐스트 (Unicast)

송신 노드 1 ↔ 수신 노드 1 (1:1 통신)

애니캐스트 (Anycast) IPv6

수신 가능한 노드 중 한 노드에만 전송

멀티캐스트 (Multicast) IPv6

하나 이상의 지정된 수신 노드 그룹에 전송

브로드캐스트 (Broadcast) IPv4

수신 가능한 모든 노드에 전송

🌐 06. 토폴로지 (Topology)

물리적 또는 논리적인 네트워크 배치 방식. 링크와 노드 간 관계를 기하학적으로 표현.

① 버스형 (Bus)

특징

  • 공통 배선(버스)을 모든 노드가 공유, LAN의 일반적 방식
  • 탭(Tap)·유도선(Drop line)으로 노드 연결
  • 한 노드 전송 → 브로드캐스트로 모든 노드 수신

장점 / 단점

  • 👍 설치 간단·저렴, 링크 길이 최소화, 노드 오류 영향 적음
  • 👎 버스 고장 시 전체 마비, 둘 이상 동시 전송 시 충돌, 노드 수 증가 시 성능 저하

② 스타형 (Star)

특징

  • 각 노드는 중앙 허브와 점대점 연결
  • 중앙 허브가 통신 제어 권한·책임
  • 모든 전송은 허브를 통해 중계

장점 / 단점

  • 👍 설치 비용 저렴(노드당 링크 1개), 고장 발견 쉬움, 노드 증설 쉬움, 한 링크 끊겨도 다른 링크 영향 없음
  • 👎 허브 장애 = 전체 마비, 링크 수 많음, 데이터 증가 시 지연

③ 링형 (Ring)

특징

  • 각 노드는 양쪽 노드와 점대점 연결
  • 신호는 한 방향으로 링을 따라 순환

장점 / 단점

  • 👍 설치·재구성 쉬움, 스타형보다 링크 짧음(경제적), 장애 노드 파악 쉬움
  • 👎 제어 절차 복잡, 노드 1개 장애로 전체 마비 → 이중 링으로 해결, 노드 추가 시 링 절단 필요

④ 메쉬형 (Mesh)

특징

  • 모든 노드 간 점대점 직접 연결
  • 장애 시 대체 경로 전달 가능
  • 링형과 함께 네트워크 백본 구성에 사용
물리 채널 수 = n(n−1)/2  |  입출력 포트 수 = (n−1)

장점

  • 신뢰성 우수
  • 고장 발견 쉬움
  • 다른 트래픽 영향 최소

단점

  • 선로 구축 비용 많음
  • 설치·설정 복잡, 시간 소요

⑤ 트리형 (Tree)

특징

  • 스타형의 변형, 중앙 허브는 능동적 허브(중계기 기능)
  • 대부분 노드는 2차 허브에 연결(능동/수동)
  • 2차 허브로 통신 분리·우선순위 부여 가능

장점 / 단점

  • 👍 고장 발견·노드 증설 쉬움, 1차 허브에 많은 노드 연결, 우선순위 부여
  • 👎 중앙 허브 병목 현상, 중앙 허브 장애 시 마비/분할

⑥ 혼합형 (Hybrid)

  • 네트워크 규모·용도에 따라 다양한 형태 결합
  • 여러 LAN을 연결한 MAN/WAN에서 자주 등장
  • 여러 종류 기술 사용 → 관리가 어려움

🎯 핵심 캐치 — 시험 빈출

🏆

다중점 = 멀티드롭, 폴링·셀렉션

다중점(Multipoint) 회선의 데이터 전송은 폴링(Polling) + 셀렉션(Selection)으로 수행 (경쟁 방식도 있음).

⚡

집선 vs 다중화

집선 = 도착 순서대로 한 단말이 독점, 다중화 = 주파수·시간 분할로 동시 사용.

📞

이용 방식 예시 암기

Simplex = TV/라디오 / Half-duplex = 무전기 / Full-duplex = 전화·컴퓨터 통신

🧮

전송 효율 공식

(정보 비트 / 전체 비트) × 100%. 비동기식은 시작·종료 비트 포함, 동기식은 SYN/STX/ETX 포함.

🔌

EIA-232 핵심 수치

15m 이내, 20Kbps 이하, 25/9핀 커넥터. UART는 논리 호환(TTL ↔ ±12V).

🌐

메쉬 회선·포트 수

회선 = n(n−1)/2, 각 노드 포트 = n−1. 백본망 구성에 사용.

🔁

토폴로지 단점 패턴

버스 = 충돌·버스 고장, 스타·트리 = 중앙 허브 고장 시 전체 마비, 링 = 단일 노드 장애로 마비(이중링으로 해결).

📡

캐스팅 모드 구분

Anycast = IPv6 신규 / Multicast = IPv6 / Broadcast = IPv4 (IPv6에는 브로드캐스트 없음).

📝 예제 풀이

예제 5-1. 직렬 → 8비트 병렬로 변경 시 속도 향상은?

병렬 전송은 동시에 8비트를 전송하므로 직렬 대비 8배의 전송 속도 향상이 예상된다.

∴ 8배 향상
예제 5-2. 7비트 문자 + 시작 1비트 + 종료 1비트 비동기식 전송 효율

전송 효율 = 정보 비트 ÷ 전체 비트

전송 효율 = 7 / (1+7+1) × 100 = 7/9 × 100 ≈ 77.78 %
예제 5-3. 문자 위주 동기식 전송 효율 (STX 8b, ETX 8b, 100문자×8b)

동기식: 800 / (8 + 800 + 8) × 100 = 800/816 × 100 ≈ 98 %

비동기식 비교: 800 / (100 + 800 + 100) × 100 = 800/1000 × 100 = 80 %

동기식이 비동기식보다 전송 효율이 훨씬 높다 (98% vs 80%)
예제 5-4. 메쉬형 토폴로지에서 노드 120개일 때 전체 회선 수

회선 수 = n(n−1)/2 = 120 × 119 / 2

∴ 120 × 119 / 2 = 7,140 개
