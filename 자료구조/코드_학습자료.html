📦 선형 큐 (Linear Queue)
구조체 & 초기화
#define MAX_SIZE 5 typedef struct { int data[MAX_SIZE]; // 데이터 배열 int front; // 삭제 위치 int rear; // 삽입 위치 } QueueType; void init(QueueType *q) { q->front = -1; q->rear = -1; }
왜 -1로 초기화?

공백 조건이 front == rear이기 때문에 초기에 둘 다 같은 값으로 맞춰야 해요.
-1에서 시작해 삽입/삭제마다 ++ 하면 인덱스 0부터 사용돼요.

void enqueue(QueueType *q, int e) { if (isFull(q)) return; q->data[++(q->rear)] = e; // rear++ 후 data[rear] = e 와 동일 }

⚠️ 선형 큐의 문제점
dequeue를 반복하면 front가 오른쪽으로 밀려 왼쪽 공간이 낭비돼요.
rear가 MAX-1에 닿으면 앞에 빈 칸이 있어도 isFull 판정 → 해결: 원형 큐
🔄 원형 큐 (Circular Queue)
선형 큐와 달라지는 점
항목선형 큐원형 큐
초기값front = rear = -1front = rear = 0
인덱스 증가rear++rear = (rear+1) % MAX
isFull 조건rear == MAX-1(rear+1) % MAX == front
공간 효율삭제 후 공간 낭비공간 재활용 ✅
구조체 & 초기화
#define MAX_SIZE 5 typedef struct { int data[MAX_SIZE]; int front; int rear; } QueueType; void init(QueueType *q) { q->front = 0; // 선형은 -1, 원형은 0 q->rear = 0; }
왜 0으로 초기화?

% MAX 연산을 사용하기 때문에 -1이 아닌 0에서 시작해요.
공백 조건 front == rear는 동일하게 성립해요.

1칸을 항상 비워두는 이유
공백: front == rear
포화: (rear+1) % MAX == front
두 조건을 구분하기 위해 배열 한 칸은 사용하지 않아요.
isEmpty / isFull
int isEmpty(QueueType *q) { return q->front == q->rear; } int isFull(QueueType *q) { return (q->rear + 1) % MAX_SIZE == q->front; }

enqueue / dequeue
void enqueue(QueueType *q, int e) { if (isFull(q)) return; q->rear = (q->rear + 1) % MAX_SIZE; q->data[q->rear] = e; } int dequeue(QueueType *q) { if (isEmpty(q)) return -1; q->front = (q->front + 1) % MAX_SIZE; return q->data[q->front]; }
원형 순환 — rear가 끝에 닿으면 0으로!
rear=0 → (0+1)%5 = 1
rear=1 → (1+1)%5 = 2
rear=2 → (2+1)%5 = 3
rear=3 → (3+1)%5 = 4
rear=4 → (4+1)%5 = 0 ← 처음으로!
↔️ 덱 (Deque — Double-ended Queue)
4가지 연산 한눈에 비교
연산방향포인터 이동 수식저장/반환 순서
add_rear→ 오른쪽rear = (rear+1) % MAX이동 먼저 → 저장
delete_front→ 오른쪽front = (front+1) % MAX이동 먼저 → 반환
add_front← 왼쪽front = (front-1+MAX) % MAX저장 먼저 → 이동
delete_rear← 왼쪽rear = (rear-1+MAX) % MAX저장 먼저 → 이동
오른쪽 이동: (x+1) % MAX  |  왼쪽 이동: (x-1+MAX) % MAX (음수 방지용 +MAX)
add_rear / delete_front (원형 큐와 동일)
void add_rear(QueueType *q, int e) { if (isFull(q)) return; q->rear = (q->rear + 1) % MAX_SIZE; q->data[q->rear] = e; // 원형 큐 enqueue와 완전히 동일 } int delete_front(QueueType *q) { if (isEmpty(q)) return -1; q->front = (q->front + 1) % MAX_SIZE; return q->data[q->front]; // 원형 큐 dequeue와 완전히 동일 }

🤔 포인터 * 하나 vs ** 두 개
구분의미언제 쓰나
*headhead가 가리키는 노드의 내용 수정중간 삽입, 삭제, 큐 연산
**headhead가 가리키는 곳 자체를 변경맨 앞 삽입 (head가 새 노드를 가리켜야 할 때)
❌ * 하나로 하면 — 원본 head 안 바뀜
void insert(ListNode *head, int data) { ListNode *new = malloc(...); new->link = head; head = new; // 복사본만 바뀜! // 원본 head는 그대로 }
✅ ** 두 개로 하면 — 원본 head 바뀜
void insert(ListNode **head, int data) { ListNode *new = malloc(...); new->link = *head; *head = new; // 원본 head가 new를 가리킴! }
큐는 왜 * 하나?
큐는 q가 가리키는 곳을 바꾸는 게 아니라 q 안의 내용물(rear, data[])을 수정하는 거라서 * 하나로 충분해요.
맨 앞 삽입은 head가 완전히 다른 노드를 가리키도록 바꿔야 하니까 **가 필요해요.
노드 구조체
#include <stdlib.h> typedef struct ListNode { int data; // 데이터 필드 struct ListNode *link; // 다음 노드 주소 } ListNode; ListNode *head = NULL; // 처음엔 비어있음

맨 앞에 삽입 (insert_front)
void insert_front(ListNode **head, int data) { ListNode *new = (ListNode*)malloc(sizeof(ListNode)); new->data = data; new->link = *head; // ① 기존 head 연결 *head = new; // ② head를 새 노드로 }
**head인 이유: 함수 안에서 head 포인터 자체를 바꿔야 하기 때문. *head만 넘기면 복사본이라 원본이 안 바뀌어요.
insert_front(5) 실행
before: head → [10] → [20] → NULL
  1. new 노드 생성, data=5
  2. new->link = *head (= [10])
  3. *head = new
after: head → [5] → [10] → [20] → NULL
중간에 삽입 (insert_after) 순서 중요!
void insert_after(ListNode *prev, int data) { ListNode *new = (ListNode*)malloc(sizeof(ListNode)); new->data = data; new->link = prev->link; // ① 먼저! prev->link = new; // ② 나중에! }
①번을 먼저 안 하면 prev->link가 덮어써져서
기존 다음 노드 주소를 영원히 잃어버려요!
❌ ②먼저 하면 어떻게 되는가
prev->link = new    → [10] → [20]
new->link = prev->link → new->link = new 자기 자신!
[30] 주소를 이미 잃어버린 상태 💀
prev=[10] 뒤에 [20] 삽입
before: [10] → [30] → NULL
① new->link = prev->link = [30]
   ([20] → [30] 연결됨)
② prev->link = new
   ([10] → [20] 연결됨)
after: [10] → [20] → [30] → NULL ✅
노드 삭제 (delete_after)
void delete_after(ListNode *prev) { ListNode *target = prev->link; // ① 저장 prev->link = target->link; // ② 건너뜀 free(target); // ③ 해제 }
prev=[10] 다음 [20] 삭제
before: [10] → [20] → [30] → NULL
① target = [20]
② prev->link = target->link = [30]
   ([10] → [30])
③ free([20])
after: [10] → [30] → NULL ✅
전체 순회 (print_list)
void print_list(ListNode *head) { ListNode *cur = head; while (cur != NULL) { printf("%d → ", cur->data); cur = cur->link; // 다음 노드로 이동 } printf("NULL\n"); }
순회 패턴: cur = head → while(cur != NULL) → cur = cur->link
이 패턴은 연결 리스트 어디서든 자주 쓰여요.
🌳 이진 트리 순회 (Tree Traversal)
트리 노드 구조체
typedef struct TreeNode { char data; struct TreeNode *left; // 왼쪽 자식 struct TreeNode *right; // 오른쪽 자식 } TreeNode;
연결 리스트와 비교
구분연결 리스트이진 트리
포인터*link 1개*left, *right 2개
방향단방향두 갈래
🤔 if (root == NULL) return 이 왜 필요한가?

순회는 재귀함수예요. 자기 자신을 계속 호출하다가
잎 노드(자식 없음)에서 멈춰야 해요.
잎 노드의 left, right는 NULL이기 때문에
NULL 체크가 없으면 무한루프가 발생해요.

preorder(D) 호출 흐름 — D는 잎 노드
preorder(D) 호출
  printf D
  preorder(NULL) → if NULL → return!
  preorder(NULL) → if NULL → return!
← 여기서 멈추고 상위 함수로 돌아감
3가지 순회 — print 위치만 다름!
순회순서기억법
전위 (Preorder)루트 → 왼쪽 → 오른쪽루트가 앞(pre)
중위 (Inorder)왼쪽 → 루트 → 오른쪽루트가 중간(in)
후위 (Postorder)왼쪽 → 오른쪽 → 루트루트가 뒤(post)
전위 순회 (Preorder)
void preorder( TreeNode *root) { if(root==NULL) return; printf("%c ", root->data); // ↑ 루트 먼저 preorder(root->left); preorder(root->right); }
중위 순회 (Inorder)
void inorder( TreeNode *root) { if(root==NULL) return; inorder(root->left); printf("%c ", root->data); // ↑ 루트 중간 inorder(root->right); }
후위 순회 (Postorder)
void postorder( TreeNode *root) { if(root==NULL) return; postorder(root->left); postorder(root->right); printf("%c ", root->data); // ↑ 루트 마지막 }

    A

 / \   \
D   E   F

중위: D → B → E → A → F → C
후위: D → E → B → F → C → A
