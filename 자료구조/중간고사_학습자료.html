Q. ADT란?
Abstract Data Type — 자료형을 "데이터 + 연산의 집합"으로 추상화해 정의한 것. 구체적 구현은 드러내지 않음
Q. 실생활 비유?
TV 리모컨 — 어떤 버튼이 어떤 기능을 하는지만 알면 됨. 내부 회로가 어떻게 구현됐는지는 몰라도 사용 가능
Q. ADT의 장점 2가지?
① 정보 은닉 (Information Hiding) — 구현 상세를 가림
② 정보 보호 (Information Protection) — 외부에서 함부로 데이터를 바꾸지 못하게 함
Q. ADT와 클래스의 관계?
ADT 개념이 객체지향 언어의 클래스(class)로 발전함. Python · Java의 class는 ADT의 대표적 구현
📘 자연수 ADT 예시 (강의 대표 예제)
  • 데이터: 0 이상의 정수
  • 연산: is_zero(n), successor(n)(다음 수), add(a,b), sub(a,b), equal(a,b)
  • 내부적으로 어떻게 저장·계산하는지는 감춤 → 사용자는 연산만 호출

5최선 · 최악 · 평균 경우 ⭐⭐
Q. 최선의 경우 (Best Case)
입력이 가장 빨리 처리되는 경우. 순차 탐색에서 찾는 값이 첫 원소일 때 → O(1). 운에 의존해 거의 의미 없음
Q. 최악의 경우 (Worst Case)
입력이 가장 오래 걸리는 경우. 순차 탐색에서 값이 마지막이거나 없을 때 → O(n). 성능 보장을 위해 주로 분석
Q. 평균적 경우 (Average Case)
입력 분포를 가정한 평균 연산 횟수. 계산이 복잡해 최악의 경우가 대신 쓰이는 경우가 많음
Q. 왜 "최악"을 주로 분석하는가?
"이 알고리즘은 아무리 나빠도 O(n)이다"라는 상한 보장을 줄 수 있기 때문. 실무에서 가장 안전한 기준
6순환함수 (Recursion) ⭐⭐⭐
정의
함수가 자기 자신을 호출
Self-call — 문제를 더 작은 같은 문제로 쪼개 해결
🧱 순환함수의 필수 3요소
  1. 종료 조건 (base case) — 무한 루프를 막는 멈춤 지점
  2. 입력이 줄어듦 — 매 호출마다 문제 크기가 작아져야 종료에 도달
  3. 자기 자신 호출 — 더 작은 입력으로 재호출
// 팩토리얼 — 순환의 교과서 예제 int factorial(int n) { if (n <= 1) return 1; // ① 종료 조건 return n * factorial(n - 1); // ② 입력 감소 ③ 자기 호출 } // factorial(4) → 4 * factorial(3) → 4*3*factorial(2) → ... // → 4*3*2*1 = 24
  • 순환함수는 OS의 시스템 스택에 각 호출의 반환 주소·지역변수를 저장 → 역순으로 복귀 (DAY 3 시스템 스택과 연결)
  • 대부분의 순환함수는 반복문으로도 구현 가능 (둘은 등가)
7순환 vs 반복 — 효율성 비교 ⭐⭐
결론
문제의 성질에 맞게 선택
분할정복형 → 순환 유리 / 단순 누적형 → 반복 유리
✅ 순환이 유리한 경우 — 거듭제곱 xⁿ
  • 반복으로 xⁿ 계산: x를 n번 곱함 → O(n)
  • 순환 분할: xn = (xn/2)² → 매 단계 문제 크기 절반 → O(log n)
  • n=1024일 때 반복은 1024번, 순환은 10번만에 끝남
// 순환으로 O(log n) 거듭제곱 int power(int x, int n) { if (n == 0) return 1; int half = power(x, n/2); if (n % 2 == 0) return half * half; else return half * half * x; }
❌ 순환이 불리한 경우 — 피보나치
  • fib(n) = fib(n-1) + fib(n-2) 처럼 정의를 그대로 순환 → 중복 계산이 폭발 → O(2ⁿ)
  • 반복(루프)으로 구현하면 값을 누적해 O(n)
  • "순환이 항상 좋다"가 아님 — 중복 부분 문제가 있으면 반복/DP가 유리

1포인터의 정의와 용도 ⭐⭐⭐
Q. 포인터(Pointer)란?
데이터가 저장된 메모리 상의 주소(위치)를 값으로 가지는 변수. 데이터 자체가 아니라 데이터가 있는 곳을 가리킴
Q. 포인터를 쓰는 가장 중요한 이유?
함수 호출 시 원본 데이터의 복사본이 아니라 주소를 넘겨, 받는 쪽에서 원본 데이터를 찾아가 값을 바꿀 수 있게 하기 위함
Q. 값 호출(call by value)의 문제점?
함수의 파라미터는 인수의 복사본을 받으므로, 함수 안에서 아무리 값을 바꿔도 원본은 변하지 않음
Q. 주소 호출(call by address)이란?
복사본 대신 원본 데이터의 주소를 넘기고, 받는 쪽에서 그 주소를 따라가 원본을 직접 수정하는 방식. 포인터가 이를 가능하게 함
2포인터 선언과 두 가지 연산자 ⭐⭐⭐
앞글자 암기법
& · *
& = 주소(address-of) · * = 값 꺼내기(dereference)
연산자이름역할예
&주소 연산자변수의 주소를 반환&a → a의 주소
* (선언문)포인터 선언해당 변수가 포인터임을 선언int *p;
* (실행문)역참조 연산자포인터가 가리키는 값을 꺼냄*p = 10; → p가 가리키는 곳에 10
// 포인터 선언과 사용 int a = 10; // 정수형 변수 int *p; // 정수를 가리키는 포인터 p = &a; // a의 주소를 p에 저장 *p = 20; // p가 가리키는 곳(=a)에 20 대입 // 결과: a == 20
  • 포인터 변수는 타입과 함께 선언: int *p는 int형 데이터의 주소, char *pc는 char형 데이터의 주소만 저장 가능
  • 주소는 크기가 고정: 숫자가 아닌 "위치"이므로 곱하기·나누기는 불가, 더하기·빼기만 제한적으로 허용 (배열 원소 이동용)
  • NULL 포인터: 아무 것도 가리키지 않는 상태, 동적할당 실패 시 NULL을 리턴
3지역변수와 스와핑(swap) 예제 ⭐⭐
Q. 지역변수(local variable)란?
함수 내부에서 선언된 변수. 함수가 호출될 때 메모리가 할당되고, 함수가 끝나면 회수됨
Q. 파라미터(parameter)는 원본인가?
아니다. 파라미터는 인수의 복사본을 담는 지역변수. 여기를 아무리 바꿔도 원본은 그대로
❌ 잘못된 swap — 값 호출
void swap(int x, int y) { int tmp = x; x = y; y = tmp; } // main에서 swap(a, b) 호출해도 a, b 안 바뀜! // x, y는 a, b의 복사본일 뿐
✅ 올바른 swap — 주소 호출
void swap(int *x, int *y) { int tmp = *x; *x = *y; *y = tmp; } // 호출: swap(&a, &b); // 주소를 넘겼으므로 함수 안에서 원본을 직접 수정
4배열과 포인터의 관계 ⭐⭐⭐
핵심 한 문장
배열 이름 = 포인터 상수
배열 이름은 첫 번째 원소의 주소를 값으로 갖는 포인터 상수(값 변경 불가)
  • 배열 선언: int a[6]; → 6개의 int 공간이 연속으로 메모리에 할당됨
  • 배열 이름 a: 그 자체로 &a[0]과 같은 주소값 (첫 원소의 주소)
  • 포인터 상수: 주소값이 고정되어 변경 불가 → a = ... 같은 대입은 컴파일 에러
  • 배열 ↔ 포인터: a[i] ≡ *(a+i)
int a[5] = {10, 20, 30, 40, 50}; int *p = a; // p는 a[0]의 주소 (= &a[0]) p[2] // == a[2] == 30 *(p+2) // == 30 (주소 이동 후 값 꺼내기) *(a+2) // == 30
5배열을 함수에 전달 — 주소 + 크기 ⭐⭐
  • 배열을 함수에 보낼 때는 배열 이름(=첫 원소 주소)만 넘어감
  • 받는 쪽은 배열의 크기(개수)를 알 수 없음 → sizeof로 구해봐야 포인터 크기만 나옴
  • 따라서 주소와 함께 배열 크기(int n)를 함께 파라미터로 전달해야 함
void printArr(int *arr, int n) { // 주소 + 크기 for (int i = 0; i < n; i++) printf("%d ", arr[i]); } // 호출: printArr(a, 6); // 크기를 안 넘기면 어디까지 읽어야 할지 모름
6연산자의 우선순위 규칙
  • 우선순위가 다를 때: 우선순위 높은 연산자부터 계산 (예: * 가 + 보다 먼저)
  • 우선순위가 같을 때: 이항 연산자는 왼쪽 → 오른쪽, 단항 연산자는 오른쪽 → 왼쪽으로 결합
  • 이 우선순위 규칙 때문에 중위식은 복잡 → 나중에 후위식으로 변환 (DAY 3에서 등장)
7포인터 산술 · scanf의 & · rand() ⭐⭐
핵심 한 줄
p + 1 = 1바이트 이동이 아니라 sizeof(타입) 만큼 이동
타입메모리 크기 (일반적)p+1이 이동하는 바이트
char1 byte+1
int4 bytes+4
float4 bytes+4
double8 bytes+8
int a[5] = {10, 20, 30, 40, 50}; int *p = a; p // a[0]의 주소 (예: 1000) p + 1 // a[1]의 주소 (1004) — sizeof(int)=4만큼 이동 *(p+2) // a[2]의 값 = 30 p++; // p를 다음 원소로 이동
📌 scanf에서 왜 &를 붙이는가?
  • scanf("%d", &a) — scanf는 입력값을 저장할 주소가 필요하므로 변수 a의 주소를 넘겨줌
  • 배열·문자열은 이미 이름이 주소 → scanf("%s", str) 처럼 & 생략
  • &를 빠뜨리면 "복사본"을 넘긴 꼴이라 원래 변수에 값이 안 들어감 (런타임 에러·쓰레기값)
🎲 rand() — 랜덤 넘버 생성 (강의 예제)
#include <stdlib.h> rand() % 10 // 0~9 사이 난수 rand() % 100 + 1 // 1~100 사이 난수 for (int i = 0; i < 10; i++) a[i] = rand() % 10; // 배열에 난수 10개 채우기
82차원 배열 — 행(row) · 열(column) ⭐⭐
용어 정리
가로 = 행 · 세로 = 열
a[i][j] → i는 행 번호, j는 열 번호
  • 2차원 배열: 같은 타입의 데이터를 행 × 열로 저장 (표, 행렬, 바둑판)
  • 선언: int a[3][4]; → 3행 4열, 총 12개 원소
  • 접근: a[i][j] — i는 0 ~ 행 수-1, j는 0 ~ 열 수-1
  • 메모리에는 행 우선(row-major)으로 연속 저장 (C 언어 기본)
int a[2][3] = { {1, 2, 3}, // 0번 행 {4, 5, 6} // 1번 행 }; a[1][2] // == 6 (1번 행, 2번 열) // 전체 순회 for (int i = 0; i < 2; i++) for (int j = 0; j < 3; j++) printf("%d ", a[i][j]);
9자동 형변환 vs 강제 형변환 (Cast) ⭐
2가지 형변환
자동 · 강제
자동 = 컴파일러가 / 강제 = 캐스트 연산자 (type) 로 직접
구분자동 형변환 (묵시적)강제 형변환 (명시적)
주체컴파일러가 자동 수행개발자가 (타입) 표기로 직접
발생 조건타입이 다른 연산·대입 시프로그래머가 원할 때
변환 방향좁은 → 넓은 타입 (안전한 쪽)양방향 가능 (손실 주의)
예1 + 0.5 → 1.0 + 0.5 = 1.5(int) 3.7 → 3
// 자동 형변환 int a = 1; float b = 0.5; float c = a + b; // a가 1.0(float)으로 자동 변환 → 1.5 // 강제 형변환 (캐스트 연산자) int x = (int) 3.7; // 3 (소수점 절사) float y = (float) 5 / 2; // 2.5 (5를 float로 바꾼 뒤 나눔) // malloc 반환값 캐스팅 (실무 사용) int *p = (int *) malloc(sizeof(int) * 10);
  • 5 / 2 → 2 (정수끼리 나누면 결과도 정수, 소수점 손실)
  • (float) 5 / 2 → 2.5 (한쪽을 float로 바꾸면 자동 형변환으로 실수 계산)
  • malloc의 반환 타입은 void * → 필요한 포인터 타입으로 캐스팅해서 받음

2구조체 선언과 typedef ⭐⭐⭐
// 기본 선언 struct Student { char name[20]; int id; float gpa; }; // ← 세미콜론 필수 // 변수 선언 struct Student s1; s1.id = 202378145; // 멤버 접근: .

  • 구조체 선언 문법: struct 이름 { 멤버들 }; — 중괄호 뒤 세미콜론 필수

  • typedef: 기존 타입에 별명을 붙여 새로 부름 (ex. struct Student → Student)
3다항식(Polynomial) — 구조체 활용 예제 ⭐

  • 구조체 하나에 여러 항의 계수 배열과 최고 차수를 함께 저장 가능

typedef struct { int degree; // 최고 차수 float coef[MAX]; // 계수 배열 } Polynomial; Polynomial a = {2, {3.0, 2.0, 1.0}}; // 3x² + 2x + 1

5malloc · free · NULL ⭐⭐⭐
// 1. 타입 · 개수 · 바이트 계산해서 할당 int *p = (int *) malloc(sizeof(int) * 10); // 2. 반드시 NULL 체크 (할당 실패 시 NULL 반환) if (p == NULL) { printf("메모리 부족!"); return -1; } // 3. 사용 — 배열처럼 사용 가능 p[0] = 10; *(p+1) = 20; // 4. 다 쓰면 반드시 free! free(p);
  • malloc(바이트 수): 요청한 크기만큼 메모리를 할당하고 시작 주소를 반환 (void * 타입)
  • 동적 할당 메모리는 이름이 없음 → 반드시 포인터로 주소를 받아야 사용 가능
  • 할당 실패: 메모리 부족 시 NULL 반환 → 항상 NULL 체크 필수
  • free(p): 사용이 끝난 공간을 반환 (해제 안 하면 메모리 누수)
  • sizeof(int): 시스템마다 int 크기가 다를 수 있으므로 직접 숫자 쓰지 말고 sizeof 사용

핵심 연산자
.   vs   ->
. = 변수로 접근 / -> = 포인터로 접근 (p->member ≡ (*p).member)

7실전 코딩 보조 도구 — sizeof · #define · calloc · realloc ⭐
📏 sizeof 연산자 — 타입/변수의 바이트 수
  • sizeof(int) · sizeof(Student) · sizeof(arr) 가능
  • 시스템마다 타입 크기가 달라질 수 있어 직접 숫자 대신 sizeof 사용이 원칙
  • 주의: 함수 파라미터로 배열을 받으면 sizeof로 크기를 알 수 없음 → 포인터 크기만 나옴 (그래서 크기를 별도 인자로 전달)
🏷️ #define · const — 상수 선언
#define MAX_SIZE 100 // 전처리기 — 컴파일 전 치환 const int MAX_SIZE = 100; // 변수로 선언하되 수정 불가 int stack[MAX_SIZE]; // 배열 크기에 사용 가능
  • 배열/스택/큐 크기를 하드코딩하지 말고 상수로 선언 → 한 곳만 바꾸면 전체 반영
  • 관례적으로 상수 이름은 대문자 (예: MAX, SIZE, MAX_STACK)
💾 malloc 계열 3총사
함수역할특징
malloc(n)n 바이트 할당초기화 안 됨 (쓰레기값)
calloc(개수, 크기)개수 × 크기 바이트 할당0으로 초기화
realloc(p, n)기존 p를 n 바이트로 크기 재조정동적 스택/배열 확장에 필수
int *p = malloc(sizeof(int) * 10); // 10개 p = realloc(p, sizeof(int) * 20); // 20개로 확장 int *q = calloc(10, sizeof(int)); // 0으로 초기화된 10개 free(p); free(q);
8복소수 구조체 — 구조체 파라미터/리턴 예제 ⭐
핵심 포인트
구조체를 값으로 리턴 가능
구조체는 배열과 달리 통째로 대입·리턴할 수 있음
  • 복소수 = 실수부(real) + 허수부(imag) — 서로 연관된 다른 타입은 아니지만 쌍으로 다루는 대표 예
  • 구조체로 묶으면 함수 파라미터·리턴값으로 한 번에 전달 가능
  • 두 복소수 덧셈: 실수부끼리 + 허수부끼리 더함
typedef struct { float real; // 실수부 float imag; // 허수부 } Complex; // 두 복소수를 더해 결과 구조체를 리턴 Complex add(Complex a, Complex b) { Complex result; result.real = a.real + b.real; result.imag = a.imag + b.imag; return result; // 구조체 리턴 가능! } int main() { Complex x = {1.0, 2.0}; // 1 + 2i Complex y = {3.0, 4.0}; // 3 + 4i Complex z = add(x, y); // 4 + 6i printf("%.1f + %.1fi", z.real, z.imag); }
  • 배열은 리턴 불가, 하지만 구조체는 리턴 가능 — 구조체의 큰 장점
  • 큰 구조체는 복사 비용이 커 포인터로 넘기는 게 효율적 (add(&x, &y) 스타일)

Q. 스택(Stack)이란?
후입선출(LIFO) 방식으로 데이터를 저장·삭제하는 선형 자료구조. 식판 쌓기 비유처럼 맨 위(top)에서만 삽입·삭제가 일어남
Q. 스택의 가장 중요한 위치는?
top — 맨 위 원소의 위치. 삽입·삭제·조회 모두 top에서 발생
Q. 스택은 어떤 종류의 자료구조?
선형(Linear) · 순서 있음 · 0개 이상의 원소를 가짐 (추상 데이터 타입, ADT)
Q. 일상 활용 예?
되돌리기(Undo), 브라우저 뒤로가기, 함수 호출의 반환 주소 추적, 컴파일러의 괄호 검사, 후위식 계산
2스택의 연산 5가지 ⭐⭐⭐
연산 앞글자
푸 · 팝 · 픽 · 엠 · 풀
push · pop · peek · isEmpty · isFull
연산역할top의 변화
create(size)빈 스택 생성top = -1
push(x)스택 맨 위에 x 삽입top ← top + 1
pop()맨 위 원소 제거 후 반환top ← top - 1
peek()맨 위 원소 조회 (제거 없이)변화 없음
isEmpty()비었는가? (top == -1)-
isFull()가득 찼는가? (top == size-1)-
  • push / pop은 핵심(필수) 연산, isEmpty / isFull은 보조 연산 (삽입·삭제 전 체크용)
  • 오버플로우(overflow): 가득 찬 스택에 push 시도 → isFull 체크로 방지
  • 언더플로우(underflow): 빈 스택에서 pop 시도 → isEmpty 체크로 방지
3배열을 이용한 스택 구현 ⭐⭐⭐
  • 1차원 배열과 top 변수 두 가지만 있으면 스택 구현 가능
  • 빈 스택의 초기 top = -1
  • 데이터가 N개 들어가면 top = N-1 (0-based index)
// 스택 선언 #define MAX 100 int stack[MAX]; int top = -1; // 비어있음 // push void push(int x) { if (top >= MAX - 1) { // isFull 체크 printf("Stack Overflow"); return; } top++; stack[top] = x; } // pop int pop() { if (top == -1) { // isEmpty 체크 printf("Stack Underflow"); return -1; } int x = stack[top]; top--; return x; }
⚠️ pop의 순서 주의
  • 데이터를 먼저 꺼내 저장한 뒤 top을 감소시켜야 정확한 값을 반환
  • top을 먼저 감소시키면 엉뚱한 값이 반환됨
4시스템 스택 — 함수 호출의 비밀 ⭐
  • 함수가 호출되면 OS가 시스템 스택에 반환 주소 + 지역변수 + 파라미터를 저장
  • 함수가 끝나면 저장된 정보를 pop해 역순으로 복귀
  • A → B → C 순으로 호출되면, 리턴은 C → B → A 순 (LIFO)
  • 순환(재귀) 함수의 무한 호출 방지 및 인터럽트 복귀에도 활용
5스택 응용 ① 괄호 검사 ⭐⭐⭐
괄호 검사 3단계
왼쪽 push / 오른쪽 pop+매칭 / 끝에 비어야 OK
📘 알고리즘
  1. 수식을 왼쪽부터 읽으며, 왼쪽 괄호( (, {, [ )가 나오면 스택에 push
  2. 오른쪽 괄호( ), }, ] )가 나오면 pop하여 짝이 맞는지 비교
    • 스택이 비어있으면 오류 (오른쪽이 더 많음)
    • 짝이 안 맞으면 오류 (예: (])
  3. 수식을 다 읽은 뒤 스택이 비어있으면 성공, 뭔가 남아있으면 오류 (왼쪽이 더 많음)
💡 예시: ( [ a + b ] )
  • ( → push [ ( ]
  • [ → push [ ( , [ ]
  • ] → pop [, 매칭 OK
  • ) → pop (, 매칭 OK
  • 끝 → 스택 비어있음 → ✅ 성공
6스택 응용 ② 수식의 세 가지 표기법 ⭐⭐⭐
표기법 3종
중 · 전 · 후
중위(infix) · 전위(prefix) · 후위(postfix)
표기법연산자 위치예시 (A+B)특징
중위(Infix)피연산자 사이A + B사람이 쓰는 일반 수식, 우선순위·괄호 필요
전위(Prefix)피연산자 앞+ A B연산자 먼저, 괄호 불필요
후위(Postfix)피연산자 뒤A B +컴퓨터가 선호, 스택으로 쉽게 계산, 괄호·우선순위 불필요
  • 컴퓨터는 중위식을 바로 계산하기 어려움 (우선순위 규칙 때문) → 후위식으로 변환 후 계산
  • 변환된 후위식은 왼쪽 → 오른쪽으로 한 번만 훑으면서 스택으로 처리 가능
📘 예: 2 + 3 × 4 변환
  • 중위: 2 + 3 × 4
  • 후위: 2 3 4 × + (우선순위가 높은 × 의 피연산자를 먼저 묶음)
  • 전위: + 2 × 3 4
7스택 응용 ③ 후위식 계산법 ⭐⭐⭐
계산 규칙 2개
피연산자 = push / 연산자 = pop 2번 → 계산 → push
📘 알고리즘
  1. 토큰을 왼쪽부터 읽음
  2. 피연산자(숫자)면 → 스택에 push
  3. 연산자면 → 스택에서 pop을 두 번 (두 번째 꺼낸 것이 왼쪽 피연산자) → 계산 → 결과를 push
  4. 끝나면 스택에 남은 하나의 값이 최종 결과
⚠️ pop 순서에 유의 — 나중에 꺼낸 것이 왼쪽 피연산자
💡 예: 2 3 4 × + 계산
  • 2 → push, 스택 [2]
  • 3 → push, 스택 [2, 3]
  • 4 → push, 스택 [2, 3, 4]
  • × → pop 4, pop 3 → 3×4=12 → push 12, 스택 [2, 12]
  • + → pop 12, pop 2 → 2+12=14 → push 14, 스택 [14]
  • 결과 = 14
🔁 전위식(Prefix) 계산법 — 후위와 대칭
  • 전위식은 토큰을 오른쪽 → 왼쪽으로 읽음 (후위와 반대 방향)
  • 피연산자면 push, 연산자면 pop 2번 → 계산 → push (먼저 꺼낸 게 왼쪽 피연산자 — 후위와 반대)
  • 예: + 2 × 3 4 = 2 + (3×4) = 14
⚖️ 연산자 우선순위 규칙
  • 우선순위가 다르면: 높은 것부터 계산 (×, ÷ > +, −)
  • 같으면 — 이항 연산자: 왼쪽 → 오른쪽 순서로 (예: 10 − 3 − 2 = (10−3)−2 = 5)
  • 같으면 — 단항 연산자: 오른쪽 → 왼쪽 순서 (예: -*p는 -(*p))
  • 이 규칙이 복잡해 중위식은 계산이 어렵고 → 후위식으로 변환하면 우선순위·괄호가 자동으로 풀림
8스택 응용 ④ 중위 → 후위 변환 ⭐⭐⭐
변환 규칙 핵심
피연산자 바로 출력 / 연산자는 스택 거쳐서 출력
컴퓨터가 계산하기 쉬운 후위식으로 바꾸는 알고리즘
📘 토큰별 처리 규칙
  1. 피연산자 (숫자·변수) → 결과에 바로 출력
  2. 여는 괄호 ( → 스택에 push
  3. 닫는 괄호 ) → 스택에서 (를 만날 때까지 pop해서 출력, (는 버림
  4. 연산자 → 스택 top의 연산자와 우선순위 비교
    • 스택 top의 우선순위가 높거나 같으면 → pop해서 출력 후 현재 연산자 push
    • 스택 top의 우선순위가 낮으면 → 바로 push
  5. 수식 끝 → 스택에 남은 연산자들을 모두 pop해서 출력

9ADT — 추상 데이터 타입 ⭐⭐
ADT 정의
데이터 + 연산 = 하나로 추상화
"무엇을 할 수 있는가"만 보이고, "어떻게 구현됐는가"는 감춤
  • ADT (Abstract Data Type): 자료구조를 "데이터 + 연산"의 쌍으로 추상화해서 정의한 것
  • 사용자는 연산의 이름·입출력만 알면 되고, 내부 구현(배열? 연결리스트?)은 몰라도 됨
  • 같은 ADT라도 구현 방식은 여러 가지 (스택 → 배열 기반 / 연결리스트 기반)
📘 스택 ADT 정의 예
  • 데이터: 0개 이상의 원소를 가진 선형 리스트
  • 연산: create, push, pop, peek, isEmpty, isFull
10이중 포인터(**) · 동적 스택 구현 ⭐
이중 포인터란
포인터를 가리키는 포인터
포인터 자체의 주소를 담아야 할 때 사용 (= 포인터의 값을 바꾸고 싶을 때)
  • 포인터도 변수 → 포인터의 값(가리키는 주소)을 함수에서 바꾸려면 포인터의 주소가 필요
  • 스택의 배열을 동적 확장(realloc)할 때 시작 주소가 바뀌므로 이중 포인터를 통해 넘김
  • 일반 swap처럼: "원본을 바꾸려면 주소를 넘겨라" 규칙의 포인터 버전
int a = 10; int *p = &a; // 포인터 — a의 주소 int **pp = &p; // 이중 포인터 — p의 주소 *p // == a (10) **pp // == *p == a (10)
🧱 구조체 기반 스택 — 실전 구현 패턴
typedef struct { int *data; // 동적 배열 int top; // 현재 top 위치 int capacity; // 현재 배열 크기 } Stack; void init(Stack *s, int size) { s->data = (int*) malloc(sizeof(int) * size); s->top = -1; s->capacity = size; } void push(Stack *s, int x) { if (s->top >= s->capacity - 1) { s->capacity *= 2; // 꽉 차면 2배 확장 s->data = realloc(s->data, sizeof(int) * s->capacity); } s->data[++(s->top)] = x; }
  • 전역변수 대신 구조체로 스택을 묶으면 여러 개의 스택을 독립적으로 사용 가능
  • 함수는 Stack* 포인터를 받아야 원본 스택이 바뀜 (값 복사 금지)
