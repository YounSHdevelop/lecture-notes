0. 확률과 통계 기초 개요

확률 = 가능성의 언어

  • 사건 → 확률 → 변수 → 분포 구조
  • 확률(가능성) → 분포 → 추정/검정 흐름

통계 = 데이터로 판단

  • 통계적 추론: 표본으로 모집단의 모수를 추정
  • 점 추정 & 구간 추정

3대 확률 이론

  • 대수의 법칙
  • 중심극한정리
  • 대편차 원리

가설 검정: 귀무(null) 가설 vs 대립(alternative) 가설을 세우고 데이터로 판정

0-1. 확률 기초 — 표기법

기호의미설명
Pr(·)확률 함수사건(event)이 파라미터
P(·)확률질량함수 (PMF)이산확률변수가 파라미터
p(·)확률밀도함수 (PDF)연속확률변수가 파라미터
A, B사건 (Event)대문자로 표기
x, y확률변수소문자로 표기

측도론에서 확률은 전체집합 U에 대하여 μ(U)=1로 정규화된 측도이다.

0-2. 확률이란?

확률의 정의

  • 어떤 일이 얼마나 자주 일어나는지를 숫자(0~1)로 표현
  • 전체 확률의 합 = 1

핵심 용어

  • 실험 = 결과를 모르는 행동
  • 표본공간(Ω) = 가능한 모든 결과
  • 사건 = 표본공간의 부분집합
  • 확률 = (사건) / (전체)

확률공간 (Ω, F, Pr)

  • Ω: 전체 결과 (표본공간)
  • F: 사건들의 모음 (시그마 대수)
  • Pr(·): 확률 함수, 0~1 사이

0-3. 확률의 공리 (Probability Axioms)

공리 = 증명 없이 참으로 받아들이는 사실

공리 1 — 비음수성
Pr(A) ≥ 0   (모든 사건 A에 대해)
공리 2 — 정규성
Pr(Ω) = 1   (전체 확률은 1)
공리 3 — 가법성 (서로소)
A ∩ B = ∅ ⇒ Pr(A ∪ B) = Pr(A) + Pr(B)
추가
Pr(∅) = 0   (불가능한 사건의 확률 = 0)

0-4. 확률변수 (Random Variable)

  • 확률변수: 결과를 숫자로 바꿔주는 함수
  • 표본공간: 모든 가능한 결과. Ω = {1,2,3,4,5,6}
  • 확률변수: X: Ω → ℝ (결과를 숫자로 매핑)
  • 실현값(realization): 특정 결과가 나왔을 때의 실제 값

0-5. 확률 분포 (Probability Distributions)

이산형 (Discrete)

값이 딱딱 끊어지는 경우
예: 주사위 {1,2,3,4,5,6}

연속형 (Continuous)

값이 부드럽게 이어지는 경우
예: 키, 온도, 시간

분포의 확장 흐름
균등분포 → 베르누이 → 이항분포 → 푸아송분포 → 정규분포

0-6. 3가지 확률 이론

대수의 법칙

평균이 진짜 값으로 간다

많이 반복하면 표본평균이 기댓값에 수렴

중심극한정리

분포 모양이 정규분포가 된다

데이터가 많아지면 표본평균의 분포가 종 모양(bell curve)

대편차 원리

평균에서 크게 벗어날 확률이 빠르게 줄어듦

극단값의 확률이 지수적으로 감소

2. 확률 (Probability)

시행근원사건표본공간 조건부 확률베이즈 정리독립/종속

2-1. 수학적 확률 & 사건

용어설명예시
시행(trial)무작위로 하나를 추출하는 행위주사위 던지기
근원사건각 시행의 결과1, 2, 3, 4, 5, 6
표본공간(S)모든 근원사건의 집합S = {1,2,3,4,5,6}
사건(event)표본공간의 부분집합짝수 = {2,4,6}

2-2. 사건의 종류

전사건 & 공사건

  • 전사건: 확실히 일어남. P(S) = 1
  • 공사건: 불가능. P(∅) = 0

여사건 & 배반사건

  • 여사건(Ec): E에 속하지 않는 결과
  • 배반사건: A ∩ B = ∅
  • 여사건 ⇒ 배반 (역은 성립 안 함!)

곱사건 & 합사건

  • 곱사건: A ∩ B (교집합)
  • 합사건: A ∪ B (합집합)

2-3. 확률 계산 예시

A = {1,2,3}, B = {1,3,4,5}, S = {1,2,3,4,5,6}

교집합 & 합집합
P(A ∩ B) = |{1,3}| / 6 = 1/3     P(A ∪ B) = |{1,2,3,4,5}| / 6 = 5/6

2-4. 통계적 확률

주사위를 1000번 던지면 각 숫자 확률이 1/6 ≈ 0.167에 근접

calc_steps = 1000 dice_data = np.array([1, 2, 3, 4, 5, 6]) dice_rolls = np.random.choice(dice_data, calc_steps) for i in range(1, 7): p = len(dice_rolls[dice_rolls==i]) / calc_steps print(i, '가 나올 확률', p)

2-5. 조건부 확률과 곱셈 공식

조건부 확률
P(B|A) = P(A ∩ B) / P(A)
A가 일어난 상태에서 B가 일어날 확률
곱셈 공식
P(A ∩ B) = P(B|A) · P(A)
동시에 일어날 확률 = 순서대로 곱하기

예: A={2,4,6}(짝수), B={4,5,6}(4이상) → A∩B={4,6} → P(B|A) = (2/6)/(3/6) = 2/3

2-6. 독립과 종속

독립 (Independent)

  • P(A|B) = P(A) → B가 A에 영향 없음
  • P(A ∩ B) = P(A) · P(B)

종속 (Dependent)

  • P(A ∩ B) ≠ P(A) · P(B)
  • 예: A={2,4,6}, B={4,5,6}
  • 1/3 ≠ 1/4 → 종속!

2-7. 베이즈 정리 (Bayes' Theorem)

결과를 보고 원인을 거꾸로 추론

베이즈 정리
P(B|A) = P(A|B) · P(B) / [P(A|B) · P(B) + P(A|Bc) · P(Bc)]
구성요소기호의미
사전확률P(B)사건 A 전 B가 발생할 확률 (과거 경험)
가능도P(A|B)B가 주어졌을 때 A 발생 확률
증거P(A)사건 A가 일어날 전체 확률
사후확률P(B|A)A가 일어난 후 B가 발생할 확률 (추론)
복수 원인 (일반형)
P(Bi|A) = P(A|Bi) · P(Bi) / Σj P(A|Bj) · P(Bj)

3. 확률변수와 확률분포

PMFCDFPDF 기댓값균등분포베르누이 이항분포푸아송정규분포

3-1. 확률변수의 분류

이산확률변수

실현값을 셀 수 있는 경우
예: 주사위 1~6
확률질량함수(PMF): Σp(xi) = 1

연속확률변수

셀 수 없는 연속적 값
예: 키, 무게, 시간
확률밀도함수(PDF)로 표현

3-2. 분포함수 (CDF) & 확률밀도함수 (PDF)

누적분포함수 (CDF)
F(x) = P(X ≤ x) = Σ p(xi)   (xi ≤ x)
지금까지 누적된 확률
확률밀도함수 (PDF)
f(x) = dF(x)/dx
확률이 얼마나 빠르게 쌓이는지 (밀도)

3-3. 기댓값 (Expected Value)

기댓값 공식
E(X) = Σ x · f(x)
확률을 고려한 평균 = "중심 위치" 또는 "균형점"

주사위: E(X) = 1×(1/6) + 2×(1/6) + … + 6×(1/6) = 3.5

3-4. 주요 확률분포

균등분포 (Uniform Distribution)

모든 사건이 발생할 확률이 동일. 예: 주사위 각 면 1/6

calc_steps = 1000 dice_data = np.array([1, 2, 3, 4, 5, 6]) dice_rolls = np.random.choice(dice_data, calc_steps) prob_data = np.array([]) for i in range(1, 7): p = len(dice_rolls[dice_rolls==i]) / calc_steps prob_data = np.append(prob_data, p) plt.bar(dice_data, prob_data)

베르누이 분포 (Bernoulli Distribution)

결과가 성공(1) 또는 실패(0) 두 가지뿐인 시행

coin_data = np.array([0, 0, 0, 0, 0, 1, 1, 1]) for i in np.unique(coin_data): p = len(coin_data[coin_data==i]) / len(coin_data) print(i, '가 나올 확률', p) # 0이 나올 확률 0.625, 1이 나올 확률 0.375

이항분포 (Binomial Distribution)

독립적인 베르누이 시행을 n회 반복했을 때의 성공 횟수 분포

x = np.random.binomial(30, 0.5, 1000) # n=30회, 성공확률 p=0.5, 1000개 샘플

푸아송 분포 (Poisson Distribution)

발생 가능성이 작은 사건의 확률분포. 일정 시간/면적에서 사건 발생 횟수.

x = np.random.poisson(lam=5, size=1000) # lambda=5, 1000개 샘플

정규분포 (Normal / Gaussian Distribution)

대표적인 연속확률분포. 종 모양(bell curve). 가우스 분포라고도 함.

x = np.random.normal(5, 10, 10000) # 평균=5, 표준편차=10, 10000개 샘플

로그 정규분포 (Log Normal Distribution)

log(x)가 정규분포를 따르는 분포. 양수값만 취하고 오른쪽 꼬리가 김.

x = np.random.lognormal(mean=0, sigma=1, size=10000)

4. 심화학습 — 다차원확률분포

결합확률분포주변확률분포 조건부확률분포공분산행렬
결합확률질량함수 (Joint PMF)
P(X=xi, Y=yj) = pX,Y(xi, yj)
주변확률질량함수 (Marginal PMF)
pX(xi) = Σj pX,Y(xi, yj)
조건부확률질량함수 (Conditional PMF)
pY|X(yj|xi) = pX,Y(xi, yj) / pX(xi)
조건부 기댓값
E[Y|X=xi] = Σj yj · pY|X(yj|xi)
독립 조건
pX,Y(xi, yj) = pX(xi) · pY(yj)

2차원 정규분포 시각화

from scipy.stats import multivariate_normal from mpl_toolkits.mplot3d import Axes3D x, y = np.mgrid[10:100:2, 10:100:2] pos = np.dstack((x, y)) rv = multivariate_normal([50, 50], [[100, 0], [0, 100]]) z = rv.pdf(pos) fig = plt.figure() ax = fig.add_subplot(111, projection='3d') ax.plot_surface(x, y, z, cmap='viridis')

5. 추론통계학 (Inferential Statistics)

표본모집단모수 대수의 법칙중심극한정리 t분포카이제곱F분포

추론통계학: 표본(sample)을 이용해 모집단(population)에 대해 통계적으로 분석하고 추측하는 학문. 실제 수집된 데이터는 n개의 확률변수의 실현값이며, n은 표본의 크기.

5-1. 대수의 법칙 (Law of Large Numbers)

시행 횟수 N을 크게 만들면 평균이 기댓값(3.5)에 근접

calc_times = 1000 sample_array = np.array([1, 2, 3, 4, 5, 6]) number_cnt = np.arange(1, calc_times + 1) for i in range(4): p = np.random.choice(sample_array, calc_times).cumsum() plt.plot(p / number_cnt)

N = 3

균등분포에 가까움

N = 6

정규분포 형태가 보이기 시작

N = 1000

완전한 정규분포!

5-3. 주요 분포 — 카이제곱, t, F

카이제곱분포 (χ²)

m개의 표준정규분포 확률변수의 제곱합

W = Σ Zi² (자유도 m)

np.random.chisquare(df, size)

스튜던트 t분포

Z(표준정규)와 W(카이제곱)가 독립일 때

T = Z / √(W/m)

np.random.standard_t(df, size)

F 분포

두 카이제곱분포의 비율

F = (W1/m1) / (W2/m2)

np.random.f(dfnum, dfden, size)

6. 통계적 추정 (Statistical Estimation)

점추정구간추정 불편성일치성 MLE베이즈

6-1. 추정량과 점추정

표본평균
X̄ = (1/n) Σ Xi
추정량 = 확률변수의 함수 T(X1,...,Xn)

6-2. 불편성 & 일치성

불편성 (Unbiasedness)

E[T(X1,...,Xn)] = θ
편향(bias)이 없음. 기대값이 참값과 동일.

일치성 (Consistency)

n이 커짐에 따라 θ에 수렴
표본을 많이 모을수록 정확해짐.

6-3. 구간추정 (Interval Estimation)

신뢰구간 (Confidence Interval)
[X̄ - zα/2/√n,   X̄ + zα/2/√n]
신뢰수준: 1-α (보통 95% 또는 99%)

6-4. 최대가능도법 (MLE)

가능도함수
L(θ; X) = Π f(xi; θ)
로그가능도함수
log L(θ; x) = Σ log f(xi; θ)
MLE 해
d/dθ log L(θ, x) = 0   →   θ̂

6-5. 베이즈 추정

사후확률분포 (Posterior)
π(θ|x) = p(x|θ) · π(θ) / ∫ p(x|θ) · π(θ) dθ
사전확률(prior) × 가능도(likelihood) / 증거(evidence)

7. 통계적 검정 (Hypothesis Testing)

귀무가설대립가설 p값유의수준 제1종 오류제2종 오류검정력

7-1. 가설 검정 기본

귀무가설 H0

"차이가 없다" (현재 상태 유지)
예: μmath = μpor

대립가설 H1

"차이가 있다" (변화 주장)
예: μmath ≠ μpor

p값: 귀무가설이 옳다고 가정할 때 통계량이 산출될 확률. p값이 작을수록 귀무가설 기각. 유의수준 α: 보통 5% 또는 1%.

from scipy import stats t, p = stats.ttest_rel(student_data_merge.G1_math, student_data_merge.G1_por) print('p값 = ', p) # 결과: 1.65e-16 → 귀무가설 기각!

7-2. 제1종 오류 & 제2종 오류

H0 참 (차이 없음)H0 거짓 (차이 있음)
H0 기각 제1종 오류 (α)
무죄인 사람에게 유죄		 올바른 결정
검정력 = 1 - β
H0 채택 올바른 결정 제2종 오류 (β)
유죄인 범죄자에게 무죄

핵심 포인트

  • α와 β는 트레이드오프 관계
  • 검정력(power) = 1 - β ≥ 0.8 이상 필요

빅데이터 주의

  • 표본이 크면 미묘한 차이도 유의하게 나옴
  • p값이 매우 작아짐 → 신뢰구간 활용 권장
📈 확률 → 통계 학습 흐름 타임라인

Step 1: 확률 기초

표본공간, 사건, 확률의 공리, 확률공간 (Ω, F, Pr)

Step 2: 조건부 확률 & 베이즈

조건부 확률, 독립/종속, 베이즈 정리 (원인 추론)

Step 3: 확률변수 & 분포

🔥 핵심 캐치 — 시험 빈출 포인트

확률의 공리 3가지

비음수성 Pr(A)≥0, 정규성 Pr(Ω)=1, 가법성(서로소 → 합 = 각 확률의 합). 이 세 가지만 기억!

여사건 ≠ 배반사건

여사건은 반드시 배반이지만, 배반이라고 반드시 여사건인 것은 아님! 자주 출제.

독립 판별법

P(A∩B) = P(A)·P(B)이면 독립. 아니면 종속. 계산으로 확인!

베이즈 정리 = 역추론

"결과를 보고 원인을 거꾸로 추론." 사전확률 × 가능도 / 증거 = 사후확률

기댓값 ≠ 실제 결과

주사위 기댓값 3.5는 실제로 나올 수 없는 값. "평균"이라는 의미!

분포 흐름 암기

균등 → 베르누이 → 이항 → 푸아송 → 정규. 간단 → 복잡 순서.

중심극한정리 핵심

모집단이 어떤 분포든 표본 크기가 커지면 표본평균은 정규분포!

제1종 vs 제2종 오류

제1종(α): 무죄→유죄 (귀무가설 맞는데 기각). 제2종(β): 유죄→무죄. 트레이드오프!

검정력 ≥ 0.8

검정력 = 1-β. 대립가설이 참일 때 올바르게 기각할 확률. 0.8 이상 필요.

MLE 풀이 순서

가능도함수 L → 로그 취하기 → 미분 = 0 → θ̂ 구하기. 시험 계산문제 필수!

불편추정량 증명

E[X̄] = E[(1/n)ΣXi] = (1/n)·nμ = μ. 표본평균은 불편추정량!

빅데이터에서 p값 주의

표본이 크면 미묘한 차이도 유의. p값만 보지 말고 신뢰구간도 확인!
