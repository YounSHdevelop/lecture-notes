데이터의 종류

📊 정형 데이터 (Structured)

행과 열로 구성된 테이블 형태. DB/엑셀 파일. SQL로 쉽게 분석 가능.

🤖 기계 생성 데이터 (Machine-generated)

IoT 센서, 서버 로그, 스마트 기기에서 자동 생성. 실시간 스트리밍 처리 중요.

🕸️ 그래프/네트워크 데이터 (Graph)

소셜 네트워크, 웹 페이지 링크 구조. 노드와 엣지로 관계 표현.

📝 비정형 데이터 (Unstructured)

텍스트, 이미지, 영상, 오디오 등. 딥러닝·NLP 기술로 분석.

데이터 과학 프레임워크 (4단계)

1

현실 세계 (Raw Data 수집)

로그 파일, 이메일, 유전자 데이터 등 다양한 원시 데이터. 사람들의 활동 자체가 원천.

2

데이터 전처리 (Preprocessing)

Python/R/SQL로 데이터 수집→처리→정제 파이프라인 구축. 결측값·이상값 처리 포함.

3

탐색적 데이터 분석 (EDA)

변수 분포 시각화, 시계열 분석, 산점도 행렬, 요약 통계. 이상값 발견 시 재정제.

4

머신러닝 모델 & 의사결정 서비스

kNN, 선형회귀, 나이브베이즈 등으로 분류·예측. 스팸 분류기, 추천 시스템 등 상품화. 피드백 루프로 추가 데이터 생성.

Chapter 3 — 파이썬 기초

🔢 자료구조 비교

자료형기호순서중복변경
리스트[ ]있음허용가능
튜플( )있음허용불가
딕셔너리{k:v}키 기반키 중복 불가가능
집합{ }없음불가가능

🔄 제어 흐름

  • 순차(Sequential): 위→아래 순서대로 실행
  • 조건 분기(if): 조건에 따라 다른 블록 실행
  • for문: iterable 원소를 하나씩 꺼내 반복
  • while문: 조건이 True인 동안 반복
  • ⚠ 파이썬 들여쓰기: 반드시 스페이스 4칸

⚙️ 함수 관련 핵심 개념

  • def: 함수를 정의하는 키워드
  • 파라미터(parameter): 함수 정의 시 입력값 이름
  • 인수(argument): 호출 시 전달하는 실제 값
  • return: 결과값 반환 키워드
  • lambda: 이름 없이 즉시 생성하는 익명 함수
  • map(함수, iterable): 모든 원소에 함수 적용

🏗️ 객체 지향 프로그래밍 (OOP)

  • 클래스(Class): 객체의 설계도 (붕어빵 틀)
  • 인스턴스(Instance): 클래스로 만든 실체 (실제 붕어빵)
  • __init__: 생성자, 인스턴스 생성 시 자동 호출
  • self: 생성된 인스턴스 자기 자신을 가리킴
  • OOP 장점: 캡슐화, 재사용성, 유지보수성, 상속

리스트 컴프리헨션 (List Comprehension)

# 일반 for 문 result = [] for i in range(5): result.append(i * 2) # 컴프리헨션으로 간결하게 result = [i * 2 for i in range(5)] # [0, 2, 4, 6, 8] # 조건 포함 evens = [i for i in range(10) if i % 2 == 0] # [0, 2, 4, 6, 8] # 딕셔너리 .items() 순회 for k, v in dic_data.items(): print(f'{k}: {v}')

파이썬 창시자 & 연도

1990년 귀도 반 로섬(Guido van Rossum)이 개발. 이름의 유래는 Monty Python's Flying Circus (뱀이 아님!).

통계학 vs 데이터 과학의 핵심 차이

데이터 과학은 피드백 루프를 통해 더 많은 데이터를 생성하는 것이 통계학과의 핵심 차이점. 서비스 → 데이터 → 분석 → 서비스의 순환.

리스트 × 2 의 의미

data_list * 2는 원소 값을 두 배로 만드는 것이 아니라, 리스트 전체를 한 번 더 복제함. 예: [1,2,3] * 2 → [1,2,3,1,2,3]

생성자 __init__와 self

__init__은 인스턴스 생성 시 자동 호출되는 매직 메소드(생성자). self는 생성된 인스턴스 자기 자신을 가리키는 첫 번째 파라미터.

for vs while 사용 기준

for: 반복 횟수가 정해져 있을 때 (리스트, range 등). while: 조건에 따라 반복 횟수가 동적으로 변할 때. while은 반드시 탈출 조건 필요 (무한루프 방지).

딕셔너리 순회 메소드

.keys() 키만 / .values() 값만 / .items() 키+값 동시 순회 ⭐. 실무에서 가장 자주 사용하는 패턴: for k, v in dict.items():

Data Science

통계학·컴퓨터 공학·도메인 지식이 결합된 융합 학문. 방대한 데이터에서 유의미한 패턴과 통찰을 발견하는 과정 전체.

데이터 과학자
지저분한(raw) 데이터에서 통찰력(인사이트)을 발견하는 사람. 통계, 프로그래밍, 비즈니스 감각을 모두 갖춘 융합형 전문가.
EDA (Exploratory Data Analysis)
탐색적 데이터 분석
모델링 전, 데이터의 분포·패턴·이상값을 시각화와 통계로 파악하는 분석 과정.
Anaconda
아나콘다
파이썬 기반 데이터 과학 플랫폼. Python + 300개 이상 라이브러리를 한 번에 설치하며, 가상 환경 관리 기능 제공.
JupyterLab
주피터 랩
Jupyter Notebook의 차세대 통합 개발 환경. 멀티탭, 분할 뷰, 파일 관리 등 향상된 UI 제공. 셀 단위로 코드 실행.
Variable
변수
데이터를 저장하는 메모리 공간. 파이썬은 타입 선언 없이 값 대입만으로 즉시 사용 가능 (동적 타이핑).
List / Dictionary / Tuple / Set
리스트 / 딕셔너리 / 튜플 / 집합
파이썬의 4대 컬렉션 타입. 각각 [], {k:v}, (), {} 기호 사용. 순서·중복·변경 가능 여부가 다름.
List Comprehension
리스트 컴프리헨션
for문을 이용해 리스트를 간결하게 생성하는 파이썬 문법. [표현식 for 변수 in iterable (if 조건)] 구조.
Lambda Function
익명 함수 (람다)
이름 없이 즉시 생성하는 함수. lambda 파라미터: 반환식 형태. map, filter, sorted 등 고차 함수와 함께 사용.
OOP (Object-Oriented Programming)
객체 지향 프로그래밍
데이터(속성)와 처리 코드(메소드)를 하나의 객체로 묶는 프로그래밍 패러다임. 캡슐화·재사용성·상속 등이 핵심.
Class / Instance
클래스 / 인스턴스
클래스는 객체의 설계도(붕어빵 틀). 인스턴스는 클래스로부터 만들어진 실체(실제 붕어빵). 하나의 클래스에서 여러 인스턴스 생성 가능.
Constructor (__init__)
생성자
인스턴스가 생성될 때 자동으로 실행되는 특별한 매직 메소드. self는 생성된 인스턴스 자기 자신을 가리킴.
