🤖 머신러닝 개요

AI ⊃ 머신러닝(ML) ⊃ 딥러닝(DL)

Tom Mitchell 정의 (1997)

경험(E)을 통해 특정 과제(T)에서의 성능(P)이 향상되는 컴퓨터 프로그램

학습 유형 3가지

유형특징대표 알고리즘

분류 vs 회귀

  • 분류: 출력이 이산(discrete) — 스팸/정상
  • 회귀: 출력이 연속(continuous) — 주가·아파트 값

⚡ Ridge vs Lasso 정규화

비용함수: Σ(yi - f(xi))² + λΣ|wj|^q
q=2 → Ridge(L2)    q=1 → Lasso(L1)
Ridge (L2)
  • 모든 변수 활용
  • 계수를 0이 아닌 작은 값으로
  • 상관관계 높을 때 안정적
Lasso (L1)
  • 변수 선택 기능
  • 일부 계수를 정확히 0으로
  • 불필요한 변수 많을 때 유리
from sklearn.linear_model import Ridge, Lasso
ridge = Ridge(alpha=1.0)
lasso = Lasso(alpha=200.0)

🔗 변수선택 3가지 방법

  • 변수증가법 (Forward Selection): 변수를 하나씩 추가하며 유의한 것만 포함
  • 변수감소법 (Backward Elimination): 전체 변수에서 무의미한 것을 하나씩 제거
  • 스텝와이즈 (Stepwise): 추가와 제거를 반복 → 실무에서 가장 선호

오즈비 (Odds Ratio)

odds ratio = e^β
  • 오즈비 >1: 해당 변수가 양성 확률 증가
  • 오즈비 <1: 해당 변수가 음성 확률 증가
  • np.exp(model.coef_)

⚙️ K-Means 알고리즘 & 코드

  1. K값(군집 수) 입력
  2. 무작위로 K개 초기 중심 선택
  3. 각 데이터를 가장 가까운 군집에 배정
  4. 군집 평균으로 새 중심 계산 → μ_k = (1/N_k) × Σx_i
  5. 중심이 변하지 않을 때까지 3-4 반복
새 중심: μ_k = (1/N_k) × Σx_i

📏 최적 K 결정 방법

① 엘보우법 (Elbow Method)

  • kmeans.inertia_: 군집 내 거리의 제곱합
  • K 증가 시 inertia 감소 → 급격히 줄어드는 지점 선택

② 실루엣 계수 (Silhouette Score)

s = (b - a) / max(a, b)
  • a: 자기 군집 내 평균 거리 (응집도)
  • b: 가장 가까운 다른 군집과의 평균 거리 (분리도)
값 범위해석

-0.25 ~ 0경계/애매

🛒 장바구니 분석 3대 지표

지지도(Support) = P(A∩B) = (A∩B 거래수) / 전체 거래수
신뢰도(Confidence) = P(B|A) = (A∩B 거래수) / A 거래수
향상도(Lift) = 신뢰도 / P(B) = Confidence / Support(B)

기저귀 & 맥주 예시 (전체 100건)

지표계산결과
지지도20 / 1000.20
신뢰도20 / 400.50
향상도0.50 / 0.301.67

Lift >1: 양의 연관 | Lift = 1: 독립 | Lift <1: 음의 연관

trans_ab = trans_a & trans_b          # 교집합
support    = len(trans_ab) / len(trans_all)
confidence = len(trans_ab) / len(trans_a)
lift       = confidence / (len(trans_b) / len(trans_all))
10장 모델 검증·튜닝

⚖️ 과적합 vs 과소적합

과적합 (Overfitting)
  • 훈련↑ 테스트↓
  • 노이즈까지 학습
  • 해결: 정규화·특징 감소(PCA)·데이터 증가
과소적합 (Underfitting)
  • 훈련↓ 테스트↓
  • 모델이 너무 단순
  • 해결: 특징 추가·모델 복잡도 증가

검증 방법 비교

  • 홀드아웃: train 70~80% / test 20~30%
  • k-겹 교차검증: 데이터를 k 블록으로 나눠 k번 검증 → 평균 성능
  • LOOCV: k=n (Leave-One-Out), 가장 엄격
from sklearn.model_selection import cross_val_score
scores = cross_val_score(tree,
  cancer.data, cancer.target, cv=5)
# [0.904, 0.912, 0.956, 0.939, 0.956]
# 평균: 0.933 ± 0.022

🎯 오차행렬 & 분류 지표

예측 양성예측 음성
실제 양성TPFN (2종 오류)
실제 음성FP (1종 오류)TN
정확도 = (TP+TN) / (TP+TN+FP+FN)
정밀도(Precision) = TP / (TP+FP)
재현율(Recall) = TP / (TP+FN)
F1 = 2 × (Precision × Recall) / (Precision + Recall)

F1 Score 해석

범위의미
0.90 이상매우 우수
0.80 ~ 0.90우수
0.70 ~ 0.80양호
0.50 이하성능 부족

📉 ROC 곡선 & AUC

  • ROC 곡선: 진양성률(TPR) vs 위양성률(FPR)
  • TPR = Recall = TP / (TP+FN) (y축)
  • FPR = FP / (FP+TN) (x축)
  • AUC: ROC 곡선 아래 면적 (1에 가까울수록 좋음)
AUC해석
1.0완벽
0.9매우 좋음
0.8좋음
0.7보통
0.5랜덤 (무의미)
from sklearn.metrics import roc_curve, auc
fpr, tpr, _ = roc_curve(y_test, y_pred)
auc_score = auc(fpr, tpr)   # 예: 0.992

📊 회귀 모델 성능 지표

MSE = (1/n) × Σ(yi - ŷi)²
MAE = (1/n) × Σ|yi - ŷi|
RMSE = √MSE
R² = 1 - SSE/SST = 1 - Σ(yi-ŷi)² / Σ(yi-ȳ)²
MAPE = (100/n) × Σ|yi-ŷi| / yi (%)

선택 가이드

  • RMSE: 가장 널리 사용, 큰 오차에 민감
  • MAE: 이상치에 덜 민감
  • MAPE: % 단위, 비즈니스 해석 용이
  • R²: 설명력 (1에 가까울수록 좋음)

⭐ 자주 출제

Ridge vs Lasso 핵심 차이

Ridge(L2): 계수를 작게 만들지만 0이 되진 않음 → 변수 선택 불가
Lasso(L1): 계수를 정확히 0으로 만들 수 있음 → 변수 선택 가능

✅ 공식 암기

향상도 = 신뢰도 / 지지도(B)

기저귀&맥주: 신뢰도=0.50, 맥주 지지도=0.30 → Lift=1.67
Lift>1: 양의 연관, =1: 독립, <1: 음의 연관

📖 핵심 키워드

Supervised Learning
지도학습
레이블(정답)이 있는 훈련 데이터로 모델을 학습. 분류·회귀 문제에 사용. 대표: SVM, 로지스틱회귀, 의사결정나무.
Unsupervised Learning
비지도학습
레이블 없이 데이터의 패턴을 스스로 탐색. 군집화·차원 축소·연관 규칙. 대표: K-Means, PCA.
Overfitting
과적합
훈련 데이터에 너무 최적화되어 새로운 데이터에서 성능이 떨어지는 현상. 해결: 정규화, 차원 축소, 데이터 증가.
Cross Validation
교차검증
데이터를 k개 블록으로 나눠 번갈아 학습/검증 반복. 모델 신뢰성·안정성 판단이 목적. cross_val_score(model, X, y, cv=5)
Regularization
정규화
과적합 방지를 위해 손실함수에 패널티 항 추가. Ridge(L2): 계수 축소, Lasso(L1): 변수 선택.
Confusion Matrix
오차행렬
분류 모델의 예측 결과를 TP/TN/FP/FN 4가지로 구분한 표. 모든 분류 지표의 기반.
ROC-AUC
수신자 조작 특성 곡선 & 면적
TPR vs FPR 곡선 아래 면적. 불균형 데이터에 적합. 1=완벽, 0.5=랜덤. 분류 모델 핵심 지표.
F1 Score
F1 점수
Precision과 Recall의 조화평균. 두 지표의 균형을 고려. 불균형 데이터에서 정확도 대신 사용.
K-Means Clustering
K-평균 군집분석
K개 중심점 기준으로 데이터를 반복 군집화. 비지도학습의 대표 알고리즘. 거리 기반이므로 표준화 필수!
Principal Component Analysis
주성분 분석 (PCA)
고차원 데이터를 정보 손실 최소화하며 저차원으로 변환. explained_variance_ratio_로 설명력 확인.
Association Rule
연관 규칙
함께 발생하는 항목 간의 규칙 발견. 지지도·신뢰도·향상도로 강도 측정. 장바구니 분석의 핵심.
GridSearchCV
그리드 서치 교차검증
지정한 하이퍼파라미터의 모든 조합을 교차검증으로 탐색. best_score_, best_params_ 반환.
StandardScaler
표준화
모든 변수를 평균=0, 표준편차=1로 변환. K-Means, k-NN, SVM, 로지스틱회귀에서 필수 전처리.
One-Hot Encoding
원-핫 인코딩
범주형 변수를 0/1 이진 변수로 변환. pd.get_dummies() 사용. 의사결정나무 실습에서 사용됨.
Elbow Method
엘보우법
K-Means에서 최적 K 결정법. 군집 내 거리 제곱합(inertia_)이 급격히 감소하다 완만해지는 꺾이는 점 선택.
Silhouette Score
실루엣 계수
군집화 품질 지표. s=(b-a)/max(a,b). a=군집 내 응집도, b=분리도. -1~1 범위, 1에 가까울수록 우수.
Odds Ratio
오즈비
로지스틱회귀에서 각 변수의 영향 배율. odds ratio = e^β. 1보다 크면 양성 확률 증가, 작으면 감소.
RMSE
평균제곱근오차
Root Mean Squared Error. 회귀 모델의 핵심 평가 지표. 실제값과 예측값 차이의 제곱 평균에 루트를 씌운 값.
