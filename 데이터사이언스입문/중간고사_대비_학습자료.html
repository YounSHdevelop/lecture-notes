Data (데이터)

정리되어 있거나(organized) 정리되어 있지 않은(unorganized) 형태의 정보의 집합.

🐍 2장 — 파이썬 라이브러리 · NumPy 기초 📘 Day 1Ch.2
⚡ 초단기 암기 모드
  • 라이브러리 = 외부에서 읽어 사용하는 프로그램. 모듈 = 함수·변수·클래스를 모아놓은 파이썬 파일
  • 4대 데이터 과학 라이브러리:
    • NumPy (numpy.org) — 수치 배열·벡터화, C로 작성돼 빠름
    • SciPy — NumPy 기반 과학계산 (optimization, integration, differential equations, statistics)
    • Pandas — 2차원 테이블(Series/DataFrame), 데이터 분석
    • Matplotlib — 데이터 시각화 (Seaborn도 자주 사용)
  • import 2가지:
    • import numpy as np — 모듈 전체를 별칭으로
    • from numpy import random — 특정 기능만 가져와 바로 사용
  • 매직 명령어 (% 시작, Jupyter 전용):
    • %run · %cp · %time · %quickref (내장형)
    • %precision 3 — 소수점 자릿수
    • %matplotlib inline — 노트북에 그래프 출력
  • NumPy 배열 속성 3개: .dtype · .ndim · .size · .shape
  • 데이터 타입: int8/16/32/64 · uint8/16/32/64 · float16/32/64/128 · bool(True/False)
  • 배열 연산: arr*2는 모든 원소 2배 (리스트의 *2와 다름!) · 배열끼리 연산은 원소별
  • 정렬: arr.sort()는 기본 오름차순. 내림차순은 arr[::-1].sort()
  • 통계: .min() .max() .sum() .cumsum() → 누적합 / 누적비율은 cumsum/sum
  • 난수(random): seed가 같으면 항상 같은 난수 (의사 난수 pseudo-random)
  • 난수 함수 표 (★ 빈출): rand·random_sample(0~1 균등) · randint(정수 균등) · randn·normal(정규) · binomial·beta·gamma·chisquare(각 분포)
  • 복원/비복원: random.choice(data, n, replace=True) = 복원(중복 허용) · replace=False = 비복원(중복 불가)
  • ★ 행렬곱 vs 원소곱: A * B = 원소별(Hadamard) / np.dot(A,B) = A @ B = 행렬곱
  • 0·1 행렬: np.zeros((2,3)) / np.ones((3,3)) / np.arange(9).reshape(3,3)
  • 속도: NumPy가 일반 Python 합산보다 약 5~7배 빠름 (%timeit로 측정)
📚 데이터 분석을 위한 4대 라이브러리

라이브러리(library) = 프로그램으로 읽어 들여 사용할 수 있도록 개발된 외부 프로그램. 직접 코드를 작성하지 않고도 복잡한 작업 수행 가능.

NumPy (넘파이)

배열 처리(vector·matrix)와 수치 계산/해석. C 언어로 작성돼 빠름. SciPy 등의 기반.

numpy.org

SciPy (사이파이)

NumPy를 강화한 라이브러리. 과학기술 계산 (optimization, integration, differential equations, statistics).

scipy.org

Pandas (판다스)

2차원 테이블 데이터(Series/DataFrame) 조작·가공·분석. 데이터 분석에 많이 사용.

pandas.pydata.org

Matplotlib (매트플롯립)

데이터 시각화(그래프 제작) 기본 라이브러리. Seaborn도 자주 사용.

matplotlib.org · seaborn.pydata.org

📐 3장 — 기술통계와 단순회귀분석 📗 Day 2Ch.3
⚡ 초단기 암기 모드
  • 통계분석 = 기술통계 + 추론통계. 회귀분석은 두 방법의 한 종류
  • 기술통계(Descriptive) = 지금 있는 데이터를 요약·정리 (요약 도구)
  • 추론통계(Inferential) = 표본으로 모집단 추정·검정 (판단 도구)
  • 기술통계 분류: 중심경향성(최빈값·중앙값·평균값[산술/가중/기하]) / 퍼짐정도(분산·표준편차·범위·IQR) / 왜도 / 첨도
  • 추론통계 분류: 통계적 추론(확률모형) / 가설 검정
  • 왜도: 한쪽으로 치우쳤는가 (평균<중앙값: 왼쪽/음의 왜도, 평균>중앙값: 오른쪽/양의 왜도)
  • 첨도: 가운데가 뾰족한가 (급첨/정규(중첨)/완첨)
  • 평균 x̄ = (1/n)Σxᵢ · 중앙값 = 정렬 후 가운데 값 (이상치 영향 ↓) · 최빈값 = 가장 많이 나타난 값
  • 분산 σ² = (1/n)Σ(xᵢ-x̄)² · 표준편차 σ = √분산 (단위가 원본과 같음)
  • describe() 결과 8개: count · mean · std · min · 25%(Q1) · 50%(중앙값) · 75%(Q3) · max — 최빈값은 포함 X
  • IQR = Q3 - Q1. 박스플롯 최댓값 경계 = Q3 + (Q3 - Q1) × 1.5, 벗어나면 이상값(outlier)
  • 변동계수 CV = σ / x̄ (표준편차 ÷ 평균) — 단위·크기 다른 데이터 공정 비교 가능
  • CV 해석표: <0.1 매우 안정 / 0.1~0.3 보통 / >0.5 변동 큼 / >1 매우 큼
  • 공분산 Sxy = (1/n)Σ(xᵢ-x̄)(yᵢ-ȳ) — 양수: 같이 증가, 음수: 반대. 단위·스케일에 영향
  • 피어슨 상관계수 rxy = Sxy / (σx · σy), -1 ≤ r ≤ 1. 공분산을 표준편차로 나눠 스케일 제거
  • r=0: 선형 관계 없음. 비선형 관계는 있을 수 있음 (W자·원형 분포 예시)
  • 단순회귀 (입력 1개) vs 다중회귀 (입력 여러 개). 지도학습의 한 종류
  • 선형 회귀식 ŷ = ax + b (a = 회귀계수/기울기, b = 절편/bias)
  • 최소제곱법: Σ(yᵢ - f(xᵢ))² 최소화해 a·b 찾음 (편미분으로 계산)
  • 결정계수 R² = 1 - Σ(yᵢ-f(xᵢ))² / Σ(yᵢ-ȳ)², 0 ≤ R² ≤ 1, 1에 가까울수록 좋은 모델
  • sklearn 코드: linear_model.LinearRegression() → reg.fit(X,Y) → reg.coef_(a) · reg.intercept_(b) · reg.score(X,Y)(R²) · reg.predict(X)
📊 기술통계 vs 추론통계 — 큰 그림

기술통계 (Descriptive)

수집한 데이터의 주요 특성을 분석·기술. "설명"

  • 예) 평균·중위수·최빈수·최댓값·최솟값·범위·분산·표준편차
  • 요약 도구 — 데이터를 먼저 정리해서 이해

추론통계 (Inferential)

데이터에서 표본(sample)을 추출해 모집단(population)의 특성 추정·검정. "판단·예측"

  • 예) 선거철 후보자 지지도 조사
  • 판단 도구 — 일부를 보고 전체를 짐작

회귀분석 (Regression)

기술통계·추론통계의 한 방법. 흩어진 점들 사이에 규칙을 선으로 잡아내는 것. 종속변수 = f(독립변수) 관계를 수학적으로 추정·예측.

🔁 흐름: ① 데이터 정리 이해 → ② 그래프로 관계 본다 → ③ 숫자로 관계 확인 → ④ 직선으로 예측 → ⑤ 예측이 얼마나 좋은지 평가
🌳 기술통계·추론통계 분류도 (통계학 구조)

기술통계 (Descriptive)

  • 중심경향성: 최빈값 · 중앙값 · 평균값(산술평균 / 가중평균 / 기하평균)
  • 퍼짐정도: 분산 · 표준편차 · 범위 · IQR(사분위범위)
  • 왜도(Skewness)
  • 첨도(Kurtosis)

추론통계 (Inferential)

  • 통계적 추론 — 데이터에서 확률모형 추론
  • 가설 검정 — 가설을 세우고 데이터로 검증
왜도(Skewness) & 첨도(Kurtosis)

왜도 — '한쪽으로 치우쳤는가'

데이터 분포의 좌우 비대칭도.

  • 평균 < 중앙값 → 왼쪽 치우침(음의 왜도) = 오른꼬리 분포
  • 평균 > 중앙값 → 오른쪽 치우침(양의 왜도) = 왼꼬리 분포

첨도 — '가운데가 뾰족하게 몰렸는가'

데이터 분포가 정규분포보다 뾰족하거나 완만한 정도.

  • 양의 첨도(급첨) — 정규보다 뾰족
  • 정규분포(중첨)
  • 음의 첨도(완첨) — 정규보다 완만

평균값 (mean) x̄
x̄ = (1/n) Σᵢ xᵢ
결석 횟수의 합 ÷ 학생 수. 이상치에 민감.

분산과 표준편차
분산 (Variance) σ²
σ² = (1/n) Σᵢ (xᵢ − x̄)²
각 값이 평균에서 얼마나 떨어져 있는지의 평균 (제곱)
표준편차 (Standard Deviation) σ
σ = √σ² = √분산
분산의 제곱근. 단위가 원본과 같아 해석 쉬움 ("대략 ±σ 범위").

📉 단순회귀분석 (Simple Linear Regression)

회귀분석 = 수치 예측 (하나의 값으로 다른 값 예측). 머신러닝에서 가장 기초적인 방법. 지도학습(supervised learning)의 한 종류.

목표변수 (target / 종속변수)

예측하려는 값. '무엇을 맞힐지' (예: 시험점수, 매출, 기말고사 성적 G3) — 결과

설명변수 (explanatory / 독립변수)

목표변수를 설명·예측하는 값. '무엇으로 설명할지' (예: 공부시간, 중간고사 G1) — 원인

단순 vs 다중

  • 단순 회귀 — 설명변수 1개 (G1 → G3)
  • 다중 회귀 — 설명변수 여러 개

최소제곱법

오차를 가장 적게 만드는 직선을 찾는 방법 ('가장 잘 맞는 선 찾기')

결정계수 R²

모델이 데이터를 얼마나 잘 설명하는지의 비율 ('얼마나 잘 맞는지')

선형 회귀식
선형 회귀 모델
ŷ = f(x) = ax + b
a: 회귀계수(slope, weight) — X가 1 증가할 때 Y의 변화량
b: 절편(intercept, bias) — X=0일 때 Y의 값
최소제곱법 (Method of Least Squares, OLS)
최소화할 오차 제곱합
Σᵢ (yᵢ − f(xᵢ))²
실제값(y)과 예측값(ŷ)의 차이를 제곱해 모두 더한 값. 이 값을 최소화하는 a·b를 편미분(partial derivative)으로 구함.
sklearn으로 단순선형회귀 실행
from sklearn import linear_model

# 1) 선형회귀 인스턴스 생성
reg = linear_model.LinearRegression()

# 2) 설명변수(X), 목표변수(Y) 준비
X = student_data_math.loc[:, ['G1']].values   # loc으로 2D 추출
Y = student_data_math['G3'].values

# 3) fit으로 a, b 계산 (최소제곱법)
reg.fit(X, Y)

# 4) 결과 확인
print('회귀계수:', reg.coef_)         # [1.106]   → G1이 1 ↑ 시 G3 ≈ 1.1 ↑
print('절편:',   reg.intercept_)      # -1.6528   → G1=0일 때 G3 예측값

# 예측식: G3 ≈ 1.106 × G1 - 1.653

# 5) 산점도 + 회귀선
plt.scatter(X, Y)
plt.plot(X, reg.predict(X))   # predict로 예측선 그리기
plt.xlabel('G1 grade'); plt.ylabel('G3 grade'); plt.grid(True)
결정계수 R² (Coefficient of Determination)
R² 공식
R² = 1 − [Σ(yᵢ − f(xᵢ))²] / [Σ(yᵢ − ȳ)²]
분자: 모델 사용 시 오차 / 분모: 평균만으로 예측 시 오차 (전체 변동성)
0 ≤ R² ≤ 1. 1에 가까울수록 좋은 모델. 설명력(기여율)이라고도 함. 
# 결정계수
print('결정계수:', reg.score(X, Y))
# → 0.642 (데이터의 약 64% 설명 가능)
📌 R²=0이 되는 경우: 설명변수를 쓰지 않고 목표변수 평균(ȳ)만으로 예측한 오차와 모델 오차가 같을 때.
📌 교과서 데이터에선 0.9 이상 자주 나오지만 실무에선 그 정도 안 나오는 경우 많음. 0.64도 실무에선 사용 가능.

⚡ 초단기 암기 모드
  • 확률공간 = (Ω, ℱ, Pr) (표본공간 · 사건모음 · 확률함수)
  • 용어: 실험(trial) / 근원사건(주사위 1개 결과) / 사건(event = 표본공간의 부분집합)
  • 확률의 공리 (★ 시험 빈출):
    • ① Pr(∅) = 0 (불가능한 사건)
    • ② Pr(A) ≥ 0 (비음수성)
    • ③ 서로소 A, B: Pr(A∪B) = Pr(A) + Pr(B) (가법성)
    • ④ Pr(Ω) = 1 (전체 확률 = 1)
  • 확률은 0~1 사이. -1이나 1.5는 불가능
  • 확률변수(Random Variable) = 표본공간 Ω의 결과를 숫자로 매핑하는 함수. 실현값 = 실제 관측값
  • 이산 확률변수 → PMF (확률질량함수) p(x), Σp(xᵢ)=1
  • 연속 확률변수 → PDF (확률밀도함수) f(x)
  • CDF F(x) = P(X ≤ x) — PDF의 적분, PDF = CDF의 미분
  • 기댓값 E(X) = Σ x·P(X=x) (확률 고려한 평균 = "중심 위치 / 균형점"). 주사위 E(X) = 3.5 (실제 나올 수 없는 값)
  • 이산 분포 5종: 균등 · 베르누이 · 이항 · 기하 · 포아송
  • 연속 분포 8종: 정규(가우스) · 로그정규 · t · 카이제곱 · 감마 · 베타 · 지수 · 와이블
  • 조건부확률 P(B|A) = P(A∩B)/P(A) · 곱셈공식 P(A∩B) = P(B|A)·P(A)
  • 독립: P(A∩B) = P(A)·P(B)
  • 베이즈 정리 (★ 매우 빈출):
    P(B|A) = P(A|B)·P(B) / [P(A|B)·P(B) + P(A|Bᶜ)·P(Bᶜ)]
    → 결과 A로부터 원인 B를 역추론
  • 베이즈 4요소: 사전확률 P(B) · 가능도 P(A|B) · 증거 P(A) · 사후확률 P(B|A)
  • 대수의 법칙: 표본 크기 n이 커질수록 표본평균이 모평균에 수렴
  • 중심극한정리(CLT): 모집단 분포와 상관없이 표본평균의 분포가 정규분포로 근접 (표본 크기 충분히 클 때)
  • 모수(parameter) = 모집단의 특성값(모평균 μ, 모표준편차 σ). 추정량(estimator) = 표본으로 모수를 추정하는 값
  • 불편성: E[T] = θ (편향 없음) · 일치성: n→∞일 때 T→θ
  • 점추정(하나의 값) vs 구간추정(구간으로 추정)
  • 신뢰구간: [X̄ − z(α/2)/√n, X̄ + z(α/2)/√n], 신뢰수준 = 1 - α (보통 95%, 99%)
  • MLE(최대가능도): 가능도함수 L(θ;x) = Πf(xᵢ;θ) → log 취해 미분=0 → θ̂
  • 가설검정: H₀(귀무가설, "차이 없다") vs H₁(대립가설, "차이 있다"). p값 < α → H₀ 기각, 보통 α=0.05

📘 확률 기초 — 표기법과 용어
기호의미
Ω표본공간(Sample Space) — 가능한 모든 결과의 집합. 주사위: {1,2,3,4,5,6}
ℱ사건(Event)들의 모음 (시그마 대수)
Pr(·)확률 함수 — 사건을 입력받아 [0, 1] 사이 값 반환
P(·) 또는 p(x)확률질량함수(PMF) — 이산 확률변수
f(x) 또는 p(x)확률밀도함수(PDF) — 연속 확률변수

⭐ 확률공간 = (Ω, ℱ, Pr). 확률은 전체에 대해 μ(Ω) = 1인 정규화 측도(normalized measure).

실험·사건

  • 실험(trial): 결과를 알 수 없는 행동 (주사위 던지기)
  • 근원사건: 각 시행 결과 (1, 2, 3, 4, 5, 6)
  • 사건(event): 표본공간의 부분집합 (짝수 = {2, 4, 6})

사건의 종류

  • 전사건: P(S) = 1
  • 공사건: P(∅) = 0
  • 여사건(Eᶜ): E에 속하지 않는 결과
  • 배반사건: A ∩ B = ∅

⚠️ 여사건 ≠ 배반

여사건 → 반드시 배반. 하지만 배반 → 반드시 여사건 X (자주 출제!)

📜 확률의 공리 (Probability Axioms)
공리 ① — 비음수성
Pr(A) ≥ 0   (모든 사건 A에 대해)
공리 ② — 정규성
Pr(Ω) = 1
전체 표본공간에 대한 확률의 총합은 1
공리 ③ — 가법성 (서로소/배반)
A ∩ B = ∅  ⇒  Pr(A ∪ B) = Pr(A) + Pr(B)
서로 겹치지 않으면 확률을 더한다
공리 ④ — 공사건
Pr(∅) = 0
불가능한 사건의 확률은 0
🔸 확률은 0 이상 1 이하만 가능. -1, 1.5 같은 값은 불가능!
🎯 확률변수 (Random Variable)

확률변수 X: 표본공간 Ω의 결과를 숫자로 바꾸는 함수. Ω → ℝ. 실현값 = 특정 결과가 나왔을 때 적용한 숫자.

예) 주사위 Ω = {1,2,3,4,5,6}, 확률변수 X: 결과 → 숫자 (X(1)=1, X(2)=2, ...)
짝수/홀수 변수 Y: Y(1)=0, Y(2)=1, Y(3)=0, ... → 주사위 결과 4가 나왔을 때 실현값 Y(4)=1

이산 확률변수 (Discrete)

값이 셀 수 있음. 주사위, 동전. PMF: Σp(xᵢ) = 1

연속 확률변수 (Continuous)

값이 연속적. 키, 시간, 온도. PDF f(x)

누적분포함수 (CDF, Cumulative Distribution Function)
F(x) = P(X ≤ x) = Σxᵢ≤x p(xᵢ)
x 이하인 값이 나올 확률의 누적 합 (← PDF 적분)
확률밀도함수 (PDF, Probability Density Function)
f(x) = dF(x)/dx
확률이 얼마나 빠르게 쌓이는지 (← CDF 미분)
🔁 CDF ↔ PDF 관계: CDF = PDF의 적분, PDF = CDF의 미분.
기댓값 (Expected Value) E(X)
E(X) = Σ x · P(X=x)
확률을 고려한 평균 = "중심 위치" 또는 "균형점"

예) 주사위 E(X) = 1(1/6) + 2(1/6) + ... + 6(1/6) = 3.5.
⚠️ 기댓값은 실제로 나올 수 없는 값일 수도 있음.

🔀 조건부 확률 · 독립 · 베이즈 정리
조건부 확률
P(B | A) = P(A ∩ B) / P(A)
사건 A가 일어났다는 조건에서 B가 일어날 확률
곱셈 공식
P(A ∩ B) = P(B | A) · P(A)
동시에 일어날 확률 = 순서대로 곱하기

예) 주사위에서 짝수 조건 하에 2 이상일 확률
짝수 = {2, 4, 6}, 2 이상 ∩ 짝수 = {2, 4, 6}
→ P(2이상|짝수) = (3/6) / (3/6) = 1

독립 (Independence)
A ⊥ B  ⇔  P(A ∩ B) = P(A) · P(B)
동시 확률이 각 확률의 곱과 같으면 독립. 아니면 종속.
베이즈 정리 (Bayes' Theorem)
P(B|A) = [P(A|B) · P(B)] / [P(A|B)·P(B) + P(A|Bᶜ)·P(Bᶜ)]
결과 A로부터 원인 B의 가능성 역추론. 분모 P(A) = 전체 확률 (전확률 공식으로 전개).
구성요소기호의미
사전확률 (prior)P(B)사건 A가 일어나기 전 B가 발생할 확률 (기존 경험)
가능도 (likelihood)P(A|B)B가 주어졌을 때 A가 발생할 확률
증거 (evidence)P(A)사건 A가 일어날 전체 확률
사후확률 (posterior)P(B|A)A를 관찰한 후 B가 원인일 확률 (추론)
🎯 베이즈 = 결과 → 원인 역추론. 실무 예: 스팸 메일 식별, 의료 진단.
📊 확률 분포 — 이산형 vs 연속형

이산형 (Discrete) 5종

  • 균등분포 (Uniform) — 모든 사건 동일 확률 (주사위 각 면 1/6)

  • 기하분포 (Geometric) — 첫 성공까지의 시행 횟수

🌟 3가지 확률 이론 (추론통계의 기반)

대수의 법칙 (Law of Large Numbers)

모집단에서 추출한 표본(iid)의 크기 n이 커질수록 표본평균의 기댓값이 모집단 평균(모평균)에 수렴.
→ "평균이 진짜 값으로 간다"

중심극한정리 (Central Limit Theorem, CLT)

모집단이 어떤 분포이든, 표본 크기가 커질수록 표본평균의 분포가 정규분포에 가까워짐.
→ 세상 많은 현상이 정규분포를 따르는 이유

대편차 원리

평균에서 크게 벗어날 확률이 지수적으로 감소. 극단값은 드묾.

📏 통계적 추정 (Estimation)

모수(parameter) = 모집단의 특성값 (모평균 μ, 모표준편차 σ 등). 추정량(estimator) = 표본을 이용해 모수를 추정하는 확률변수의 함수 T(X₁,...,Xₙ).

표본평균 (Sample Mean)
X̄ = (1/n) Σᵢ Xᵢ
점추정(point estimation): 하나의 값으로 모수 추정

불편성 (Unbiasedness)

E[T] = θ

추정량의 기댓값이 참값과 일치. 편향 없음. → 불편추정량(unbiased estimator)

일치성 (Consistency)

limn→∞ P(|T − θ| ≥ ε) = 0

n이 커질수록 θ에 수렴. 표본 많을수록 정확.

구간 추정 (Interval Estimation)
신뢰구간 (Confidence Interval)
[X̄ − z(α/2)/√n,   X̄ + z(α/2)/√n]
신뢰수준 = 1 - α (보통 95% or 99%)
P(L(X) < θ < U(X)) ≥ 1 - α
📌 신뢰수준(level of confidence) = 신뢰구간에 모수가 들어 있을 확률 (1-α)
최대가능도법 (MLE, Maximum Likelihood Estimation)
가능도함수 (Likelihood Function)
L(θ; x) = Πi=1n f(xᵢ; θ)
확률밀도함수 f(x;θ)에서 x는 변수, θ는 상수였다면, 가능도는 x는 관측값(상수), θ가 변수.
로그가능도 → 미분 → 최댓값
log L(θ; x) = Σᵢ log f(xᵢ; θ)
d/dθ log L(θ; x) = 0  ⇒  θ̂MLE
곱셈을 덧셈으로 바꾸려 로그 취함 → 미분=0 → 최댓값이 되는 θ

예) 동전 5번 던져 앞/앞/앞/뒤/뒤 → L(θ) = θ³(1−θ)² → d/dθ log L = 0 풀면 θ̂ = 3/5 = 0.6

⚖️ 가설 검정 (Hypothesis Testing)

추정 결과가 타당한지 확인하는 절차. 두 집단의 평균 차이가 통계적으로 유의한지 판단.

귀무가설 H₀ (null hypothesis)

"차이 없다" / 현상 유지. 예: μ₁ = μ₂

대립가설 H₁ (alternative hypothesis)

"차이 있다" / 주장. 예: μ₁ ≠ μ₂

p값 (p-value)
p < α  ⇒  H₀ 기각
H₀가 참이라 가정할 때 관측된 통계량이 나올 확률.
유의수준 α (significance level, 보통 0.05 또는 0.01)보다 작으면 H₀ 기각 → 대립가설 H₁ 채택.
제1종 오류 (Type I) vs 제2종 오류 (Type II) — ★ 매우 빈출
H₀ 참 (차이 없음)H₀ 거짓 (차이 있음)

검정력 = 1 − β

🔗 데이터 결합 — merge (SQL JOIN과 동일)

merge는 공통 키(key)를 기준으로 지능적으로 결합. 4가지 Join 패턴 중 선택.

how 값명칭설명
'inner'내부결합 (Inner Join)(기본값) 양쪽 모두에 존재하는 키만 (교집합)
'outer'외부결합 (Outer/Full Join)양쪽 중 한 곳에만 있어도 모두 유지 (합집합). 없는 값은 NaN
'left'왼쪽결합 (Left Join)왼쪽 df 모두 유지, 오른쪽은 매칭되는 것만 붙임
'right'오른쪽결합 (Right Join)오른쪽 df 모두 유지, 왼쪽은 매칭만
pd.merge(df1, df2, on='ID', how='inner')  # 기본값 - 공통 키만
pd.merge(df1, df2, on='ID', how='outer')  # 전부, 빈 값은 NaN
pd.merge(df1, df2, on='ID', how='left')   # 왼쪽 기준
pd.merge(df1, df2, on='ID', how='right')  # 오른쪽 기준
인덱스 기반 merge
# 왼쪽 인덱스와 오른쪽 'index_num' 컬럼 비교
pd.merge(df1, df2, left_index=True, right_on='index_num')
⚠️ ★ merge 함정 3가지:
① NaN 포함 시 타입 변환: int 컬럼이 NaN을 포함하면 자동으로 float로 변환
② 중복 컬럼명: 같은 이름 컬럼이 두 df에 있고 기준이 아니면 자동 접미사 _x, _y 추가
③ 키 명시: 같은 이름 컬럼 여러 개 있을 때 on=으로 기준 명시 필요
🔗 데이터 결합 — concat (단순 이어붙이기)

concat은 축(axis)을 기준으로 단순히 이어붙임. 키 매칭 X.

# 수직 방향 (axis=0, 기본) - 행으로 쌓기
pd.concat([df1, df3], axis=0)    # 같은 양식 월별 데이터 통합 등

# 수평 방향 (axis=1) - 열로 붙이기
pd.concat([df1, df2], axis=1)    # 인덱스 같을 때 옆으로 결합

concat (vertical, axis=0)

같은 양식의 월별 데이터 통합 같은 경우. 위에서 아래로 쌓음.

concat (horizontal, axis=1)

인덱스가 같을 때 옆으로 붙이기.

merge vs concat

merge: 공통 키 기준으로 지능적 결합 (SQL JOIN). concat: 단순 이어붙임.

Q6. 박스플롯에서 최댓값 경계 공식은?

  • ④ 최댓값 그대로

Q7. 변동계수 CV의 공식은?

  • ② σ / x̄
  • ③ x̄ / σ
  • ④ σ × x̄
💡 정답: ② σ / x̄ (표준편차 ÷ 평균)

• 0.1~0.3: 보통
• > 1.0: 매우 큼
Q8. 피어슨 상관계수 r = 0이면?

Q9. 결정계수 R²의 범위는?
  • ① -1 ≤ R² ≤ 1
  • ② 0 ≤ R² ≤ 1
  • ③ -∞ ~ ∞
  • ④ 0 이상만 (상한 없음)
💡 정답: ② 0 ≤ R² ≤ 1
R² = 1 - (모델 오차 / 전체 변동). 0이면 모델이 평균만큼도 설명 못함, 1이면 완벽 설명.
참고: 상관계수 r은 -1~1인데, R²은 0~1. 헷갈리면 안 돼. 단순회귀에선 R² = r².
Q10. 확률의 공리가 아닌 것은?
  • ① Pr(∅) = 0
  • ② Pr(A) ≥ 0
  • ③ Pr(Ω) = 1
  • ④ Pr(A) ≤ 0.5
💡 정답: ④ Pr(A) ≤ 0.5 (이건 공리 아님)
확률의 공리 4개:
① Pr(∅) = 0 (불가능한 사건)
② Pr(A) ≥ 0 (비음수)
③ Pr(Ω) = 1 (전체 확률)
④ 서로소일 때 Pr(A∪B) = Pr(A) + Pr(B) (가법성)
확률은 0~1 사이지만 0.5 이하여야 할 이유는 없음 (확실한 사건은 1).

Q12. 베이즈 정리에서 사후확률은?
  • ① P(A)
  • ② P(B)
  • ③ P(A|B)
  • ④ P(B|A)
💡 정답: ④ P(B|A)
베이즈 4요소 (A=결과, B=원인):
• 사전확률 P(B): 결과 보기 전 원인의 확률
• 가능도 P(A|B): 원인 B 하에서 결과 A 확률
• 증거 P(A): 결과의 전체 확률
• 사후확률 P(B|A): 결과 관찰 후 원인 확률

Q14. 제1종 오류(α)의 정의는?
  • ① H₀이 참인데 기각하는 오류 (무죄 → 유죄)
  • ② H₀이 거짓인데 채택하는 오류 (유죄 → 무죄)
  • ③ 검정력과 같은 개념
  • ④ 신뢰수준이 낮은 오류
💡 정답: ① H₀ 참인데 기각 (무죄→유죄)
⭐ 재판 비유로 외우면 안 까먹어:
• 1종 오류 α: 무죄인 사람을 유죄로 (H₀ 참인데 기각) — False Positive
• 2종 오류 β: 유죄인 사람을 무죄로 (H₀ 거짓인데 채택) — False Negative
• 검정력 = 1 - β (올바르게 유죄 판결하는 능력)
α와 β는 트레이드오프 관계야.
Q15. 대칭 + 양의 정부호 행렬에만 적용 가능한 분해는?

  • ② LU
  • ③ Cholesky
  • ④ QR
💡 정답: ③ Cholesky
행렬 분해 5종 비교:

  • ② 양쪽 모든 키를 유지한다 (합집합, 없는 값은 NaN)
  • ③ 왼쪽 df 기준으로만 결합한다
  • ④ 오른쪽 df 기준으로만 결합한다

Q17. 단답형 — NumPy 배열 mat.shape가 (2, 3)일 때, mat.size의 값은?
💡 정답: 6
shape (2, 3) = 2행 × 3열. size는 전체 원소 수 = 행 × 열 = 2 × 3 = 6.
NumPy 배열 속성 3총사:
• .shape (2, 3) — 모양
• .size 6 — 원소 총 개수
• .ndim 2 — 차원 수
Q18. 단답형 — 공분산 11.017, σ(x)=3.319, σ(y)=4.581일 때 대략적인 상관계수는? (소수 둘째자리 반올림)
💡 정답: 0.72
r = Cov(X,Y) / (σx × σy)
= 11.017 / (3.319 × 4.581)
= 11.017 / 15.20...
≈ 0.72 (양의 강한 상관)
이 값은 G1과 G3의 상관관계랑 비슷 — 1학기 성적 높은 학생이 최종 성적도 높은 경향.
Q19. 단답형 — 공정한 주사위의 기댓값 E(X)는?
💡 정답: 3.5
E(X) = Σ x · P(X=x)
= 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
= (1+2+3+4+5+6)/6 = 21/6 = 3.5
⚠️ 주사위엔 "3.5"라는 면이 없지만 기댓값은 실제 나올 수 없는 값일 수도 있어 — 기댓값 = "중심 위치 / 균형점".
Q20. 단답형 — 검정력(Power)을 β로 표현하면? (수식)
💡 정답: 1 - β
검정력(Statistical Power) = 1 - β
= H₀이 거짓일 때 올바르게 기각할 확률
= "유죄인 사람을 유죄로" 판정할 능력
실무 권장: 검정력 ≥ 0.8 (즉, β ≤ 0.2). α(1종)와 β(2종)는 트레이드오프 — 한쪽 낮추면 다른 쪽 올라감.
