class MyCalcClass:
    def __init__(self, x, y):   # 생성자

기술 통계 (Descriptive)

추론 통계 (Inferential)

분포의 모양 — 왜도 & 첨도

왜도 (Skewness)

한쪽으로 치우쳤는가 (좌/우 비대칭). > 0: 오른쪽 꼬리, < 0: 왼쪽 꼬리.

첨도 (Kurtosis)

가운데가 뾰족하게 몰렸는가. > 3: 정규보다 뾰족, < 3: 평평.

🔗 공분산 · 상관계수
공분산 (Covariance)
Cov(X,Y) = (1/n) Σ (xᵢ − x̄)(yᵢ − ȳ)
같이 증가/감소하는지 보는 값. 양수: 같은 방향, 음수: 반대. 단위에 영향 받아 강도 판단 불가!
피어슨 상관계수 (Pearson Correlation)
r = Cov(X,Y) / (σₓ · σᵧ)
공분산을 두 표준편차의 곱으로 나눠 -1 ≤ r ≤ 1로 표준화. r=1: 완벽한 양의 선형, r=-1: 완벽한 음의 선형, r=0: 선형 관계 없음 (비선형은 있을 수 있음!).
📎 상관계수 ≠ 인과관계. p값(p-value)이 낮을수록 관계의 신뢰도↑
📈 단순선형회귀 · 최소제곱법 · 결정계수
단순선형회귀 모형
y = ax + b
a(기울기·회귀계수): X가 1 증가할 때 Y의 변화량
b(절편): X=0일 때 Y의 값
최소제곱법 (OLS, Ordinary Least Squares)
min Σ (yᵢ − ŷᵢ)²
실제값과 예측값 차이(잔차)의 제곱합을 최소화하여 a, b를 찾음
결정계수 (R², Coefficient of Determination)
R² = 1 − (모델 오차 / 전체 변동성)
0 ≤ R² ≤ 1. R²=0.64 → 모델이 데이터 변동의 약 64% 설명. 단순선형회귀에선 R² = r²

📘 확률 기초 — 표기법 · 용어
기호의미
Ω표본공간: 가능한 모든 결과. 예) 주사위 {1,2,3,4,5,6}
F사건(Event)들의 모음 (시그마 대수)
Pr(·)확률 함수 (사건이 파라미터, 0~1 사이)
P(·)확률질량함수(PMF) — 이산 확률변수
p(·)확률밀도함수(PDF) — 연속 확률변수

⭐ 확률공간 = (Ω, F, Pr)

실험 · 사건

  • 실험(trial): 결과를 모르는 행동 (주사위 던지기)
  • 근원사건: 각 시행 결과 (1,2,3,4,5,6)
  • 사건(event): 표본공간의 부분집합 (짝수={2,4,6})

사건의 종류

  • 전사건: P(S)=1
  • 공사건: P(∅)=0
  • 여사건(Eᶜ): E에 속하지 않는 결과
  • 배반사건: A ∩ B = ∅

⚠️ 여사건 ≠ 배반

여사건 → 반드시 배반. 하지만 배반 → 반드시 여사건 X (자주 출제!)

📜 확률의 3공리
공리 1 — 비음수성
Pr(A) ≥ 0   (모든 사건 A에 대해)
공리 2 — 정규성
Pr(Ω) = 1   (전체 확률 = 1)
공리 3 — 가법성(서로소)
A ∩ B = ∅  ⇒  Pr(A ∪ B) = Pr(A) + Pr(B)
🔸 Pr(∅)=0 (불가능한 사건). 확률은 0 이상 1 이하만 가능. -1은 불가능!
🔀 조건부 확률 · 독립 · 베이즈 정리
조건부 확률
P(B | A) = P(A ∩ B) / P(A)
A가 일어난 상태에서 B가 일어날 확률
곱셈 공식
P(A ∩ B) = P(B | A) · P(A)
독립 (Independence)
A ⊥ B ⇔ P(A ∩ B) = P(A) · P(B)
동시 확률이 각 확률의 곱이면 독립. 아니면 종속.
베이즈 정리 (Bayes' Theorem)
P(B|A) = [P(A|B) · P(B)] / P(A)
분모: P(A) = P(A|B)·P(B) + P(A|Bᶜ)·P(Bᶜ)
구성요소기호의미
사전확률P(B)사건 A 이전 B의 확률 (기존 경험)
가능도P(A|B)B가 주어졌을 때 A 발생 확률
증거P(A)사건 A가 일어날 전체 확률
사후확률P(B|A)A 관찰 후 B의 확률 (추론)
🎯 베이즈 = 결과 → 원인 역추론. P(A∪B)(합집합)는 베이즈에 쓰이지 않음!
🎯 확률변수와 확률분포

확률변수(X): 표본공간의 결과를 숫자로 매핑하는 함수. 실현값 = 실제 관측된 값.

이산 확률변수

값이 셀 수 있음 (주사위). 확률질량함수(PMF): Σp(xᵢ) = 1

연속 확률변수

값이 연속적 (키, 시간). 확률밀도함수(PDF)

누적분포함수 (CDF)
F(x) = P(X ≤ x)
지금까지 누적된 확률 (← PDF 적분)
확률밀도함수 (PDF)
f(x) = dF(x)/dx
확률이 얼마나 빠르게 쌓이는지 (← CDF 미분)
기댓값 (Expected Value)
E(X) = Σ x · P(X=x)
확률 고려한 평균 = "중심 위치" or "균형점" (실제 나올 수 없는 값일 수도!)

예) 주사위 E(X) = 1(1/6)+2(1/6)+…+6(1/6) = 3.5

📊 주요 확률분포 — 이산형 vs 연속형
분포 확장 흐름
균등 → 베르누이 → 이항 → 푸아송 → 정규
간단 → 복잡 순서. 베르누이(한 번) → 이항(여러 번) → 푸아송(시간 기준) → 정규(전체 형태)

균등분포 (Uniform) — 이산/연속

모든 사건이 동일 확률. 예) 주사위 각 면 1/6

베르누이 (Bernoulli) — 이산

성공(1) / 실패(0)의 단일 시행

이항분포 (Binomial) — 이산

독립 베르누이 시행을 n회 반복했을 때 성공 횟수. 예) 동전 30번 던져 앞면 수

푸아송 (Poisson) — 이산

발생 확률이 작은 사건이 시간/면적당 몇 번 발생하는지. λ(lambda)

정규분포 (Normal) — 연속

종 모양(bell curve). 가우시안. 대칭. 평균 ± 표준편차

로그정규 — 연속

log(X)가 정규분포. 양수만, 오른쪽 꼬리 긺. 소득분포 등

⭐ 시험 빈출: 이산형 vs 연속형 구분 — 정규분포는 연속형, 베르누이·이항·푸아송은 이산형.

🌟 추론통계 3대 법칙

대수의 법칙

평균이 진짜 값으로 간다. 시행 횟수 N이 커지면 표본평균이 기댓값에 수렴.

중심극한정리 (CLT)

분포 모양이 정규분포가 된다. 모집단이 어떤 분포든, 표본 크기가 커지면 표본평균의 분포가 정규분포에 가까워짐.

대편차 원리

평균에서 크게 벗어날 확률이 지수적으로 감소. 극단값은 드물다.

주요 파생분포

카이제곱 (χ²)

m개의 표준정규 확률변수의 제곱합. W = Σ Zᵢ². (자유도 m)

스튜던트 t분포

T = Z / √(W/m). 소표본 평균 검정에 사용.

F 분포

두 카이제곱분포의 비율. 분산 비교(ANOVA).

📏 통계적 추정 (Estimation)
표본평균 (Sample Mean)
X̄ = (1/n) Σ Xᵢ
추정량 = 확률변수의 함수 T(X₁,…,Xₙ)

불편성 (Unbiasedness)

E[T] = θ. 편향(bias) 없음. 기대값이 참값과 일치.

일치성 (Consistency)

n이 커지면 θ에 수렴. 표본 많을수록 정확.

신뢰구간 (Confidence Interval)
[X̄ − z(α/2)/√n,   X̄ + z(α/2)/√n]
신뢰수준 = 1 − α (보통 95% or 99%)
최대가능도법 (MLE, Maximum Likelihood Estimation)
d/dθ [log L(θ; x)] = 0  →  θ̂
① 가능도함수 L(θ;X) = Π f(xᵢ;θ) → ② 로그 취함 → ③ 미분=0 → ④ θ̂ 구함

예) 동전 5번 던져 앞/앞/앞/뒤/뒤 → L(θ) = θ³(1−θ)² → θ̂ = 3/5 = 0.6

⚖️ 통계적 검정 (Hypothesis Testing)

귀무가설 H₀

"차이 없다" (현상 유지). 예: μ₁ = μ₂

대립가설 H₁

"차이 있다" (주장). 예: μ₁ ≠ μ₂

p값 (p-value)
p < α → H₀ 기각
H₀가 참이라 가정할 때 이 통계량이 나올 확률. 유의수준 α(보통 0.05).
제1종 오류 vs 제2종 오류
H₀ 참 (차이 없음)H₀ 거짓 (차이 있음)
H₀ 기각제1종 오류 (α)
무죄→유죄		올바른 결정
검정력 = 1−β
H₀ 채택올바른 결정제2종 오류 (β)
유죄→무죄
🎯 검정력(Power) = 1 − β ≥ 0.8 권장. α와 β는 트레이드오프. 빅데이터에서는 p값만 보지 말고 신뢰구간도 확인!

# 수평 방향 (좌우)

concat (vertical, axis=0)

같은 양식의 월별 데이터 통합 같은 경우. 위에서 아래로 쌓음.

concat (horizontal, axis=1)

인덱스가 같을 때 옆으로 붙이기.

merge vs concat

merge: 공통 키 기준으로 지능적 결합 (SQL JOIN). concat: 단순 이어붙임.
