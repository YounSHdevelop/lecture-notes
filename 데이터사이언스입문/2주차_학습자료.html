🔬 Chapter 3. SciPy (사이파이)
📐 선형대수 (scipy.linalg)
from scipy import linalg
import numpy as np

A = np.array([[1, 2],
              [3, 4]])

# 행렬식 (Determinant)
linalg.det(A)    # -2.0

# 역행렬 (Inverse)
linalg.inv(A)
# [[-2.  1. ],
#  [ 1.5 -0.5]]

# 고유값과 고유벡터 (Eigenvalue, Eigenvector)
eigenvalues, eigenvectors = linalg.eig(A)
# 고유값: [-0.372, 5.372]
함수수학적 의미반환값
linalg.det(A)행렬식 det(A)스칼라
linalg.inv(A)역행렬 A⁻¹행렬
linalg.eig(A)고유값 분해(고유값배열, 고유벡터행렬)
🎯 수치 최적화 (scipy.optimize)
뉴턴법 — 방정식의 근 구하기
from scipy.optimize import newton

# f(x) = x³ - 2 의 근
def f(x):
    return x**3 - 2

# x=1에서 시작하여 근 탐색
root = newton(f, x0=1)
# 1.2599... ≈ ∛2
minimize_scalar — 함수 최솟값
from scipy.optimize import minimize_scalar

# f(x) = (x-3)² + 2 의 최솟값
def g(x):
    return (x - 3)**2 + 2

result = minimize_scalar(g,
             method='Brent')
result.x    # 3.0  ← 최솟값 위치
result.fun  # 2.0  ← 최솟값

뉴턴법(Newton's Method): 초기값 x₀에서 시작해 접선을 그어 근에 점점 수렴하는 수치해석 방법

⚠️ 핵심 캐치 — 시험 포인트
★ POINT 1

np.array()와 list의 차이: NumPy 배열은 원소별 연산(벡터화) 지원, 리스트는 +가 연결(concatenate)임

★ POINT 2

dtype 자동 결정: 배열에 정수만 있으면 int64, 실수 섞이면 float64로 자동 결정됨

★ POINT 3

[::-1] 역순 슬라이싱: 배열 뒤집기. np.sort(arr)[::-1]로 내림차순 정렬 가능

★ POINT 4

np.dot(A, B) vs A*B: @ 또는 np.dot()는 행렬 곱, *는 원소별 곱(Hadamard). 시험에서 자주 혼동!

★ POINT 5

np.random.seed(): 난수 재현성 보장. 같은 seed → 같은 난수 시퀀스. 실험/테스트에서 필수

★ POINT 6

replace=False: 비복원 추출(중복 불가). 기본값은 replace=True(복원 추출). 구분 필수!

★ POINT 7

linalg.eig() 반환값: (고유값 배열, 고유벡터 행렬) 튜플 반환. 두 변수로 받아야 함

★ POINT 8

df.drop() axis 구분: axis=0은 행 삭제, axis=1은 열 삭제. 반대로 쓰면 오류 발생!

★ POINT 9

Series vs DataFrame: Series는 1차원(하나의 열), DataFrame은 2차원(여러 열). df['열이름']은 Series 반환, df[['열이름']]은 DataFrame 반환

★ POINT 10

cumsum(): 누적합. [1,2,3,4,5]의 cumsum → [1,3,6,10,15]. sum()과 혼동 주의

🔑 핵심 키워드
ndarray
N차원 배열
NumPy의 핵심 자료구조. 동일한 dtype의 원소로 구성된 N차원 배열
dtype
데이터 타입
배열 원소의 데이터 유형. int64, float64, bool 등. 배열 내 모든 원소가 동일
Vectorization
벡터화 연산
반복문 없이 배열 전체에 연산을 적용하는 방식. NumPy의 핵심 성능 요인
Broadcasting
브로드캐스팅
크기가 다른 배열 간 연산 시 자동으로 형태를 맞추는 NumPy 규칙
seed
난수 시드
난수 생성기의 초기값. 같은 seed 사용 시 항상 동일한 난수 시퀀스 생성
Sampling with/without Replacement
복원/비복원 추출
복원: 뽑은 것을 되돌리고 다시 뽑음(중복 가능). 비복원: 뽑은 것 제외(중복 불가)
reshape
형태 변환
원소 수를 유지하면서 배열 형태(shape)를 변경. 예: (6,) → (2,3)
Matrix Multiplication
행렬 곱
np.dot() 또는 @ 연산자. A(m×n) × B(n×p) = C(m×p)
Determinant
행렬식
정방행렬의 특성값. 0이면 역행렬 없음. scipy.linalg.det()로 계산
Eigenvalue / Eigenvector
고유값 / 고유벡터
Av = λv를 만족하는 λ(고유값)와 v(고유벡터). 데이터 분석(PCA 등)의 핵심
Series
시리즈
Pandas의 1차원 자료구조. 인덱스가 있는 배열. DataFrame의 각 열
DataFrame
데이터프레임
Pandas의 2차원 자료구조. 행과 열이 있는 테이블 형태의 데이터
isin()
포함 여부 확인
값이 지정된 목록에 있는지 확인. 여러 조건을 OR로 연결할 때 유용
merge()
데이터 병합
