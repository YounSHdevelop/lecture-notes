제4장 스마트시대의 비즈니스와 모바일 상거래

e-비지니스의 이해 · 한신대학교 2학년 1학기

📋 핵심 요약 (30초 정리)
스마트 혁명
2009년 아이폰 등장으로 시작된 변화. 사용자를 디지털 전문가로 변화시키며 산업 전반에 혁신을 불러옴
스마트폰
인터넷 정보검색, PC 기능을 갖춘 휴대용 컴퓨터. 2021년 한국 가입자 약 5,566만명
N-Screen
스마트폰 → 태블릿 → 스마트TV 등 다양한 기기 간 연결성을 강화하는 서비스
스마트 생태계
다양한 스마트 기기 + 무선 인터넷 + 모바일 앱으로 형성된 개방적 생태계
SNS 확산
페이스북 27억명(2021), 카카오톡 4,700만명(2021), 인스타그램 1,860만명(2022)
스마트 콘텐츠
스마트 기기 특성을 활용한 콘텐츠. 국내 시장 규모 133.6조원(2021)
앱 스토어
모바일 애플리케이션을 사고파는 온라인 장터. 앱 경제(App Economy)를 형성
모바일 광고
2018년 1,572억 달러 → 2022년 3,195억 달러로 약 2배 증가
ICT 산업구조 개편
요금제·통화품질 경쟁에서 OS·앱스토어 중심 경쟁으로 산업 구조가 전환
융합 비즈니스
ICT + 전통산업 융합. 자동차, 에너지, 의료, 조선 등 다양한 분야와 결합
모바일 플랫폼
애플 iOS + 구글 안드로이드 = 96.3% 시장 점유. 양강 구도 형성
모바일 웹 2.0
모바일 + 참여·공유·개방 결합. 실시간 정보 생산·유통·공유가 가능
M-Commerce
모바일 기기로 지불처리가 가능한 전자상거래. 재화·서비스·정보 거래 포함
LBS (위치기반 서비스)
GPS 기반 위치기반 서비스. 구글 스트리트 뷰, 맛집 찾기 등에 활용
증강현실 (AR)
실제 공간에 가상 정보를 추가한 기술. 포켓몬GO, IKEA Place 등
모바일 IPTV
이동 중 방송 콘텐츠를 수신할 수 있는 서비스. 웨이브, 티빙 등
앱스토어 수익 모델
애플 기준 개발자 70% : 애플 30% 배분. 2021년 개발자 수익 71조원
⚖️ 개념 비교 카드

스마트폰 vs 일반 모바일폰

스마트폰

  • PC 수준의 기능 수행
  • 앱 설치 및 확장 가능
  • 인터넷 브라우징
  • 모바일 OS 탑재

일반 모바일폰

  • 음성통화 중심
  • 제한적 기능
  • 앱 설치 불가
  • 단순 운영체제

과거 모바일 산업 vs 현재 플랫폼 기반

과거 (이통사 중심)

  • 이동통신사 중심 구조
  • 폐쇄적 생태계
  • HW 성능 맞춤 납품
  • SW 산업 왜곡

현재 (플랫폼 기반)

  • 플랫폼 기반 단말기 생산
  • 콘텐츠사 플랫폼별 제작
  • 웹 통한 수익 창출
  • 개방적 생태계

모바일 웹 1.0 vs 모바일 웹 2.0

모바일 웹 1.0

  • 단방향 정보 전달
  • 제한적 콘텐츠
  • 수동적 소비
  • 정적인 웹

모바일 웹 2.0

  • 참여·공유·개방
  • XML/XHTML 기반
  • Ajax UI, 오픈 API
  • 실시간 소통

초창기 플랫폼 vs 최근 플랫폼

초창기 플랫폼

  • 하드웨어 제어 중심
  • 보이지 않는 중간자
  • UI 없음
  • 제한적 네트워크

최근 플랫폼

  • 앱·서비스 실행 브레인
  • 독자적 UI 보유
  • PC 수준 OS
  • 5G / Wi-Fi 지원

애플 앱스토어 vs 구글 플레이스토어

애플 App Store

  • 업계 최초 앱스토어
  • 220만개 앱(2017)
  • 1,300억건 다운로드
  • 매출 857억 달러(2021)

구글 Play Store

  • 350만개 앱(2017)
  • 멀티태스킹 지원
  • 쉬운 연동성
  • PC 웹에서 바로 설치
