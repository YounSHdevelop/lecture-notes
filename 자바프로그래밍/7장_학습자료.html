Object 클래스 최상위 부모

자바의 모든 클래스는 자동으로 Object를 상속받습니다. class Donut {}은 실제로 class Donut extends Object {}와 동일합니다.

메서드반환형설명
equals(Object o)boolean두 객체가 동일한지 비교 (기본: 주소 비교)
hashCode()int객체 고유 해시코드 반환
toString()String객체를 문자열로 표현 (기본: "클래스명@해시코드")
getClass()Class<?>객체의 실제 클래스 정보 반환
wait() / notify()void멀티스레드 동기화

1. equals() 오버라이딩 시험 필수

❌ == 연산자

  • 참조(주소) 비교
  • 서로 다른 new 객체면 항상 false
  • 기본 자료형은 값 비교 가능

✅ equals() 메서드

  • 내용(값) 비교 — 오버라이딩 필요
  • String은 이미 내용 비교로 구현됨
  • 직접 만든 클래스는 직접 오버라이딩
// equals() 오버라이딩 — 절차: instanceof 확인 → 다운캐스팅 → 필드 비교 @Override public boolean equals(Object obj) { if (obj instanceof Donut) { Donut other = (Donut) obj; // 다운캐스팅 return this.name.equals(other.name); // 필드 비교 } return false; } Donut d1 = new Donut("초코"); Donut d2 = new Donut("초코"); d1 == d2; // false — 서로 다른 주소 d1.equals(d2); // true — 이름이 같으므로
⚠️ 핵심: 기본 Object의 equals()는 == 과 동일(주소 비교)합니다. 내용 비교를 하려면 반드시 @Override로 재정의해야 합니다.

2. toString() 오버라이딩

오버라이딩하지 않으면 Donut@7f31245a 형태로 출력됩니다. System.out.println(객체) 호출 시 toString()이 자동으로 호출됩니다.

@Override public String toString() { return name + " 도넛(" + price + "원)"; } Donut d1 = new Donut("초코", 2000); System.out.println(d1); // 초코 도넛(2000원)

3. getClass() vs instanceof

Object obj = new ChocoDonut(); // instanceof — 부모 클래스도 true if (obj instanceof ChocoDonut) { ChocoDonut choco = (ChocoDonut) obj; System.out.println("초코 도넛 발견!"); } // getClass() — 정확한 클래스명 반환 Donut d1 = new ChocoDonut(); System.out.println(d1.getClass().getName()); // ChocoDonut

String 클래스 불변(Immutable)

불변성 & String Pool

String은 한 번 생성하면 내용 변경 불가.
s1 = s1 + "World" → 기존 객체 수정이 아닌 새 객체 생성.

String Pool: 리터럴은 재사용
String s1 = "Java"; // Pool
String s2 = "Java"; // 같은 주소
s1 == s2 → true

String s3 = new String("Java");
s1 == s3 → false ← 별도 객체!

String 주요 메서드

  • length()문자열 길이
  • charAt(i)i번째 문자 반환
  • equals(s)내용 비교
  • equalsIgnoreCase(s)대소문자 무시 비교
  • indexOf(s)첫 위치 반환 (없으면 -1)
  • lastIndexOf(s)마지막 위치 반환
  • substring(b,e)b~e-1 부분 문자열
  • replace(old,new)문자열 치환
  • split(regex)구분자로 분리 → 배열
  • trim()앞뒤 공백 제거
  • toUpperCase()모두 대문자
  • toLowerCase()모두 소문자
  • startsWith(s)해당 문자열로 시작?
  • contains(s)포함 여부

String 메서드 코드 예제

String s1 = "레몬도넛"; s1.length(); // 4 s1.charAt(0); // '레' s1.indexOf("도"); // 2 s1.substring(0, 2); // "레몬" s1.replace("레몬", "딸기"); // "딸기도넛" — 원본 불변! String csv = "초코,레몬,딸기"; String[] parts = csv.split(","); // parts[0]="초코", parts[1]="레몬", parts[2]="딸기" " hello ".trim(); // "hello" "hello".toUpperCase(); // "HELLO"
⚠️ 주의! String 비교는 반드시 equals() 사용. new String()으로 만든 객체는 내용이 같아도 == 비교 시 false입니다.

StringBuffer / StringBuilder 가변(Mutable)

StringBuffer

  • 멀티스레드 환경에서 안전 (synchronized)
  • 여러 스레드 동시 접근 안전
  • 상대적으로 약간 느림

StringBuilder

  • 단일 스레드 환경에서 사용
  • 동기화 없어 더 빠름
  • 일반 상황에서 권장

StringBuffer 주요 메서드 시험 필수

메서드설명예시 결과
append(s)끝에 추가"도넛" → "도넛가게"
insert(offset, s)특정 위치에 삽입insert(2,"맛있는")
delete(start, end)범위 삭제delete(0,2)
replace(start,end,s)범위 치환replace(0,2,"초코")
reverse()문자열 뒤집기"ABC" → "CBA"
toString()String으로 변환
length()길이 반환
charAt(i)특정 위치 문자

StringBuffer 코드 예제

StringBuffer sb = new StringBuffer("도넛"); sb.append(" 가게"); // "도넛 가게" sb.insert(2, "맛있는 "); // "도넛맛있는 가게" sb.delete(0, 2); // "맛있는 가게" sb.replace(0, 2, "초코"); // 0~1 범위를 "초코"로 치환 sb.reverse(); // 전체 뒤집기 StringBuffer sb2 = new StringBuffer("ABC"); sb2.reverse(); System.out.println(sb2); // CBA
핵심 차이: String은 불변 — 수정마다 새 객체 생성 (메모리 낭비 가능)
StringBuffer/Builder는 가변 — 같은 객체 내부에서 수정 (효율적)
문자열을 반복적으로 수정할 때는 StringBuffer/StringBuilder를 사용하세요.

// import 없이 바로 사용 Math.abs(-10); // 10 Math.abs(-3.14); // 3.14 Math.ceil(3.2); // 4.0 (올림) Math.floor(3.9); // 3.0 (내림) Math.round(3.5); // 4 (반올림 → long) Math.pow(2, 3); // 8.0 Math.sqrt(25); // 5.0 Math.max(10, 20); // 20 // 1~6 랜덤 정수 (주사위) int dice = (int)(Math.random() * 6) + 1;
💡 random() 공식: (int)(Math.random() * N) + start
start 이상 (start + N - 1) 이하의 정수 생성
예) 1~10: (int)(Math.random() * 10) + 1 | 50~100: (int)(Math.random() * 51) + 50

Q1출력값 예측
다음 코드의 출력 결과는?
String s1 = "Java"; String s2 = "Java"; String s3 = new String("Java"); System.out.println(s1 == s2); System.out.println(s1 == s3); System.out.println(s1.equals(s3));
① true / true / true
② true / false / true
③ false / false / true
④ true / false / false
✅ 정답: ②
s1, s2는 같은 String Pool 주소 → true
s3는 new String()으로 별도 힙 객체 생성 → s1 == s3 false
equals()는 내용 비교 → "Java" == "Java" → true

Q10버그 찾기
다음 코드에서 논리적 버그가 있는 줄과 이유를 고르시오.
01 String s1 = "Hello"; 02 String s2 = new String("Hello"); 03 if (s1 == s2) { 04 System.out.println("같은 문자열"); 05 } 06 Integer num = 100; 07 System.out.println(num + 50);
① 7번 줄 — Integer와 int를 더할 수 없다
② 3번 줄 — 문자열 비교는 equals()를 사용해야 한다
③ 6번 줄 — int를 Integer에 바로 대입할 수 없다
④ 버그 없음
✅ 정답: ②
3번 줄: s2는 new String()으로 만든 별도 객체 → == 비교는 항상 false
